# Folio-J

> 项目仍处于早期开发阶段，目前以本地单用户 Web 应用运行，需要从源码启动。阅读、片段保存和讲解回看已可使用，功能与使用体验仍在迭代。

围绕日语原版内容的个人沉浸与学习工具。
读感兴趣的作品，获得个性化的帮助，并让值得保留的讲解能够再次找到。

## 可以怎样使用

- **读日语原书。** 导入可重排 EPUB，使用目录、书内搜索、横竖排与注音设置，离开后继续上次的阅读。
- **留下想学的片段。** 从书中划选原文，连同语境和出处保存；也可以手动录入来自其他内容的日文片段。
- **围绕难点讨论。** 接入自己的模型服务，针对片段提问、追问，或请求生成讲解。
- **保存和重读讲解。** 自行编写、粘贴 Markdown 或保存 AI 生成的讲解，与原文对照阅读；从书中保存的片段还可以在原处回看。

例如，读小说时遇到一句难以理解的话，可以先保存这一句和前后文，打开片段讨论，再把需要留下的解释整理为讲解。继续读书时，这段原文上的标记可以带你回看已保存的内容。

阅读、保存片段和人工维护讲解无需配置模型。使用 AI 功能时，需要接入模型服务；请求会发送到你配置的服务，并可能产生费用。

## 快速开始

准备 Python 3.11、Node.js 24、uv、pnpm 10 和 just。下载或克隆仓库后，在仓库根目录运行：

```sh
just setup   # 安装依赖
just start   # 初始化／升级数据库，构建并启动应用
```

启动完成后，打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。在终端按 `Ctrl-C` 停止服务。

1. 在素材库导入 EPUB，选择已有来源或新建来源。来源用来组织同一作品的材料与学习片段。
2. 打开书籍开始阅读，划选想保存的原文，创建学习片段。没有 EPUB 时，也可以从来源目录手动添加片段。
3. 打开片段，直接编写讲解；需要 AI 辅助时，先在「设置」中添加模型服务与模型，再展开讨论。

默认数据保存在本机 `data/app.db`。已有数据的用户，更新代码并启动前请先阅读[升级与备份指南](docs/UPGRADING.md)。环境版本、热重载和开发命令见[开发指南](docs/DEVELOPMENT.md)；端口、数据路径与模型配置见[使用指南](docs/USAGE.md)。

## 当前边界

- 当前支持普通可重排 EPUB；学习条目积累库、材料内直接对话、媒体播放与主动复习尚未提供。
- 应用绑定本机 `127.0.0.1`，按单用户运行；同一数据库只运行一个后台实例。当前进程锁使用 macOS／Linux 机制，Windows 运行尚未验证。
- API 密钥保存在数据库旁的私有目录，以本机文件权限保护，尚未加密。备份时需要同时保管数据库与对应凭据目录。
- Safari、Firefox、实体触屏等环境的验证仍不完整。详细能力、验收范围和已知缺口见[实施基线](docs/handovers/MVP_IMPLEMENTATION_BASELINE.md)。
