# Folio-J

Folio-J 是一个正在开发中的日语学习项目，希望能够帮助学习者围绕感兴趣的原版内容，把沉浸理解、知识积累与持续学习连接起来，并逐步形成可与外部工具和 AI agent 协作的个人学习环境。

> 当前从 EPUB 阅读切入，以本地单用户 Web 应用运行，需要从源码启动。阅读、翻译辅助、片段保存、AI 讨论与讲解回看已可使用，具体交互仍在打磨。

## 按来源组织材料与积累

在 Folio-J 中，我们主张用来源（Source）组织原版材料与围绕它们形成的学习积累。来源的范围由使用者声明，例如一部作品及其多卷内容；相关的学习片段、讨论和讲解也围绕这个来源逐渐积累。

在这一定位下，我们希望同一来源能够容纳书籍、漫画、有声书、视频等不同形式的材料，让学习积累可以按来源一起回顾，同时保留各自的具体出处。

当前已支持在同一来源下组织多份 EPUB 和手动添加的学习片段；其他媒体的接入仍属于后续方向。

## 从一本日文书开始

读一本小说时，遇到一句难以理解的话，可能需要查一些词，也可能想要干脆获得一条译文，甚至一份讲解。当前，你可以这样使用 Folio-J：

1. **导入并开始阅读。** 导入 EPUB 文件后，工具会编译出一份独立的资源包；阅读器支持目录、书内搜索、横竖排控制、注音配置与阅读进度记录与恢复等基本功能。*特别地，项目目前没有原生的即时查词能力，建议搭配 yomitan 使用*
2. **按需获得帮助。** 划选原文查看翻译；设备与浏览器支持时，也可以朗读所选内容。
3. **留下值得学习的片段。** 可以把原文自动连同前后文和出处保存下来，用以后续学习、整理与回顾。
4. **围绕难点深入讨论。** 打开学习片段，向内置原生教学 Agent 提问，也可以自行编写或粘贴 Markdown，保存为独立讲解。
5. **回到原文。** 从书中的片段标记回看已有译文与讲解，需要时再打开片段深入阅读。

![在 EPUB 原文旁查看已保存的译文与讲解](docs/handovers/text-study/evidence/inline-preview/compact.png)

*界面示例：点击已保存片段的标记，在原处查看译文与讲解。截图使用原创合成样书和人工讲解。*

可以只读书、临时翻译，或选择值得深入学习的片段。没有 EPUB 时，也可以从来源目录手动添加日文片段，编写讲解或展开讨论。

阅读、保存片段和人工维护讲解无需配置模型。翻译和 AI 讨论需要接入自己的模型服务；请求会发送到你配置的服务，并可能产生费用。

## 快速开始

准备 Python 3.11、Node.js 24、uv 和 pnpm 10。
下载或克隆仓库后，如果已安装 `just`，可以用以下命令完成上述步骤：
```sh
just setup   # 安装依赖
just start   # 初始化／升级数据库，构建并启动应用
```
否则，在仓库根目录运行：
```sh
# 安装锁定的后端与前端依赖
uv sync --project backend --locked
pnpm --dir frontend install --frozen-lockfile

# 初始化／升级数据库
uv run --directory backend alembic upgrade head

# 构建前端并启动应用
pnpm --dir frontend build
uv run --project backend python scripts/run.py start
```
启动完成后，打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。在终端按 `Ctrl-C` 停止服务。

首次打开后，在素材库选择已有来源或新建来源，再导入 EPUB。需要翻译或 AI 讨论时，先在「设置」中添加模型服务与模型。

默认数据保存在本机 `data/app.db`。已有数据的用户，更新代码并启动前请先阅读[升级与备份指南](docs/UPGRADING.md)。环境版本、热重载和开发命令见[开发指南](docs/DEVELOPMENT.md)；端口、数据路径与模型配置见[使用指南](docs/USAGE.md)。

## 演进方向

EPUB 阅读是当前的起点。长期希望沿以下方向发展，具体范围与实施顺序仍在探索：

- **扩展原版素材的范围。** 以文本及其语境、出处组织学习内容，逐步支持漫画、有声书、视频等素材，并保留各自适合的阅读或观看体验。
- **从理解延伸到持续学习。** 在讲解的基础上提取和关联知识，结合学习者的积累与素材内容，推荐值得进一步学习或复习的内容。
- **连接个人工具与 agent。** 支持学习内容的导入导出，与 Anki 等外部工具集成；让受信任的外部 agent 获取个人学习上下文，并在授权范围内操作。

项目动机与更多长期思考见[产品方向](docs/PRODUCT_DIRECTION.md)。

## 当前边界

- 目前可导入普通可重排 EPUB；知识提取与积累库、书内直接对话、其他媒体播放和主动复习尚未提供。
- 应用绑定本机 `127.0.0.1`，按单用户运行；同一数据库只运行一个后台实例。当前进程锁使用 macOS／Linux 机制，Windows 运行尚未验证。
- API 密钥保存在数据库旁的私有目录，以本机文件权限保护，尚未加密。备份时需要同时保管数据库与对应凭据目录。
- Safari、Firefox、实体触屏等环境的验证仍不完整。详细能力、验收范围和已知缺口见[实施基线](docs/handovers/MVP_IMPLEMENTATION_BASELINE.md)。
