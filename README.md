# Folio-J

Folio-J 是一个运行在本机的日语沉浸阅读与学习工具。

读一本日文书，遇到生词时，我们可以随时查词；遇到每个词都认识、连起来却读不懂的地方，也许看看翻译就够了，也许还需要找 AI 问得更深入一些。

Folio-J 希望把这些需求集中解决：将即时查词、语境翻译和 AI 问答放到阅读过程中，并且多走一步——帮你保存值得留下的片段、译文和讲解，在书中留下痕迹，再将这些学习资产整理起来、便于回看。

## 从一本日文书开始

1. **打开书，按习惯读。** 导入 EPUB，横排、竖排都能读，按章节细致记录阅读进度。除原书自带注音外，可以自动补齐振假名、按需查看。
2. **遇到生词，就地查。** 导入喜欢的 Yomitan (format 3) 词典并开启即时查词后，点击或按住 Shift 悬停即可查词。词卡里的生词，也能接着往下查。
3. **整句读不懂时，带着前后文看。** 划选原文后点「翻译」，即可获取结合语境的译文，并在原文留下标记。想听原句，也可以调用设备上的日语声音朗读。
4. **保存想再读的片段。** 保存时自动带入前后文和已有译文，核对后连同书中出处一起留下。打开片段还能继续向 AI 追问。
5. **给片段留一份讲解。** 手写或粘贴 Markdown 讲解，也可以与 AI 讨论、生成。点开书里的标记或「本章记录」，就能在原文旁查看。
6. **从全书词汇表回看原文。** 按词频排序展示全书词汇表，或用词形、读音筛选查找书中的词汇。

**无需配置模型，也能开始使用。** 阅读、查词、保存片段和手写讲解均可直接使用。如果习惯用外部 AI，点「复制讲解提示词」就能带走原文、前后文和学习偏好，拿到回答后再粘贴回来保存。

应用内翻译、讨论和生成讲解需要接入自己的 OpenAI 兼容模型服务。调用时，原文和本次所需的上下文会发往该服务，费用由服务商决定。操作与配置步骤见[使用指南](docs/USAGE.md)及其中的[模型设置](docs/USAGE.md#模型设置)。

## 用「来源」整理书与片段

「来源」是整理材料与学习片段的基本单位，可以是一套轻小说系列，也可以是任何你自定的专题。例如，把同一部作品的几卷放在同一个来源下，读到第三卷时，仍能从来源目录里轻松找回第一卷留下的片段，每个片段都保留着各自的书名、章节和原文位置。

手头只有一段日文时，也可以不导入书籍，直接在来源下手动添加片段，开始讨论或写讲解。

## 快速开始

Folio-J 目前从源码启动，供单人在本机浏览器中使用，支持导入普通可重排 EPUB。已在 macOS 上验证；Windows 11 x64 提供实验性支持，Linux 尚未完成验证。

**环境要求**：**Python 3.11**、**Node.js 24**、`uv` 和 `pnpm 10`（推荐同时安装 `just` 以简化命令）。

<details>
<summary>Windows 使用说明</summary>

使用 Windows PowerShell 5.1 或 PowerShell 7，以及 Chrome／Edge 浏览器；推荐 `just 1.58` 或更新版本。下方命令可直接在 PowerShell 中执行，无需安装 Bash。主目录 `~` 对应当前用户目录，例如 `C:/Users/你的用户名`。验证范围见 [Windows 实机测试清单](docs/handovers/WINDOWS_ACCEPTANCE.md)。

</details>

**关于数据位置**：

- **全新安装**：默认将数据库保存在 `~/Folio-J-Data/app.db`，日后更新或移动程序文件夹都不会影响这份数据。如需自定义数据库位置或端口，请在首次启动前参考[应用配置](docs/USAGE.md#应用配置)修改 `~/Folio-J-Data/app.toml`。
- **老用户升级**：如果此前已经保存过数据，升级前请先按[升级与备份](docs/UPGRADING.md)备份原数据库。

**安装与启动**：

克隆仓库后，若已安装 `just`，在仓库根目录依次运行：

```bash
# 1. 安装前后端依赖，并检查当前生效的数据库路径
just setup

# 2. 确认数据路径无误后，编译并启动应用
just start
```

如果调整过 `app.toml` 配置，可随时运行 `just data-path` 再次核对路径。

<details>
<summary>未安装 just 时的等价命令</summary>

在仓库根目录依次执行：

```bash
# 1. 安装依赖并查看数据库路径
uv sync --project backend --locked
pnpm --dir frontend install --frozen-lockfile
uv run --project backend python -m app.config

# 2. 确认路径无误后，迁移数据库、构建前端并启动服务
uv run --directory backend alembic upgrade head
pnpm --dir frontend build
uv run --project backend python scripts/run.py start
```

</details>

启动后终端会显示实际使用的数据库路径与访问地址。默认在浏览器打开 [http://127.0.0.1:8010](http://127.0.0.1:8010) 即可使用（若修改过端口则以终端显示为准）。在终端按 `Ctrl-C` 可停止服务。

## 项目方向

Folio-J 从 EPUB 阅读起步。后续我们希望让积累下来的片段和讲解能更好地用于知识点整理与复习，也计划让同一个「来源」能容纳漫画、有声书、视频等更多形式的原版材料。当前可用功能与已知限制见[实施基线](docs/handovers/MVP_IMPLEMENTATION_BASELINE.md)，长期设想见[产品方向](docs/PRODUCT_DIRECTION.md)。
