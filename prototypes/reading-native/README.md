## 预览

```sh
python3 -m http.server 8877 --bind 127.0.0.1 --directory prototypes
```

打开 http://127.0.0.1:8877/reading-native/ 。也可直接打开 `index.html`，但浏览器本地状态保存推荐使用 localhost。

## 本轮变化

- 原文／讲解、学习条目、对话是三个独立内容栏，桌面各自滚动；学习条目不再与讲解共用标签。
- 讲解区标签用于切换多份文档。右侧对话详情左上角返回摘要列表，再选择其他对话进入。
- 默认示例展示两份讲解和三条独立对话，包括等待审核的具体方案；列表展示摘要、草稿和状态。
- 工作台导航从完整侧栏缩为 56px 图标竖栏：顶部返回目录，中部阅读、文档、学习条目、讨论，底部设置与说明。图标有工具提示与可访问名称。
- 退出到示意目录页时使用 210px 完整导航；点击「继续阅读」重新进入工作台。退出不会清除文档、草稿和待审核方案。
- 合并重复标题、日期和来源信息，使用 54px 工具栏。移除常驻的方案切换条和设计说明页脚。
- 系统无衬线字体、中性灰与少量蓝色、细分隔线、分段选择控件、小尺寸工具栏按钮。保留正文层级与完整讲解，不依赖缩短正文营造紧凑感。
- 小于 1000px 保留 46px 图标栏，阅读、条目、讨论纵向排列；讨论入口会跳到讨论区。

## 可体验

- 左上角返回 → 目录中的继续阅读。
- 图标栏文档列表、讲解内部切换、独立展开或收起条目栏／对话栏。
- 对话详情中的返回 → 多对话摘要 → 选择一条进入；历史、草稿、参考对象、权限与待审核方案分别保留。
- 点击划线原文提问、保存专题讲解、准备修改方案、拒绝或批准。
- 右上角 `…`：切换「已有讲解／只有原文」、重置示例。

保存、回复和审核均是本地预写模拟。原型沿用早期以 TBD-14/15 标记的探索假设；这两个编号已不在现行 PRD 待定表中，不能据此推断产品决定。TBD-16/17 仍涉及执行契约与组合审核呈现；本轮目录页仅验证导航变化，不代表完整首页设计。

## 与现行 PRD 的边界

- 原型可准备「收录」方案，并通过审核或 Full access 使 Agent 模拟收录；现行 PRD F5/F9 规定 Agent 只创建待整理候选，收录、仅参考和退回待整理由用户直接操作，Full access 也不扩大工具范围。修改候选的审核通过只保存内容，不等于收录。
- 原型只在有待审核方案时禁用权限选择器，其他运行状态没有真实任务模拟；现行 PRD F9 规定线程仅在空闲时切换模式，本轮运行或等待审核时均不能切换，停止处理完成后才可更改。原型的即时回复与本地状态不能作为并发、停止或恢复实现依据。
- 原型中的「已有讲解／只有原文」是演示数据场景切换，不代表用户可在实际运行中切换任务模式。原型中的预写保存、审批成功提示也不证明后端写入成功或符合现行版本校验规则。

视觉布局、独立栏位、多对话导航和截图可作为施工参考；正式写入和运行行为以现行 PRD、GLOSSARY 与 ARCHITECTURE 为准。
