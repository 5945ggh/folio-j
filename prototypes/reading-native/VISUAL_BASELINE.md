# Folio-J 工作台视觉基线 · A.3

状态：在用户认可的 A.2 风格基础上，落实独立学习条目栏与多对话列表。作为后续正式产品的视觉和交互参考；此目录仍为静态原型，不是正式前后端实现。

## 已确定的方向

- 极简、现代、紧凑；系统字体、中性灰、细分隔线和少量蓝色。
- 进入片段后切换到专注工作台，外部目录的完整导航缩为图标竖栏；左上角返回目录。
- 讲解在左，对话在右。学习条目拥有独立栏，不占用讲解的切换位置。
- 讲解区域内部切换多份讲解；切换讲解不自动改变正在阅读的学习条目或对话。
- 右侧存在两级视图：对话摘要列表 → 某条对话。详情左上角返回列表，不退出工作台。

## 区域分工

| 区域 | 展示与操作 | 不随其他区域变化的状态 |
| --- | --- | --- |
| 图标竖栏 | 返回目录、阅读、文档入口、条目栏开关、对话列表、设置 | 工作台与外部目录的导航层级 |
| 顶部工具栏 | 片段标题、来源、保存反馈、条目／对话栏开关 | 当前片段 |
| 原文与讲解 | 目标原文、可选语境、文档标签、版本信息与完整讲解 | 选中文档及各文档的阅读位置 |
| 学习条目栏 | 当前片段的条目、原文定位、具体版本的讲解出处 | 展开状态、引用版本、滚动位置 |
| 对话详情 | 返回、标题、参考对象、历史、工具方案、输入、权限 | 本线程历史、草稿、权限与待审核方案 |
| 对话列表 | 标题、最近内容摘要、状态、最近查看提示、新建入口 | 每条对话独立保存，不合并其他对话历史 |

条目来源的完整 Section 在条目栏中直接可读，不能只剩简释和跳转链接。切换左侧讲解不会让条目自动引用新文档或最新版本。

## 视觉参数

这些数值是原型验证后的起点，可随正式组件实现微调。

| 项目 | 基线 |
| --- | --- |
| 桌面图标竖栏 | 56px；窄屏 46px |
| 顶部工具栏 | 54px |
| 1440px 视口下内容栏 | 讲解自适应，学习条目 272px，对话 344px |
| 宽屏 ≥1600px | 学习条目 310px，对话 380px，正文行宽有上限 |
| 较窄桌面 1000–1199px | 学习条目 250px，对话 300px，讲解至少 280px |
| 小于 1000px | 阅读、条目、对话纵向排列；保留图标竖栏及栏位开关 |
| 阅读正文／对话 | 13px / 12px；状态和辅助信息约 9–11px |
| 日文原文／讲解标题 | 约 18–21px / 19px |
| 正文色／辅助色 | `#252526` / `#838387`，次要信息降权 |
| 背景与分隔 | 白色正文、近白侧栏、`#e8e8e9` 分隔线 |
| 操作强调 | 低饱和蓝色；待审核使用克制的暖色状态点 |

每栏独立滚动。可单独收起学习条目或对话，释放的宽度交还讲解；不会因此删除学习内容或取消待审核方案。原型不引入任意拖拽分栏、无限新增栏位或复杂窗口管理。

## 对话返回与选择

1. 详情中的返回只切换右侧为列表，左侧文档和中间条目保持不动。
2. 列表行包含标题、两行摘要、状态和时间／最近查看提示；整行可点击。
3. 列表中的「有草稿」「等待审核」反映各自线程；返回列表或刷新不提交草稿，也不批准操作。
4. 选择已有对话，恢复该线程的历史、参考对象、权限及草稿。新建对话直接进入新的详情。
5. 选中原文提问会重新展开对话详情，并带入明确的参考对象；这不表示授权修改讲解。

原型摘要由预写内容或最后一条消息提供，不新增模型摘要调用。后台生成、失败、重试等状态仍按 PRD 后续实现；本轮没有运行真正的并发 AI 任务。

## 交付边界

- 默认已有内容场景：两份讲解、一条参考条目、三条独立对话，其中一条有具体待审核修改。
- 只有原文场景仍可直接讨论；不要求先生成完整解析。
- 文档保存、条目收录和审批沿用上一轮模拟；TBD-14/15 是旧版探索编号，现行 PRD 不再列为待定项。TBD-16/17 仍有执行与组合审核呈现的待定细节。原型中的 Agent 自动收录／审批收录与现行 PRD F5/F9 的用户直接整理边界不同，不作为正式行为依据。
- 线程自动命名、重命名／删除和后台恢复细节仍需设计；现行 PRD 已规定可主动停止、同线程运行／待审期间不接收新轮，且仅在线程空闲时切换权限。原型未实现这些运行约束。
- 此基线用于建立正式 UI 的组件层级、布局与交互约束，不替代 PRD、领域模型或后端契约。
