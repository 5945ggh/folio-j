# 阅读与导航

> 本文维护页面职责、路由、阅读导航及具体交互呈现参数。产品身份、原文保护、权限、保存与删除规则以[PRD](PRD.md)为准，交付状态与阶段验收见 [MVP 实施基线](handovers/MVP_IMPLEMENTATION_BASELINE.md)。

长期取舍、空间职责设想与开放问题见[产品方向讨论底稿](PRODUCT_DIRECTION.md)；本文记录当前界面约定，并单列已批准、待实施的入口目标。

## 当前界面职责与路由

| 路由 | 职责 |
| --- | --- |
| `/` | 替换式跳转 `/materials?type=book`，不新增首页 |
| `/materials?type=book` | 跨 Source 书籍网格、类型占位、添加书籍与组合工具栏 |
| `/materials/:id` | 独立连续阅读，返回来处／所属 Source／目录与搜索／图库／设置／状态 |
| `/materials/:id/details` | 书籍信息、统计与信息编辑入口，返回原目录条件／窗口；查看不计阅读打开 |
| `/materials/:id/vocabulary` | 材料词汇、词性筛选、词频排序、词形／读音搜索及出现位置；可前往原文并保留词表来处 |
| `/sources` | 普通进入记忆中的有效 Source，否则当前排序首项；无来源显示创建入口 |
| `/sources/:id?view=overview` | 来源概览，普通进入及主动选择来源默认 |
| `/sources/:id?view=materials` | 素材视图、实际类型预览及完整书籍窗口入口 |
| `/sources/:id?view=segments` | 片段目录、搜索及独立录入 |
| `/sources/:id?view=analyses` | 讲解聚合，直达所属 Segment 的确切修订 |
| `/sources/:id?view=materials&expanded=book` | 当前 Source 全部书籍的应用内模态窗口 |
| `/segments/:id` | 原文／讲解与按需讨论，既有目标参数保留 |
| `/settings` | 通用入口，打开首个分类「学习偏好」 |
| `/settings?section=models` | 模型与服务的模型配置 |
| `/settings?section=providers` | 模型服务列表与接入管理 |
| `/settings?section=learning` | AI 讲解偏好与保存片段时使用的前后文 |
| `/settings?section=appearance` | 当前浏览器的应用颜色模式，即选即生效 |
| `/settings?section=permissions` | 新对话默认权限 |
| `/settings?section=dictionary` | 导入与删除本机词典、查看已安装版本与记录数、选用阅读时使用的一本词典 |

| `/settings?section=speech` | 当前浏览器的设备朗读声音 |
| `/settings?section=history` | 验证记录，返回服务管理 |

参数名属施工默认；目录 URL 表达 q、source、status、sort、order、page。Source 列表与内容搜索独立，显式 URL 优先于本地偏好；列表位置可放 sessionStorage，不存完整书籍或密钥。正式书籍列表仅显示真实书籍，无假媒体入口；导入占位与临时成功入口按下述状态展示。卡片封面／标题直达阅读，状态菜单不触发主导航；素材库书卡不重复来源，所属 Source 与返回来处仍分别表达。声明封面缺失或失效时回退首张可用包内图片，无可用图片才占位；新封面结果解除旧失败状态。添加明确选现有／新 Source，导入失败不撤销已创建 Source，迟到结果不抢导航。

### 添加书籍与导入状态

添加书籍与新建来源在同一弹窗中切换完整视图，每个视图只显示一组操作，不改变页面 URL。新建视图隐藏文件选择与导入操作，进入时聚焦来源名称；“返回添加书籍”或 Escape 回到导入并聚焦来源选择，保留原有来源选择。创建成功先补入来源选项，再返回并选中新来源；切换视图保留同一个文件输入和已选文件。取消系统文件选择器或重选同一文件保留当前弹窗与已选文件。创建失败保留表单内容，创建提交中禁用字段、创建与返回操作，Escape 不离开；提交导入立即关闭弹窗并恢复目录中的有效焦点。未提交时关闭弹窗不承诺恢复本次文件与草稿。

提交后的导入状态由当前浏览器标签页内存承接，站内导航离开再返回继续显示。素材库与所属来源书籍网格显示去扩展名文件名的占位卡，带旋转准备提示且不可进入阅读或书籍管理；来源概览以紧凑书卡承接同样的准备、失败和重试状态。成功刷新真实列表，不抢导航；若结果不在当前筛选或分页中，在同一书籍网格中保留可点击的临时书卡。失败保留占位卡与错误，提供同一文件重试和移除失败提示；移除不撤销已创建来源。刷新或关闭页面后不承诺找回导入状态。

### 素材库与来源空间

主导航＋内容两栏，Source 二级列表留在独立来源空间。类型与工具在紧凑的同一顶部行：左侧书籍为唯一可选类型，漫画、有声书、视频为禁用占位，鼠标和键盘均不能切换；右侧展开搜索／筛选、合并排序依据与方向、卡片大小与添加，无额外大标题。未开放类型使用普通箭头光标，悬停即时显示“{类型名}支持会有的！”自定义提示。不设独立继续阅读区域，以最近打开排序配合位置恢复。生效条件可见可清除，图标有名称、悬停说明及键盘焦点。书卡以真实封面为主体，下方为书名，底部右侧为三点菜单；封面完整展示不拉伸，长标题可查看完整内容。不增加进度槽、常驻状态下拉框或重复来源名，封面／书名进入阅读，菜单不触发阅读。只有多页才显示完整分页。

素材库、来源列表及来源内容目录搜索保留独立输入草稿。输入法组合期间只更新输入框，不写入 URL 或发起中间查询；组合结束后以完整文本搜索，组合期间的 Escape 交给输入法处理。普通输入和清空即时生效，外部查询变化与路由切换同步重置草稿。

书卡菜单以紧凑行距提供书籍详情、编辑书籍信息、禁用的移动到其他来源，以及带当前状态的阅读状态二级入口，底部以分隔线隔开删除书籍。移动配“暂未开放”文字，不附底部延期说明。删除打开确认框，按 [PRD 4.2.1](PRD.md#421-本轮材料目录与阅读管理) 说明清理与保留范围及不可撤销性；首版不提供一并删除选项。取消或 Escape 返回原入口，提交中防重复和关闭，失败保留确认框并可重试；成功刷新目录与来源计数，回到有效页，并将焦点交还仍存在的目录入口。素材库与来源空间使用同一交互。阅读状态进入同一弹层的子菜单，提供未开始／进行中／已完成，返回入口、左箭头或 Escape 回父菜单，再次 Escape 关闭；方向键跳过不可执行项，操作不误触阅读。

书籍详情使用独立路由、公共中性外壳、紧凑返回栏与左对齐的封面／信息布局；显示书名、封面、所属来源、导入时间、阅读状态、最近打开及章节数量，保留阅读／编辑入口。缺少封面或解码失败时使用三斜线装帧占位，真实封面与原重试入口优先；不展示推算的本书学习成果。来处区分素材库、来源视图和全部书籍窗口，详情进入阅读后可返回详情，再回原来处；无有效来处回素材库。

卡片和详情共用编辑弹窗，编辑应用内书名、预览并选择静态 PNG／JPEG 自定义封面、恢复原书封面；不提供 EPUB 替换、来源编辑或移动表单。保存同次提交书名与封面意图，失败保留草稿；冲突保留草稿并允许重新读取当前信息，不以旧版本覆盖。取消／Escape 在有草稿时确认放弃，保存中不关闭或重复提交。保存后同步目录、详情和阅读书名／封面，保留目录条件与有效焦点。

成功数据确认整个库无书时，网格区域显示整片可点击的低对比虚线导入区，无内部按钮；隐藏顶部重复加号与相邻分隔线，有书后恢复加号。区域使用完整按钮语义，Tab 可聚焦，Enter／Space 开始既有导入；取消恢复区域焦点，完成后恢复有效入口焦点。有书但条件零结果显示清空／调整条件；加载、错误、当前页空列表均不足以证明真空库。未实现拖拽时只表达点击导入。

主导航使用“来源目录”；折叠入口可放品牌旁图标，不保留底部文字菜单。公共控件可复用，各页面保留独立布局组合空间。现有 URL、导入归属／迟到保护、状态版本、阅读返回及位置恢复契约继续生效。

应用公共外壳提供浅色／深色／跟随系统，默认跟随系统；浅色保留白底、灰蓝导航与蓝色操作色，素材库、来源、详情、设置、片段及加载／错误页共用。页面组合决定内容布局，视觉基线和颜色作用域见[设计系统](DESIGN_SYSTEM.md)。侧栏宽屏可展开／收窄（208／60px），图标保持名称和焦点提示；窄屏临时抽屉。Source 上下文列表只在 Source 空间，工作台合并重复全局导航，保留内容讨论控制。阅读器继续使用独立纸面主题。设置保留全部现有接入能力。

来源空间为主导航／来源列表／来源内容三栏；来源列表全高独立滚动，搜索、排序、新建集中于栏头。窄屏提供可达来源切换，全部来源可浏览，不以首个 API 页冒充全量。右侧紧凑名称、可选说明及来源信息／编辑／删除菜单，保留概览／素材／片段／讲解四视图。

四视图页签的选中底块以 180ms 平滑移动，当前视图显现时执行 150ms 纯淡入；搜索、分页和后台刷新不重播。减少动态效果时即时切换，内容切换沿用既有查询与滚动恢复。

概览与片段目录共用出处和添加时间展示：有精确材料出处时显示服务端核对的当前书名、章名及章内位置，手填出处作为补充；手动片段显示已填出处，空缺时显示“未保存出处”。材料删除或定位失效时保留可靠名称与状态，不沿用失效章名。出处各项在左侧紧凑连续排列，书名、章名与补充说明各自单行省略，书名优先收缩；章内位置及失效状态整块保留，悬停可查看完整出处。宽容器的添加时间独立靠右，条目元信息可用宽度不超过 600px 时，时间整块移到下一行；概览和片段目录共用规则。

片段目录每行保留讨论入口，三点菜单提供“删除片段…”。列表与片段详情共用删除确认：展示讲解（包含全部修订）、讨论、消息和进行中任务数量，说明来源、原材料及其他片段保留。提交前重新核对完整影响范围，变化后更新数量并要求再次确认；提交中防重复和关闭，失败保留并可重试。成功刷新目录、计数及阅读标记，末页为空时回有效页；列表焦点交还相邻片段或添加入口，详情删除后返回所属来源。讲解菜单的“删除此讲解”使用危险操作文字色。

宽屏来源栏可拖动或用方向键、Home／End 调整宽度，并保存本地偏好；默认 260px，范围 220–360px。搜索框按 Escape 收起并将焦点交回入口，收起后仍显示可清除的搜索条件。全空来源在概览集中展示添加片段与导入素材入口。

概览按 updated_at 降序预览 2 条讲解，按 created_at 降序预览 3 条片段，辅助预览 3 份所属素材及约 4 行已有备注，完整备注从来源信息查看；条数为展示参数，计数来自真实统计。讲解直达所属 Segment 的确切修订，素材直接进入真实阅读。概览素材“查看全部”进入当前来源素材视图，查询不继承完整列表旧搜索，失败／加载／空态分开；仅书、仅片段、无讲解、全空及零来源如实显示。

素材视图保留真实类型数量及有界样本。查看全部固定 Source 与类型，在素材背景上打开大型模态窗口；独立滚动，窄屏全屏。打开新增浏览器历史，筛选输入不逐字新增历史；后退先关闭窗口，刷新重建窗口。Escape／关闭回同一素材视图并恢复合理焦点；必须实现焦点约束和背景不可交互。

窗口打开书进入普通阅读页，返回恢复原窗口的条件、排序、页码、列表位置；站外直达窗口关闭安全回 Source 素材视图。旧 expanded=book 无 view 的直达按素材窗口理解。来处校验应用内路径，不任意跳转或无条件 browser.back；无来处材料回素材库，片段回 Source 列表，所属 Source 单独导航。

阅读工具紧凑按需展开；章内进度不等于完成。尺寸／侧栏／字号变化按稳定锚点恢复，不保存动画中间布局。状态刷新不重挂载 Reader，再开仍等待位置写队列排空并 fresh GET。

普通主导航与主动选源默认概览；显式视图与查询、同路径刷新、浏览器历史、阅读后的来处恢复优先，不能被偏好初始化覆盖。来源记忆只保存有效身份，不覆盖 URL。普通记忆失效可降级首项；显式来源失效显示不可用。当前来源被搜索隐藏或不在首批时按身份核实，不能静默切换；左右检索保持各自作用域。

### 书籍详情统计

`/materials/:id/details` 独立加载后端统计汇总，不挂载阅读器、不下载全书 token；书籍信息、统计的加载与失败分别呈现，统计失败可重试。没有可用分词代次时，字符／汉字统计仍可展示，词法部分明确“尚未准备”；读取统计不隐式分词，也不更新阅读状态、最近打开或位置。统计不作为阅读或既有注音准备的前置条件。

当前统计在页面可见时每 30 秒检查，重新进入或窗口重新获得焦点时更新；新分词代次准备成功后使当前统计查询失效。不提供常驻刷新按钮，错误状态保留重试。详情提供“查看词汇”入口，词汇页与详情共用当前代次观察。

范围说明使用“当前材料版本的全部可提取正文”，包括目录和后记；同 resource_id 的重复 spine 只计一次，不合并不同资源中的相同文字，不称作小说正文。词次／词种注明固定分词配置和词典形口径，保留助词、助动词，过滤空白、标点和零跨度记录；字符数采用 NFC 正文码点数，含空白与标点。曲线横轴为“本书最高频的前 k 种词”，纵轴为“词次覆盖率”，不表达理解率或学习者掌握率；空分母显示“—”，曲线为空。计算规则和输入身份由后端维护，显示结果绑定确切版本与代次，迟到结果不替换新目标。

### 材料词汇页

`/materials/:id/vocabulary` 使用公共外壳，顶部保留书名和返回书籍详情入口。宽屏并排呈现词汇列表与所选词的出现位置；视口宽度不超过 760px 时，选择词汇进入出现位置视图，再返回词表。词汇每页 40 项，出现位置每页 10 项；加载、失败、未准备、分析后无有效词次和筛选无结果分别表达。

查询参数 `q`、`pos`、`sort`、`page`、`word`、`occurrencePage` 保存搜索、一级词性、词频方向、词表页、所选词和出现页。默认词频降序，同频按归并键稳定排序。更改搜索、词性或排序后回第一页并清除所选词；切换词表页清除选择，选择另一个词后从第一出现页开始。词性选项来自该代次全部有效词次，筛选后保持稳定。搜索和频次口径见 [PRD](PRD.md#421-本轮材料目录与阅读管理)。

词汇行展示归并键、实际读音／词性和频次；变体过多时明确为部分样本。出现项显示章节、原文及前后文，“查看原文”才进入阅读器。没有合法呈现位置时保留原文与次数，并标明无法定位。词典释义后续接入。

原文入口携带临时精确目标，核对材料、版本、章节、spine、资源摘要、码点范围和原文快照后定位并复用临时高亮。目标失效时显示失败，不能退回普通阅读恢复冒充定位成功。阅读器顶部返回词汇页，保留完整查询状态；词汇页再返回书籍详情时继续保留此前目录来处。普通词汇查询不写阅读状态或位置，明确进入阅读后沿用现有阅读规则。

### 设置顶部分类

设置复用公共主导航，内容区使用紧凑页头与学习偏好／模型与服务／外观／对话与权限／词典／翻译／设备朗读七个顶部分类。模型与服务内以“模型配置／服务管理”切换用途选择与服务接入；验证记录通过服务管理入口进入。

词典分类独立载入已安装词典，列出名称、版本、记录数和当前选项。第一次导入自动选中，后续导入保留原选择。单选保存成功后才更新「使用中」，失败可重试。空列表以图标、说明、导入按钮和格式提示组成一个留白充分的区域，不显示「已安装词典 0」；有安装项时在列表标题旁提供导入入口。词典行的「更多」提供删除，确认框说明删除本机安装且可重新导入。删除当前词典且还有其他项时，须明确选择替代词典；删除最后一本时说明即时查词将暂不可用。提交期间防止重复操作，失败保留确认框和选择供重试，成功后更新列表与阅读器状态。从阅读器进入时提供返回原书的入口。

外观分类直接显示应用颜色模式，浅色／深色／跟随系统即选即生效，无独立保存按钮，不等待服务端设置或 Provider 列表。选择保存在当前浏览器，保存失败时显示已生效但未保存的状态；应用外观与阅读器纸面设置分别提供入口。

学习偏好按保存范围分为「AI 讲解偏好」和「保存学习片段」。前者包含学习背景与默认讲解预设，使用场景和学习情况示例按需展开。后者直接显示「自动带上前后文」开关，并按前文、后文分列句数与字符上限。预设与开关选中即保存，文字和数字在离开输入框时保存。设置页自动保存成功提示在约 2.5 秒后消失，开始新的修改或保存时清除上一条成功提示；保存中、未保存和失败状态持续显示，失败保留输入并提供重试。分类专用链接直达对应页面，刷新和浏览器后退沿用网址中的分类。

模型配置页按用途选择默认模型，选中即保存，无可选模型时提供服务管理入口。服务管理页承载服务列表与全局验证历史，服务或模型分别保存。新对话默认权限选中即保存，无独立保存按钮，保存失败保留选择并提供重试。条目整理尚未开放，界面说明阶段边界，保留已有提取模型存储值。无可选模型、设置加载失败与服务列表加载失败分别呈现。

服务列表显示名称、协议、已登记模型与文本验证摘要，详情承载模型管理、连接设置和对应服务的验证记录。模型页列出已登记模型、启停状态和普通／流式验证结果。通过「登记模型」进入列表选择或手动填写，手动登记的协议及参数收在高级设置中。批量登记部分成功时保留失败项供重试。有草稿时，切换方式需确认放弃当前输入。模型行的「更多」提供编辑参数、启停和删除入口。连接信息与访问密钥分别编辑并显式保存，启停开关独立即时生效。删除服务时确认影响范围。

验证记录按模型、验证类型、结果和具体时间展示，全局历史另列服务名。服务端按服务、登记模型身份及状态筛选后分页，窄屏可展开筛选和移除条件。服务尚无记录时可返回模型列表；筛选无匹配时可清除条件。展开记录先显示模型回复或失败、中断原因，协议、提示词版本和用量收在调用详情中。

模型选项同时显示 Provider 名称和模型 ID。模型行用图标与文字分别显示“未验证／验证中／可用／验证失败／中断”，提供原因与对应记录入口，状态基于当前配置；刷新可继续查看运行状态。模型行的“可用性验证”菜单提供普通文本、流式文本和两项重新验证，各入口说明调用次数：单项 1 次，组合 2 次。结构化输出标明尚未开放验证，列表获取、文本验证与其他能力分别表达，不用一个“连接正常”概括全部能力。

新增和编辑使用一致的模态表单。页面表单与弹窗各自保存；学习背景与默认预设同次提交原子保存，其他分组只更新自身字段。未保存修改在顶部分类或模型子页切换、站内离开和浏览器历史导航前提示，可继续编辑、放弃或保存后离开；刷新和关闭使用浏览器原生提醒。保存失败保留草稿，保存中不允许取消已提交请求，后续编辑重新标为未保存。草稿和密钥不写入浏览器持久存储。

### 阅读器 R1.1

#### 阅读外观与工具显隐

Reader 不渲染主导航，也不修改应用原有侧栏偏好；加载、错误及不可用材料仍有可靠返回或重试。顶部保留返回、书名／章名与低频书籍信息，底部保留章内进度、临时返回点、上一章／目录／下一章导航组与工具；窄屏进度移至顶部章名旁，显隐不改变正文宽高或留白。

书卡保留按压反馈，阅读正文稳定呈现后执行 240ms 轻淡入，标题独立上移 8px；保留会话再次显示时可重播。书籍与章节的加载文案延后 150ms 显示，就绪即移除，错误与返回入口即时可用。减少动态效果时关闭入场动画，保留加载提示防闪延迟。

目录、书签与书内搜索共用左任务面板和页签，切换保留查询；设置和插图库在右侧，阅读工具面板均非模态，不圈定 Tab 焦点或禁用正文。正文延伸至页面底部，不为阅读工具预留固定底部区域；侧栏保留完整圆角和 12px 侧／底边距，左导航与右工具独立共存。导航上方的书名、阅读信息和页签固定，仅各页签内容滚动；宽屏章内进度置于紧凑浮动工具栏内部，工具栏外的空白不截获点击。目录为工具栏的列表导航入口，可切换书签或搜索页签；“添加当前位置书签”是独立快捷动作；任一页签打开时再次点击目录关闭整个导航面板，其他工具同键关闭、同侧异键切换，关闭或完成定位只收起发起操作的一侧。窄屏保留两侧状态，最近使用的一侧显示在前，工具按钮切回被遮住的一侧先恢复其内容。图片查看器独立覆盖阅读器，不受工具面板尺寸或滚动裁切；打开时背景虚化并压暗，图片居中，背景暂停交互。

Escape 先关闭最上层。正文点击图片直接打开查看器，不隐式打开图库，一次关闭回到原阅读位置；从插图库打开则关闭回图库，保留图库页码与滚动位置。查看器内约束焦点，支持关闭按钮、Escape 和点击背景空白处关闭，并恢复合理焦点。窄屏控件与面板可滚动，隐藏工具不能进入 Tab 顺序。图标工具有悬浮／键盘焦点名称提示，专注提示显示当前开启／关闭状态；专注偏好与当前工具显隐分开，普通单击、实际鼠标移动与 Tab 可唤出工具，静置隐藏不破坏选区、拖动、控件或已打开面板。失败、冲突及无法恢复的反馈始终可见。书籍信息分别标明书名、所属来源、阅读状态与阅读位置保存状态；导入提示说明格式与兼容性处理。历史交互依据见[交互优化](handovers/archived/reader-r1/INTERACTION_POLISH.md)。

纸面提供白／黑／跟随系统，不反色图片；此处的跟随系统直接响应系统颜色模式，与应用外观选择独立。顶部标题栏与底部工具栏共用随纸面变化的半透明背景和轻微模糊，文字与图标保持清晰。工具栏不透明度滑块范围 0–100%、步长 5%、默认 80%；0% 完全透明，100% 不透明。调整即时生效，恢复阅读界面默认值时重置，不改变正文几何布局。

横排正文从顶部标题栏后滚过，章首保留起始间距，章末提供可滚动留白，使最后一行能完整移到工具栏上方。横排容器覆盖屏幕，上留白为桌面 82px／窄屏 78px，下留白为 80px 加安全区，首尾留白随正文滚动，标题栏背景模糊为 3px；竖排每列按相同上下间距限定可读区域。工具显隐不改变这些空间或位置采样边缘，排版留白不计正文长度。正文两侧留白支持滚轮／触摸板滚动，面板独立滚动；竖排纵向手势沿阅读轴推进。适用阅读方向的方向键、PageUp／PageDown 和空格平滑滚动，遵循减少动态效果偏好；位置恢复仍即时执行。

#### 阅读设置分组与会话

底部“阅读设置”打开右侧非模态面板，按下表依次组织；浮窗不透明度另在即时查词设置中提供同值快捷入口。常用项直接展示，其他控件与帮助独立展开，展开一组不收起其他组。低频内容隐藏时不进入 Tab 顺序。布局、控件与留白延续现有 Reader 风格，颜色使用阅读语义变量。

| 用途组 | 直接展示 | 展开内容 | 恢复默认范围 |
| --- | --- | --- | --- |
| 排版 | 字号、横排／竖排 | 更多排版：行距、字体、正文宽度 | 字号、方向、行距、字体、宽度 |
| 注音 | 显示／按需／隐藏，原书／全量范围 | 注音使用说明 | 范围、显示方式 |
| 阅读界面 | 白／黑／跟随系统纸面 | 工具栏不透明度、浮窗背景不透明度、展示阅读记录下划线、展示阅读记录页边入口；工具与记录说明 | 纸面、工具栏与浮窗不透明度、两种记录显示 |
| 带上下文复制 | 默认收起，显示已保存配置摘要 | 前后句数、出处；字符上限与格式示例分别展开；保存、放弃 | 五项复制草稿，保存后生效 |

各组标题旁提供“重置”按钮，悬停说明恢复范围；复制重置只改草稿。专注阅读仅由底部工具栏控制，面板不包含此开关，阅读界面重置也保留其选择。

作用范围以细边框小标签紧接组名显示，重置按钮靠右，不再另占说明行。标签使用“这本书”“这本书 · 此浏览器”“所有书籍 · 此浏览器”等短语，版本限制收进悬停说明。文字方向、字体、注音显示／范围及纸面名称在选项按钮上方；字段名称与选项统一使用 13px，组名为 14px，辅助说明与范围标签为 11px，均沿用界面字体。

前三组即时呈现，并沿用各自保存方式；没有面板级保存全部或跨组总恢复。排版／注音调整沿用原文位置恢复及注音准备规则。竖排下正文宽度禁用但保留值，摘要说明仅用于横排。分组恢复只合并本组字段，不用旧整对象覆盖其他组的新值，也不重置阅读进度或删除资料。

| 设置范围 | 保存位置与适用对象 | 面板表达 |
| --- | --- | --- |
| 字号、行距、方向 | 数据库阅读位置；本书，保留材料版本校验 | 排版组名旁“这本书” |
| 字体、正文宽度 | 当前浏览器；本书版本 | 字段名称旁“仅此浏览器” |
| 注音范围及显示 | 当前浏览器；本书版本 | 注音组名旁“这本书 · 此浏览器” |
| 纸面、专注、工具栏与浮窗不透明度、记录下划线及页边入口 | 当前浏览器；所有书籍 | 阅读界面组名旁“所有书籍 · 此浏览器” |
| 复制五项配置 | 数据库个人默认值；连接同一后端的全部书籍与浏览器 | 复制组名旁“所有书籍”，展开后说明资料库共用及保存后生效 |

同一组内不同范围就近标明。即时呈现不等于持久保存成功；浏览器写入失败保留当前呈现并反馈，数据库排版仍沿用位置保存状态。首次阅读及恢复默认的字号／行距为 22／2.4，已有书籍沿用保存的设置；后端缺省参数用途不变，合法旧值不按控件范围裁减。本轮不改变存储契约。

折叠状态与面板滚动位置属于当前材料的 Reader 路由会话：关闭设置、切换右侧工具或切章后保留，换书从初始收起状态开始。复制编辑状态由阅读会话持有，表单折叠或卸载不丢弃草稿；原始数字输入包括空值保持为输入，不自动替换为零。草稿不写入浏览器持久存储。

复制摘要始终使用已保存配置，任一侧句数或字符上限为零时显示不附带该侧；格式示例使用有效草稿。未保存、保存中、输入错误、读取／保存失败与冲突在复制组收起后仍可见，阅读设置入口提供简短状态。注音准备与失败同样不藏入折叠内容。

离开当前 Reader 路由或换书前，有复制草稿提供保存后离开、放弃并离开、继续编辑；进入片段页也受保护，正文保活不改变此边界。保存中导航先等待同一请求结论，失败保留页面及草稿；继续编辑取消此次导航，不撤销已提交请求。刷新或关闭标签页使用原生离开提醒，不承诺离页后恢复。具体失败与冲突操作见下方复制规则，当前实现与验收范围见[实施基线](handovers/MVP_IMPLEMENTATION_BASELINE.md)。

#### 跳转链与返回点

返回来处恢复素材库的筛选／排序／页码／列表位置，或来源概览、素材视图和 expanded=book 窗口；无有效内部来处回素材库。相邻切章、目录、书签、搜索结果与图库明确前往共用一个会话原点，连续查阅不覆盖它，实际新位置继续持久化；图库浏览／放大／切图／关闭不导航。例如 A→B→C 后返回 A；在 B 继续阅读到 B′ 后，返回 A 的入口仍保留，下一次跳到 C 时才将原点更新为 B′。

继续阅读信号采用以下交互判定：页面在前台且有焦点，主动净前进至少一个阅读视口，首末移动相隔至少 5 秒。单纯停留、短时查阅、工具面板滚动及排版恢复不计；后台或重排中断尚未确认的信号，已确认信号保留到下一次实际跳转。判定仅管理临时返回点，不标记已读或学习完成，也不改变独立的章节位置保存。历史依据见[跳转链与继续阅读](handovers/archived/reader-r1/INTERACTION_POLISH.md#2026-10-16-跳转链与继续阅读)。

返回按钮悬停与键盘焦点提示为 `返回“章节名 xx%”`，使用建立返回点时的章内进度并四舍五入为整数，无法计算时只显示章名。实际返回定位成功后清除原点，后续跳转再建立新原点。返回按当前排版恢复，不恢复旧设置；身份或 DOM 位置无法核验时明确失败并保留返回点供重试，不猜测同句位置。刷新或离开后不承诺保留临时原点，内容身份与引用校验仍由 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)规定。

#### 位置书签

工具栏“添加当前位置书签”只在正文稳定呈现时可用，捕获点击时的原文或图片位置。成功提示紧凑排列，摘要最多一行并省略溢出，“添加备注”复用阅读器蓝色强调色；不自动打开表单或抢焦点，约 8 秒后淡出，悬停或焦点停留时暂停。附近已有书签时使用同一提示容器，显示“附近已有书签”和已有摘要，提供“查看已有”“仍然添加”；此时尚未创建书签。继续添加沿用首次位置，关闭或提示消失即放弃本次添加，再次点击工具栏可采样新位置。错误和在途状态保留，失败沿用首次请求及是否继续添加的选择重试。点击添加备注才打开左侧书签页及对应详情的备注编辑态；查看已有只打开详情，不导航原文。学习片段的页边入口改用资料图标，与位置书签区分。

左侧书内导航按“目录／书签／搜索”组织。书签按章节、part 和资源内位置有界分页，以右上角 20px 圆角、其余直角的独立卡片排列。卡片使用细边框与低对比底色，顶部低强调显示章节和“章内约 N%”，无法派生进度时省略百分比；摘要最多两行，备注最多一行并以短侧线区分。图片摘要为空时显示图片位置。除快捷操作外，整张卡片及留白均可打开详情；左下危险色删除图标直接打开删除确认，右下入口跳转原文，操作不会顺带打开详情。详情对应卡片以蓝色边框、淡底色与左侧线保持选中强调，关闭详情后清除，键盘焦点独立显示。

详情依次展示章节与章内进度、添加时间（本地年月日与时分）、原文摘录、备注。原文使用低对比引用面，备注编辑入口收在分组标题右侧；空备注使用低强调提示。顶部标题与底部操作保持可达，仅中间内容滚动；底部左侧为危险色删除，右侧为蓝色前往原文。宽屏在导航侧方展开，窄屏限制在视口内，不被列表滚动区域裁切。关闭详情、关闭面板、切换页签或跳转不静默丢弃当前会话的备注草稿。列表与详情共用应用内删除确认，列出简短出处及备注删除范围，取消为初始焦点；删除失败或版本冲突保留反馈，显式重载后才升级确认版本。取消后回到触发入口，删除成功后焦点回到仍存在的书签列表。用户可编辑、清空备注，保存失败及版本冲突保留草稿，重新读取后供核对。跳转仅收起发起操作的左侧面板，复用当前排版与临时返回点；定位失败保留反馈。

保留范围与删除规则见 [PRD 4.9](PRD.md#49-阅读摘录书签与记录检索)，摘要预算、身份及接口见[位置书签实现](ARCHITECTURE.md#315-位置书签)。

#### 书内搜索与图库

书内搜索使用去首尾空白、NFC 后的全书原文字面查询，不搜索注音、OCR 或 UI 合成章名；支持重复／重叠命中和同资源连续 part，不跨原资源或章边界。显示真实总数，每批 40 条，条目显示章节与纯文本上下文，点击按确切版本／章／part／资源与码点范围定位并高亮。图库按真实图片出现顺序有界分页，同图多次出现分别展示，缩略图与大图按需加载；浏览、缩放及切图不改正文位置。

正文与图库共用图片查看器。默认完整适合窗口，支持放大、缩小、恢复适合窗口及放大后拖动，触屏支持双指缩放；上一张／下一张按书中出现顺序切换，切图重置为适合窗口。查看器提供“复制图片”和“下载原图”：复制用于粘贴图片，下载保留原始格式；复制失败明确反馈，不以复制链接替代成功。查看器中的“在图库中查看”切换到当前图片出现项所在页并突出该项；“前往书中位置”才移动正文并进入正常定位链路。

无图、无命中、加载与失败各自表达，失败保留查询并提供重试。材料统计放在书籍详情，不进入阅读工具。只读查询与阅读状态的边界见 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)，页面、浏览器和扩展兼容性以[实施基线](handovers/MVP_IMPLEMENTATION_BASELINE.md)链接的实际验收记录为准。

#### 注音与正文复制

全量注音使用持久分词结果：首次进入旧书先准备，成功后恢复阅读，失败可重试。阅读设置提供原书／全量范围和展示／按需／隐藏方式，不放重新生成入口；默认原书展示，偏好逐材料版本保存。全量补充未被原书 ruby 覆盖的汉字，按需可悬浮、轻点、选区或正文 R 键查看。字号、行距、宽度、字体、方向与注音范围调整在当前阅读内容中重排并恢复原文锚点，不先展示章首；全量数据尚未就绪时保留当前范围与画面，请求成功后再应用，失败可重试。显示／隐藏保持排版空间；后台状态与内部词典信息不进入日常阅读流程。

复制使用所选原文纯文本，保留编译正文的换行与空白，排除原书和自动注音的 rt／rp；不改变选区或注音显示。注音生成、覆盖保护及引用身份仍由 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)维护。

选区工具栏另提供“带上下文复制”，点击使用已保存的独立偏好同步组装文本并复制；设置未成功读取时提示并提供重试。阅读设置中的同名分组维护五项草稿，点击“保存复制设置”才写入数据库并生效。保存失败及冲突保留草稿；冲突后必须重新读取最新版本，可保留修改再次提交整组配置，也可使用服务器设置，不宣称字段级合并。重新读取失败保留草稿。“放弃修改”恢复已知最新服务器配置；恢复复制默认值仅改草稿。

成功复制显示短提示，剪贴板失败显示完整只读文本和“选择文本”入口；反馈不替换原生选区。变更选区、切章和暂离阅读清理旧复制结果反馈；复制配置草稿按上方会话规则保留。窄屏工具栏允许换行。

#### 后续搜索扩展

扩展搜索继续共用左侧书内导航，命中学习资料或书签时定位并打开对应内容；当前书签呈现见上方“位置书签”，首版不增加页边书签。产品范围见 [PRD 4.9](PRD.md#49-阅读摘录书签与记录检索)，实施顺序见[计划](handovers/reading-practice/PLAN.md)，交付状态见实施基线。

#### 章节位置与进度显示

材料普通打开恢复全书最后的逻辑章和内容位置；目录选择其他章恢复该章上次位置，无记录则到章首，选择当前章保持位置并关闭目录。目录顶部提供当前章“回到章首”，将会话返回点更新为操作前的位置；已在章首时重复操作保留原返回点，不清空其他章记录。搜索、插图定位成功也更新章节位置，预取、失败跳转及恢复中的临时位置不更新。历史依据见[章节位置记忆](handovers/archived/epub-reading/CHAPTER_MEMORY_ACCEPTANCE.md)。

底部上一章／目录／下一章沿用阅读器章序，横竖排一致。相邻章有记录时恢复，无记录到章首；首末边界禁用对应按钮，不循环。切章从请求开始到稳定呈现前禁用相邻按钮，失败保留原章并允许重试；未呈现位置不写入记录。工具栏切章保留左右面板与搜索，目录点击仍关闭左面板；新的明确导航或工具切换使旧请求失效。窄屏进度移到顶部章名旁，相邻按钮提示含目标章名；章末入口暂不增加，方向键仍用于正文滚动。历史依据见[底部相邻章节导航](handovers/archived/reader-r1/INTERACTION_POLISH.md#2026-10-16-底部相邻章节导航)。

目录条目右侧以低强调整数百分比显示上次章内位置，无记录留空。当前阅读页与目录共用以下显示口径：

- 未到章末时按稳定正文位置计算，图片处取图片前已有正文比例，最高 99%。
- 最后一行文字或最后一张图片末端进入稳定视口可读区时显示 100%，不要求滚过底部留白或空白片段；一屏完整呈现的短章同样显示 100%。
- 纯图片章到末尾显示 100%，此前目录显示“有记录”，阅读工具栏显示“章内 —”。
- 章末状态与原文字／图片恢复锚点一起保存，不将锚点替换成最后一个字符。重开、刷新或跳回章末时呈现当前排版末屏；回看离开末尾后重新计算，字号、方向或窗口变化先恢复锚点再按稳定视口判断。

100% 仅表示当前位置到章末，不表示累计已读，也不自动改变材料阅读状态；总阅读进度仍后置。历史依据见[章末进度与真实书复核](handovers/archived/epub-reading/CHAPTER_MEMORY_ACCEPTANCE.md#2026-10-16-真实书复核与口径调整)。资源身份、fragment、位置版本与章归属由服务校验，重排后的附近恢复与精确引用校验保持独立。材料自身或所属来源删除后的可读与位置保存边界遵循 [PRD](PRD.md)。

## 讲解浏览、人工保存与按需讨论

`/segments/:id` 是片段阅读与讲解页，Workbench 仅是其中按需展开的讨论区域。片段正文、工具栏与讨论背景沿用公共外壳的颜色变量；EPUB 阅读器保留独立纸面主题。

片段页使用专用三栏布局：左侧约 56px 窄工具栏、中央阅读区、右侧按需讨论。进入片段页隐藏全局主导航，不改写全局侧栏偏好；窄屏工具栏转为顶部紧凑操作栏，讨论展开时占满内容区，阅读 DOM 与滚动位置保留，隐藏阅读区退出键盘和辅助技术的操作范围。关闭讨论将焦点交回开关。

工具栏顶部负责返回明确来处，中部负责讨论显隐，底部菜单负责片段资料编辑与删除。中央顶部以“所属来源：来源名 →”链接直达来源首页，长名称可省略，箭头保持可见；不影响工具栏返回时恢复来处。精确出处独立呈现服务端核对的材料名与章名，长名称视觉省略并保留完整标题；“在原文中定位”跳转确切目标，与返回来处分别表达。材料不可用时保留可靠名称与定位状态，片段内容仍可阅读。手动片段无需精确出处。资料浮层挂载或后台刷新重新核对出处时，保留已有出处文字与布局，核对完成前暂不可定位；首次加载显示等待，失败或失效提供反馈。

内容卡片集中显示目标原文、已保存前后文和当前译文。前后文只显示内容，辅助技术保留范围名称；分别预览最接近目标的两行，预览合并空白、提高对比度；完整资料保留保存时的文本。目标原文预览最多四行，无语境不占空行。卡片内朗读入口只播放目标原文，沿用声音设置、错误反馈与播放条。播放条悬浮在阅读栏底部，正文保留滚动空间；窄屏讨论展开后播放条仍可操作，讨论输入区按播放条实际高度避让。正文可选择，独立的“查看完整原文与资料”按钮打开资料浮层；关闭恢复当前可见入口和阅读位置。片段页浅色的普通按钮、链接与焦点采用黑白灰，深色按语义颜色适配；删除、错误与警告保留语义色。

原文卡底部右侧的独立“复制分享”图标打开居中略偏上的模态浮层，背景压暗并轻微模糊，中部为可滚动、可选中文本的只读预览。底部只有一个主复制按钮，旁侧下拉切换默认“复制原文与出处”、“仅原文”和“仅出处”，按钮文案与预览同步；切换不写入剪贴板。默认模式按已保存前文、目标原文、后文排列，有语境时用引用块区分目标，保留原有文字和换行；末尾附可靠材料名、核对后的章名及手填出处，无材料名时回退来源名。出处省去字段标签和章内百分比，空字段省略；仅原文保持目标文本原样。内容范围、隐私和失败反馈遵循 [PRD F2](PRD.md#f2-source-与片段)。浮层打开时背景不可操作，键盘焦点限制在浮层内；支持外部点击和 Escape 关闭、关闭后恢复入口焦点；窄屏切到讨论时收起。分享组件在页面加载时订阅同一出处核对查询，打开或重开分享不另触发核对；必要后台核对不显示加载说明，预览区域保持固定高度。失效时只保留可靠材料名；需要回退来源名时，含出处复制等待来源首次读取，已有可靠材料名则无需等待来源。“仅原文”始终可用，读取失败明确反馈并可重试或复制现有内容。

当前译文直接读取 Segment.translation，可为人工填写或采用后修改的文字，不要求等于任一关联结果。关联翻译记录在同一卡片内独立展开，保留当次译文、语境和模型；回看不生成、不采用、不改写当前值。当前译文为空但有关联记录时仍可查阅；两者均为空时不保留空翻译区域，读取失败提供重试且不隐藏已有当前译文。资料编辑继续通过既有入口维护译文，采用行为沿用 PRD 4.8。

资料查看与编辑沿用“原文与语境、译文与听写、出处与备注”三组顺序，组内依次为前文／目标原文／后文、译文／听写、只读精确出处／自由文本出处／个人管理备注。阅读隐藏空字段与空组；编辑保留全部输入，前后文可独立展开，已有内容默认展开。固定原文显示为可选择、可滚动的只读文字，不占用禁用输入框；译文、听写、前后文和文字出处会进入新任务的模型输入，个人管理备注只用于管理。资料浮层和编辑均显示服务端核对的精确出处，编辑中的出处只读且不提供离开草稿的跳转。入口统一为“查看完整原文与资料”和“编辑片段资料”。

编辑只提交本次改动字段；冲突后保留草稿，重新读取完整当前资料供核对，读取成功并明确确认后才允许重试。未修改字段保留其他操作的新值；当前资料读取失败时仍可查看草稿并重试读取。

讨论面板使用单行标题栏，返回对话列表与收起面板分别使用导航箭头和无箭头的分栏面板图标，提供名称与悬停提示；新建对话使用加号，保留名称与悬停提示；第一条消息形成的标题只用于列表查找，详情不重复堆叠。可展开的“参考原文与前后文”读取当前已保存资料，并说明新任务与历史输入快照的区别。用户消息右对齐、淡色气泡、最大宽度约 85%；助手回复使用透明背景和内容区全宽。角色名称保留在辅助技术语义中，回复的复制操作在悬停／键盘焦点时显示，触屏常显；已有成果继续提供确切讲解入口。

输入区以多行问题和发送按钮为主，只保留模型、审核模式两个设置按钮。打开后直接列出可选项，当前项有勾选标记，单击选项即切换并收起；模型列表底部保留生成方式。浮层互斥，不改变输入区或消息区高度，支持 Escape 与外部点击关闭。临时要求直接写入聊天消息，新请求沿用设置中的默认讲解预设；不提供独立的本轮要求或预设覆盖入口。恢复旧失败任务时，将原问题与旧补充要求一起放进可见聊天框；已受理请求仍按冻结内容核实，不改写历史快照。资料编辑不常驻原文固定规则或模型输入用途的说明段落；模型不可用、配置读取失败、提交不确定、运行及待审核状态继续提供原因与操作。返回列表或收起讨论保留本页草稿与运行协调，不等同于停止。本轮未接入单条回复直接保存讲解、讨论主视图或自动概括标题，相关输入范围与写入权限仍由 PRD 规定。

讲解集合负责列表、新建及其 AI 生成选项；单篇文档负责全文编辑、重命名、版本信息与删除。新建只出现在讲解列表，以一个“＋ 新建讲解”菜单提供“编写或粘贴讲解”“创建 AI 讲解”和“复制讲解提示词”；打开菜单不创建内容。“创建 AI 讲解”每次新建普通对话，发送明确请求创建并保存独立讲解的预定问题。Agent填写完整正文并通过工具保存，成果可从讲解列表打开，聊天可只报告结果；普通提问默认只回复。具体讲解的标题行左侧提供返回列表图标，右侧保留当前文档操作，不再单独显示集合工具栏。加载、失败或跨片段无效详情仍提供返回入口。标题使用较小字号，长标题与版本状态按可用宽度换行。当前版本可编辑，历史版本在标题旁标明只读并提供“回到当前版本”；“版本信息”展示讲解标题、讲解 ID、所读修订与当前修订。新建菜单支持键盘导航、Escape 关闭和外部点击；快捷入口在模型或预定问题未就绪时提供明确反馈，重复触发各自拥有独立的线程身份。取消人工新建回到菜单入口，新建保存成功并打开确切修订后聚焦文档返回入口；编辑已有讲解沿用编辑入口的焦点恢复。目录默认折叠，只显示章节标题，减少头部留白并以一条底线衔接正文；正文的首个简单总标题与讲解名称一致时可承接页面标题，重复标题与空前言不占额外阅读空间；重命名后页头使用新名称，原正文标题保留在正文，原始 Markdown 和 Section 锚点保持完整。重命名位于“更多操作”，当前或历史阅读均可修改讲解名称；弹窗预填名称，保存失败保留草稿，关闭恢复菜单入口焦点。左侧讨论开关始终使用对话气泡图标，展开状态和操作名称随显隐更新；右侧讨论栏保留独立的收起图标。讨论开关只更新显隐，保留当前线程与讲解选择；列表返回恢复本次列表滚动位置。

选择“复制讲解提示词”直接复制当前片段的完整提问，成功就地提示；读取失败可重试，剪贴板不可用时可手动选择全文。复制不展开讨论。

普通提问与站内讲解生成在助手消息中显示同一行反馈：文字说明已观察到的活动，旁边显示从请求受理到当前或结束的耗时。阶段变化可被读屏识别，计时不逐秒播报。非流式回复在收到模型结果前保留等待状态；已保存讲解使用实际成果入口。

普通原文／讲解回看、确切修订直达及人工编辑不启动工作台，不查询模型设置、讨论或任务。显式展开讨论、未显式收起的线程直达或「创建 AI 讲解」才激活讨论；URL 中 chat=0 优先于 thread，首次进入保持纯回看；激活后在同一 Segment 页面内保活，收起与返回讨论列表保留草稿、待核实提交、审核补充要求及协调器状态。同片段参数变化不重挂整个页面，切换 Segment 隔离状态；离页后的草稿持久化不扩张。

Segment 讲解区提供新建入口，直接输入或粘贴 Markdown；表单只提供可选标题与正文，统一记录为用户保存；保存无需模型配置，成功后打开确切修订，不创建讨论线程或模型任务。首版不做批量文件导入、URL 抓取或富文本编辑。当前修订可全文编辑，旧修订只读；提交携带基础修订，冲突、空白、超限或保存失败保留草稿，不覆盖新版本。取消有未保存修改时确认放弃，路由离开和关闭页面保留现有草稿提醒；不承诺关闭页面后恢复人工草稿。编辑器固定打开时的原文摘要和基础修订，后台刷新不替换编辑依据；冲突保留草稿并刷新相关读取，重新打开最新版本后再编辑。片段后台读取失败时页面改为错误状态，已打开的编辑器保持挂载；已删除资料不继续显示，只保留本次编辑草稿供复制。

首次持久讲解保存会固定目标原文，提交前显示提示；打开、取消或失败保存不固定。前端不提交未变化正文；服务端无变化校验不产生空修订或成功凭据。响应不确定时固定本次完整请求并禁用编辑，重复提交同一请求核实；成功打开返回的确切修订。明确失败后保留草稿，不覆盖后来保存的成果。人工入口继续沿用讲解归属、确切修订、来源返回和删除门禁，不改变讨论权限。

### 定位与返回

片段路径保持`/segments/:id`。查询参数表达当前阅读和讨论目标：

| 参数 | 含义 |
| --- | --- |
| `analysis` | 明确打开的讲解；缺省展示讲解列表 |
| `revision` | 在该讲解内打开确切修订；缺省当前版本，不能脱离`analysis`独立使用 |
| `thread` | 明确打开的讨论；缺省讨论列表 |
| `chat` | `1`展开讨论，`0`收起；未指定时由是否存在`thread`决定 |

阅读选择和讨论选择可以同时存在。打开成果写入讲解与确切修订；切换讲解或返回列表时清除旧修订。刷新只读取已有内容，不重发生成或审核请求。浏览器历史中的目标变化不会将同片段页面重新挂载。

本页发起的讨论有了明确保存的成果后，只有当前讲解与确切修订仍与首次提交时一致，才自动打开成果；用户已选择其他阅读位置时保留该选择，仍可从成果入口手动打开。丢响应后的核实或同请求重试沿用首次提交的阅读位置。相关验收见[架构重构记录](handovers/archived/ARCHITECTURE_REFACTOR_ACCEPTANCE.md)。

指定讲解与讨论必须属于当前片段；不能因它不在已加载的首批列表中就认定无效，也不能把另一片段的内容配在当前原文下。无效目标显示错误并提供回到当前片段列表的入口。

**返回来处**与**所属来源**是两种导航：前者使用应用内入口记录的路径和名称，后者始终前往片段所属的Source。站外打开或没有有效来处时，前者明确显示“来源目录”。查询参数更新保留来处记录，不使用无条件浏览器后退跳出应用。

当前选中讲解只表达阅读位置；“展开讨论”不自动授权修改，也不声称将这份讲解注入模型上下文。讨论继续遵守当前片段范围与明确目标规则。

## 学习衔接

材料选区与精确出处往返按 C1／C2 接入；交付状态与验证范围见[实施基线](handovers/MVP_IMPLEMENTATION_BASELINE.md)。

### 选区与资料往返

首版选区使用单个 chapter part iframe 内的原生选择，支持跨 DOM 节点；跨 iframe 拖选、跨章和追加不连续选区不在范围。选中只保留临时状态，不调用模型；点击“保存为学习片段”后捕获此次选区快照，准备草稿并确认原文和来源，最终提交成功才创建片段和固定原文。Reader 内新建片段统一走此入口，来源等其他手动创建入口保留。后端出处与回读支持同一逻辑章内的有序多资源范围，严格校验与规范化身份见[PRD 4.7](PRD.md#47-当前-epub-阶段安排)和[架构](ARCHITECTURE.md)。

已有片段仅按确切出处提供有界候选，由用户显式选用并保留其语境；不按相同文字自动合并，候选失效不静默新建替代。新建时预装整理过边缘空白和连续空行的有界前后文，按整理后码点计预算并说明自动摘录，显示目标与简短预览，完整语境可展开修改或清空；可直接保存。语境可同章跨 part，目标仍为确切选区。

创建或选用成功后关闭草稿并留在原文，顶部显示紧凑、可关闭的一行提示，“打开片段”按钮复用阅读工具的柔和强调色，配色约定见[设计系统](DESIGN_SYSTEM.md#阅读器的强调色与标记)。提示停留 12 秒；悬停或键盘焦点停留时暂停，离开后重新计时。明确打开后进入既有片段／讲解路由，可保存人工讲解或显式启动讨论，不扩大 Agent 的资料读取范围。

#### 即时查词

底部书形按钮打开「即时查词」。浮层显示当前词典，「管理词典」前往设置页。可以选择关闭、点击查词或 Shift 悬浮，方式保存在当前浏览器。触屏在两种开启方式下均用轻点。点击模式由基字接收查词手势，已有划线继续呈现。词卡的「此处记录」打开原处资料。查词与按需注音、工具显隐各自消费一次手势。长按、划选与复制沿用原生操作，明确的选区可从操作条查词。

桌面上的每一张子卡从点击字形或选区附近展开。优先利用父卡旁和上、下方的空间，避开刚点过的文字与已打开词卡的标题。各层留在原位，必要时可部分重叠。窄屏将当前卡放在父卡下方，父卡露出词头及标出所查词的日文片段，可点回父层。各层分别保留候选与滚动位置。拖动卡头可在可视区域内移动该卡；窄屏拖动整组，保留父子错层。点击日文释义或例句进入下一层；在 Shift 悬浮模式下，按住 Shift 指向卡内日文也可继续查，松键保留已开的词卡。标为中文的译文支持选择、复制。同一原文起止范围内的词条按匹配顺序分列，保留各自词头、读音与释义。新卡获得键盘焦点，点击其他卡头可转移焦点。卡头按钮或聚焦卡内的 ← / → 切换范围并更新高亮，翻页保留卡片顶边与手动位置。词卡、紧凑片段、紧凑翻译及聚合列表共用“浮窗背景不透明度”，范围 20%–100%，默认 72%，沿用已保存的词卡值并在当前浏览器跨书保存。阅读界面与即时查词设置中的两个滑杆即时同步；仅纸面底色参与混色，保留 9px 背景模糊和完整文字、图标、焦点提示。展开的完整阅读侧栏使用实底，收起恢复偏好；工具栏不透明度独立。返回箭头或 Escape 逐层退回，关闭按钮收起整组。词卡可与阅读设置或插图库同时打开。开关或切换这两个面板保留词卡栈、页码和滚动位置。重叠时，最近打开或点选的一方显示在前。Escape 先处理前面的一层，图片查看器打开时优先退出查看器。正文滚动、切章和退出阅读清理临时词卡。

#### 片段标记与页边入口

“保存为学习片段”位于原生选区浮动工具栏，完成选择后出现；支持 Tab 进入与 Escape 关闭，保留原生划选和复制。已存片段以低强调细下划线表示，竖排沿文字旁侧，注音不加线。普通轻点可见标记的基字打开已有资料，启用点击查词时改由词卡的「此处记录」进入，单片段直接预览，多个确切命中先选择；修饰键、拖动、长按划选、键盘扩选及复制保留。轻点标记不同时切换工具栏或按需注音；双击不增加等待，首击可能先显示预览，形成选区后以选择为先。

页边使用扁平小符号或聚合数字，至少 44px 命中区域只放正文外真实留白；竖排优先底部，无空间时使用本章列表，不挤压正文。入口固定在目标首处原文，随正文滚动，排版变化重新定位，滚动不切换锚点或临时合并入口。页边的片段图标和“译”分别直达该片段或该处译文。若还有原文范围相连重叠的记录，标题左侧提供“返回此处记录”，回到当前类型的列表并聚焦该条。数字表示合在该页边按钮上的记录数，点击后打开这些记录及其重叠记录的列表。按钮内全为翻译时先显示“翻译”，包含学习片段时先显示“学习片段”。再点同一页边按钮收起，点其他按钮按新入口打开。聚合候选与完整本章列表显示原文摘要和精确到分钟的保存时间，不显示 ID 后缀或额外选择提示，完整 ID 位于保存信息。全部分页读取完成后才开放完整列表和标记；本章列表始终提供集中入口，加载与失败分别反馈。

#### 原处预览与记录浮窗

预览默认紧凑横排。仅有一个候选时，标题直接显示“学习片段”或“翻译”；多个候选保留“此处记录”。仅有一种记录类型时省略整行类型标签，同时有两类记录时显示带数量的类型切换，展开后沿用这一规则。从学习片段列表进入详情时，标题左侧出现返回箭头，焦点移到箭头。点击箭头回到列表并聚焦原条目。从正文直达或页边仅有一条且无关联记录时省略箭头。查看具体片段时，底部保存信息右侧提供蓝色的“打开片段 →”文字入口，与顶部“展开”区分。“本章记录”的片段与翻译详情都在原文引用旁提供“定位原文”，点击后回到书中对应文字。“此处记录”从正文或页边打开，两类详情均省去这项操作。内容区依次显示原文引用、译文、讲解、备注与保存信息。片段原文采用约 18px 日文阅读字体，长原文可展开；该片段自己的当前译文紧接原文，以细引线和轻底色组织，不随同处阅读翻译更新。没有译文则直接读讲解，两者都没有时仅保留短原文与保存信息。单篇讲解直接展示篇名，多篇以当前篇名作为选择入口，默认选择及加载更多行为保持。预览取真实正文开头，保留段落和有意义的排版；有译文时约露三四行，无译文时给予更多空间。备注低强调，保存信息在底部默认折叠，不另加分隔线。

“本章记录”中的讲解完整展示、内容区独立滚动，标题栏右侧提供关闭按钮。“此处记录”多篇讲解选择入口旁标“讲解预览”，仅实际截断时显示底部渐隐。“展开”进入右侧覆盖式完整阅读侧栏，正文不重排、目标不随滚动变化；“收起”回到紧凑预览，保留当前目标、类型标签、所选片段／讲解和临时手动位置，叉号完全关闭。目录与侧栏共存，同侧设置或图库替换侧栏，窄屏遵循前侧规则。普通标记只打开预览，“打开片段”才离开阅读器，携带当前讲解及确切修订，返回仍用片段精确出处。

横排正文中只对应单一翻译目标、不含学习片段的划线，普通轻点在完整原段之后展开最新成功译文；短选区不拆原段，跨段目标在最后一段后显示。一次只展开一处，再点同处收起，点击另一处切换，正文滚动保留。译文字号略小、低强调，不附记录工具栏；开合保持原文位置，淡入淡出遵循减少动态效果偏好。页边入口仍开完整浮窗；竖排、重叠多目标或无法安全插入的作者版式回退浮卡。译文不加入原文定位或保存，可独立复制，混合复制只提取原文。

正文划线预览贴近实际点击的行／列，横排优先下方、上方回退，竖排优先侧方；页边预览以所点按钮为锚点，左右页边优先向外侧留白展开，不足时向正文侧展开，竖排底部入口优先向上。窄屏统一底部浮卡，以原文强调对应目标。

宽屏记录浮窗可拖动标题栏，按钮与内容区保留操作；标题栏聚焦后可用方向键移动。拖动后停驻屏幕，背景点击、正文划选和滚动保留，其他标记在同一浮窗切换内容并沿用位置。关闭或切章清除手动位置，下次跟随入口；窗口和内容尺寸变化约束位置，确保标题和关闭可达。窄屏底部卡与展开侧栏不拖动；同一处不重复显示段尾译文和浮窗，已停驻时点击正文标记也在浮窗切换内容。

同时只保留一个预览。正文空白与两侧页边普通轻点清除原生选区及选区工具栏，收起未停驻的紧凑预览，本次不再切换阅读工具栏；新划选、拖动、长按、修饰键及控件操作保留。未停驻浮卡在卡外普通轻点、原文划选或正文滚动时收起，固定本章列表与展开侧栏保持，卡内独立滚动。候选指向／聚焦临时强调原文，选中后持续强调全部出处范围。切章、失效或删除清理旧目标，重排重算标记与入口，草稿切换保护遵循 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)。

#### 阅读会话往返

同一标签页从阅读器进入片段页时，短期保留最近一本书的正文与 iframe。返回先核验材料可用性、内容版本和阅读状态，再复用正文并刷新片段、译文与讲解；`?segment=` 仍按片段出处定位。暂停时隐藏阅读器，禁用输入、布局采样和延迟位置保存，完成已有位置写入。打开另一材料、离开片段往返范围、暂离超过十分钟或刷新后释放；不可用或版本不一致不展示旧正文。持久位置、引用和删除边界继续遵循 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)。

#### 语境、出处与定位反馈

阅读记录下划线与页边入口在[阅读设置的“阅读界面”组](#阅读设置分组与会话)分别控制，统一适用于学习片段和翻译，默认开启，当前浏览器内跨书、刷新与标签页同步。两项都隐藏时，本章记录仍可访问。保存提示不抢焦点，悬停或焦点停留期间不自动关闭。

学习偏好的「保存学习片段」组独立保存前后文设置，提供预装开关、前后句数及字符上限；默认值与计数规则由 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)维护。本次草稿可临时调整，临时调整不改写默认设置；修改预算不立即重填，重新按预算取文是明确操作，保留已修改内容供用户决定替换。修改或清空的字段不被首次预填、迟到结果、设置变化或重开覆盖，选用已有片段也不触发语境更新。本次流程内收起再展开保留草稿，取消或离页后的草稿持久化不扩张。

取文失败保留目标与草稿，允许重试、手动填写或仅保存目标；出处校验失败仍拒绝保存。切换目标、取消或离页使旧结果失效。界面标明语境截断，用户改写后不继续标为逐字原书引用；用户手动输入沿用现有长度限制，不按自动预算裁剪。划选、预装、编辑及保存不调用模型。

片段资料与编辑入口共用只读精确出处展示，分别显示服务端核对的材料名与章名，具体呈现见[讲解浏览、人工保存与按需讨论](#讲解浏览人工保存与按需讨论)；不可定位时保留原状态及可靠材料名，缺失部分不补造。source_ref 独立保留，有精确出处时显示为“出处补充”，否则为“出处说明”。

带出处的片段提供“返回原文”，深链接按 Segment 身份解析，不在 URL 放全文。返回原处与书内搜索共用临时定位高亮：精确目标稳定呈现约 2.5 秒后，以约 260ms 淡出并清理，背景与文字颜色同步恢复。正文主动输入、轻点／划选提前开始淡出，新导航、切章或离页立即清理，减少动态效果时直接消失。重排不续期、不重新变亮或复活，不清除永久学习／翻译标记，下划线关闭仍可定位。阅读器完成现有注音准备并验证同章全部目标范围后，从第一段范围起点定位；部分范围无法投影时明确定位不完整。等待、准备失败和重试保留此次目标，不能因普通阅读恢复丢弃它。定位失败不保存未呈现目标、不提前消费临时返回点；来处导航、会话返回点与位置保存分别沿用现有规则。版本或快照失配保留可见资料的历史文字并说明无法定位，已删除资料遵守不可见门禁。

### 阅读翻译与设备朗读

本节维护翻译与设备朗读的交互呈现，产品规则及原始方案入口见 [PRD 4.8](PRD.md#48-阅读翻译与设备朗读)，交付与验证以实施基线为准。选区工具条提供翻译、设备朗读及保存；普通选择保持原生行为，不自动调用模型。

#### 翻译卡片与历史回看

翻译以不重排正文的覆盖卡呈现，与已有学习资料预览互斥，同一时刻只有一个当前内容卡。首屏突出短原文引用、译文和主要动作；原文按实际显示长度折叠，生成信息、本次语境和历史按需展开。横排优先放在选区上下，竖排优先放在侧边；正文滚动或重排使原屏幕位置失效后，卡片停靠右侧。窄屏卡片放在底部并避让朗读控制；卡片内部可滚动，关闭入口保留在顶部。加载、失败、停止和关闭分别表达，关闭不取消已受理任务；当前目标不随滚动、新选区或迟到响应漂移。

已有译文时，译文下方依次提供“朗读原文”“重新翻译”，右侧“更多翻译操作”收纳“清除此处全部翻译”。朗读与重播用喇叭图标和对应文字，暂停、继续或停止按实际播放状态显示。重译用刷新图标。实际目标语言随该版译文的生成信息收在“语境与设置”中。生成进度和停止入口在任务运行时可见。重译时保留旧译文，完整新结果读取后才替换展示，失败或停止仍可读旧文。“上一版／返回新版”只切换查看一对已保存结果，其余历史从完整列表读取，不触发模型调用。宽屏可拖动标题栏及键盘移动，窄屏保持底部停靠。

紧凑译文浮窗以轻量“翻译”标题、较小日文原文和约 20–22px 的正常字重译文组织首屏，两者左对齐。隐藏“语境与设置”“历史译文”及历史分页，展开后显示；“本章记录”的完整详情直接提供这些入口。收起再展开保留语境草稿、当前历史选择与折叠状态。朗读、重译、更多操作、版本快捷切换和任务反馈在紧凑模式继续可用。

译文从正文标记、本章记录或原处再次划选进入；底部工具栏不再提供“最近翻译”。确切目标的详情保留分页历史和任务状态，旧结果说明实际语言、模型和语境，重译是明确动作。本章记录和划选翻译详情去除“保存为学习片段”“另存新片段”及独立采用表单，保留已关联片段的打开入口。正文划选保存草稿新增可编辑／清空译文，按 [PRD 4.8](PRD.md#48-阅读翻译与设备朗读) 的确切匹配规则，优先使用本 Reader 会话最近在翻译详情选中的匹配成功结果，否则取最新匹配成功结果；只预填一次完整译文，修改、清空或开始提交后拒绝迟到覆盖。语境继续独立预装，不套用翻译历史语境；选用已有片段不覆盖其译文或语境。新建成功留在阅读器并提供打开片段入口，Segment 中可找回关联结果，普通回看不发起模型调用。

#### 本章记录与翻译标记

右上角“本章记录”提供“学习片段｜翻译”标签页，翻译按正文位置排列，相同确切出处只显示原文与最新有效成功译文，不显示语言、已留存或译文份数，候选显示原文、最新译文与真实保存时间；历史仍可回看。正文中翻译用低强调红色虚线，片段用实线；竖排沿文字旁侧绘制，注音不加线。重叠部分不叠线，点击相连重叠记录共用“此处记录”面板，两类均有内容时通过“学习片段 N”“翻译 N 处”切换，分别按片段数和确切出处数计数；归并不改变底层身份。新译文完成后刷新标记，回看或切换标签不发起生成，切换标签保留各自选择与草稿。

纯翻译命中直接展示最新成功译文。从翻译列表进入详情时，焦点移到标题左侧的返回箭头。箭头或 Escape 回到列表并聚焦对应条目。页边单条入口按上述关联范围提供返回，无列表可返回时 Escape 关闭浮卡。声音不可用或朗读失败时，操作行下方显示提示，并提供声音设置入口。历史列表只显示生成时间、语言和译文，原句集中于顶部详情。

译文详情的更多菜单和本章列表都提供“清除此处全部翻译”，确认框明确清除该确切出处的全部阅读译文历史和正文翻译划线、停止进行中的重译，并保留已另存的片段及关联快照。菜单取消或 Escape 返回始终存在的更多触发器；确认框取消也恢复到该触发器。失败保留确认框和原记录，可重试。成功后关闭该处已展开的行内译文或划选浮卡，更新列表与标记；同处片段实线保留。原提交尚未核实时禁用删除，并说明须先核实。

#### 朗读条与声音浮层

设置分别提供默认翻译配置和设备朗读。翻译分类分为「阅读翻译」和「前后文范围」。目标语言和前后文范围在离开输入框时保存，选择模型立即保存。前文、后文的句数和字符上限直接显示，宽屏并排，窄屏上下排列。其他页面同时修改时保留草稿，核对差异后可采用已保存设置或确认写入自己的修改；设备声音选择和语速保存在当前浏览器，设置变化不覆盖进行中的翻译或保存草稿，输入默认值及任务快照由 [PRD 4.8](PRD.md#48-阅读翻译与设备朗读)维护。

朗读条采用一个圆角容器，播放图标、原文摘要、以短竖线分隔的语速／声音区和关闭图标不重复描边。设备支持时，朗读中可暂停、暂停后继续；未开始或不支持暂停时保留停止。结束或停止后提供重播，整体不自动收缩；设备暂停若实际结束朗读，按真实终态提供重播。关闭同时停止，关闭译文卡后播放控制仍可找到；离开阅读或片段页面停止并清理目标。

声音浮层优先在设置区上方展开并右对齐，突出原生声音选择、当前匹配声音、0.5–1.5 倍速滑块（0.1 步进）、常用预设及恢复默认；重新检测位于“更多选项”。外部点击、Escape 或再次点击入口关闭，保留键盘焦点反馈；完整错误在浮层查看，条上保留简短提示。偏好更改后短暂提示，下次播放或重播生效，继续不重建当前朗读；完整设置页提供日语试听，无可用声音或错误准确反馈。不展示音频已保存、逐词跟读或尚未接入的远端 fallback。

## 后续方向与未决事项

未来空间等待使用反馈。Source 可有多份 EPUB，手动 Segment 无需虚构材料；本轮集中材料目录限于已接入 EPUB，不扩展通用媒体框架。

按来源回顾学习、跨来源检索积累和主动学习活动具有不同职责；这不要求现在建立全部一级导航。独立Segment概览、独立Analysis页面、最终空间命名继续开放，按实际阅读与查找需求再决定。
