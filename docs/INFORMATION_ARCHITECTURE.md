# 阅读与导航

> 2026-10-03：已有片段阅读与导航基础上，补充当前 EPUB 切片 1 的界面契约；新增阅读入口实施中，验收状态见[EPUB 阶段入口](handovers/epub-reading/README.md)。历史片段导航验收见[阅读导航验收记录](handovers/archived/READING_NAVIGATION_ACCEPTANCE.md)。产品行为以[PRD](PRD.md)为准。

长期取舍、空间职责设想与开放问题见[产品方向讨论底稿](PRODUCT_DIRECTION.md)；本文继续记录当前界面的具体约定。

## 当前界面职责

- **来源目录**位于`/sources`，按来源找到片段并录入新片段。来源是用户声明的来源范围，不等同于应用首页或具体素材文件。
- **来源详情的阅读材料**列出该来源的 EPUB，并提供导入入口；成功导入或命中重复材料后直接进入阅读。手动学习片段仍是并列可用入口，不要求先导书。
- **材料阅读页**位于 `/materials/:id`，以目录组织连续图文，提供明确返回来源的入口。主要界面用于阅读，目录、横竖排及字号／行距设置保持克制；展示章内进度及保存状态。切片 0 的 JSON／自检／样书选择 UI 不进入正式界面。
- **片段页面**同时承载原文、已保存讲解与讨论入口。普通打开先阅读；原文与讲解可以对照，不再通过互斥标签选择其一。不增加进入阅读前必须经过的独立概览页。
- **讲解列表**展示标题与标明为正文摘录的内容。用户明确选择后打开文档，不自动选中第一份。指定讲解、修订的链接直接打开相应内容。
- **讨论区域**按需展开，指定讨论入口直接打开该线程。展开或收起不代表创建线程、开始或停止任务。当前片段内返回讨论列表、收起栏位时保留草稿、待核实请求和当前挂载线程的审核补充要求；切换页面或刷新不承诺恢复未提交草稿。
- **设置**提供学习偏好、模型接入与调用诊断。导航保持克制，不为未实现的素材库、积累库或学习中心展示空入口。

`/`目前替换式跳转至`/sources`，保留未来Home的位置。暂不制造仪表盘或空白中转页，也不承诺“最近活动”或学习统计。

## 定位与返回

片段路径保持`/segments/:id`。查询参数表达当前阅读和讨论目标：

| 参数 | 含义 |
| --- | --- |
| `analysis` | 明确打开的讲解；缺省展示讲解列表 |
| `revision` | 在该讲解内打开确切修订；缺省当前版本，不能脱离`analysis`独立使用 |
| `thread` | 明确打开的讨论；缺省讨论列表 |
| `chat` | `1`展开讨论，`0`收起；未指定时由是否存在`thread`决定 |

阅读选择和讨论选择可以同时存在。打开成果写入讲解与确切修订；切换讲解或返回列表时清除旧修订。刷新只读取已有内容，不重发生成或审核请求。浏览器历史中的目标变化不会将同片段页面重新挂载。

本页发起的讨论或快捷生成有了已保存成果后，只有当前讲解与确切修订仍与首次提交时一致，才自动打开成果；用户已选择其他阅读位置时保留该选择，仍可从成果入口手动打开。丢响应后的核实或同请求重试沿用首次提交的阅读位置。相关验收见[架构重构记录](handovers/archived/ARCHITECTURE_REFACTOR_ACCEPTANCE.md)。

指定讲解与讨论必须属于当前片段；不能因它不在已加载的首批列表中就认定无效，也不能把另一片段的内容配在当前原文下。无效目标显示错误并提供回到当前片段列表的入口。

**返回来处**与**所属来源**是两种导航：前者使用应用内入口记录的路径和名称，后者始终前往片段所属的Source。站外打开或没有有效来处时，前者明确显示“来源目录”。查询参数更新保留来处记录，不使用无条件浏览器后退跳出应用。

当前选中讲解只表达阅读位置；“展开讨论”不自动授权修改，也不声称将这份讲解注入模型上下文。讨论继续遵守当前片段范围与明确目标规则。

## 后续方向与未决事项

Home可作为恢复学习等快捷功能入口，但具体内容等待使用反馈。Source 可有多份 EPUB 材料，手动 Segment 无需虚构材料；当前按 EPUB 切片 1 接入导入与阅读，不额外建设通用素材库。

材料普通打开恢复最后的逻辑章和内容位置；用户选目录后进入对应章。资源身份、fragment、位置版本与章归属由服务校验，不能把其他材料的位置套到当前书。重排后的阅读恢复允许附近定位，精确引用校验保持独立。来源删除后材料读取与进度保存均不可用；切片 1 无独立材料移除入口。

按来源回顾学习、跨来源检索积累和主动学习活动具有不同职责；这不要求现在建立全部一级导航。独立Segment概览、独立Analysis页面、侧栏形态及最终空间命名继续开放，按实际阅读与查找需求再决定。
