# 阅读与导航

> 本文维护页面职责、路由、阅读导航及具体交互呈现参数。产品身份、原文保护、权限、保存与删除规则以[PRD](PRD.md)为准，交付状态与阶段验收见 [MVP 实施基线](handovers/MVP_IMPLEMENTATION_BASELINE.md)。

长期取舍、空间职责设想与开放问题见[产品方向讨论底稿](PRODUCT_DIRECTION.md)；本文记录当前界面约定，并单列已批准、待实施的入口目标。

## 当前界面职责与路由

| 路由 | 职责 |
| --- | --- |
| `/` | 替换式跳转 `/materials?type=book`，不新增首页 |
| `/materials?type=book` | 跨 Source 书籍网格、类型占位、添加书籍与组合工具栏 |
| `/materials/:id` | 独立连续阅读，返回来处／所属 Source／目录与搜索／图库／设置／状态 |
| `/materials/:id/details` | 书籍信息、统计与信息编辑入口，返回原目录条件／窗口；查看不计阅读打开 |
| `/sources` | 普通进入记忆中的有效 Source，否则当前排序首项；无来源显示创建入口 |
| `/sources/:id?view=overview` | 来源概览，普通进入及主动选择来源默认 |
| `/sources/:id?view=materials` | 素材视图、实际类型预览及完整书籍窗口入口 |
| `/sources/:id?view=segments` | 片段目录、搜索及独立录入 |
| `/sources/:id?view=analyses` | 讲解聚合，直达所属 Segment 的确切修订 |
| `/sources/:id?view=materials&expanded=book` | 当前 Source 全部书籍的应用内模态窗口 |
| `/segments/:id` | 原文／讲解与按需讨论，既有目标参数保留 |
| `/settings` | 模型与服务：用途默认模型、服务列表与接入管理 |
| `/settings?section=learning` | 学习背景、讲解预设与默认选择 |
| `/settings?section=permissions` | 新对话默认权限 |
| `/settings?section=history` | 验证记录，返回模型与服务 |

参数名属施工默认；目录 URL 表达 q、source、status、sort、order、page。Source 列表与内容搜索独立，显式 URL 优先于本地偏好；列表位置可放 sessionStorage，不存完整书籍或密钥。正式书籍列表仅显示真实书籍，无假媒体入口；导入占位与临时成功入口按下述状态展示。卡片封面／标题直达阅读，状态菜单不触发主导航；素材库书卡不重复来源，所属 Source 与返回来处仍分别表达。声明封面缺失或失效时回退首张可用包内图片，无可用图片才占位；新封面结果解除旧失败状态。添加明确选现有／新 Source，导入失败不撤销已创建 Source，迟到结果不抢导航。

### 添加书籍与导入状态

添加书籍与新建来源在同一弹窗中切换完整视图，每个视图只显示一组操作，不改变页面 URL。新建视图隐藏文件选择与导入操作，进入时聚焦来源名称；“返回添加书籍”或 Escape 回到导入并聚焦来源选择，保留原有来源选择。创建成功先补入来源选项，再返回并选中新来源；切换视图保留同一个文件输入和已选文件。取消系统文件选择器或重选同一文件保留当前弹窗与已选文件。创建失败保留表单内容，创建提交中禁用字段、创建与返回操作，Escape 不离开；提交导入立即关闭弹窗并恢复目录中的有效焦点。未提交时关闭弹窗不承诺恢复本次文件与草稿。

提交后的导入状态由当前浏览器标签页内存承接，站内导航离开再返回继续显示。素材库与所属来源书籍网格显示去扩展名文件名的占位卡，带旋转准备提示且不可进入阅读或书籍管理；来源概览以紧凑书卡承接同样的准备、失败和重试状态。成功刷新真实列表，不抢导航；若结果不在当前筛选或分页中，在同一书籍网格中保留可点击的临时书卡。失败保留占位卡与错误，提供同一文件重试和移除失败提示；移除不撤销已创建来源。刷新或关闭页面后不承诺找回导入状态。

### 素材库与来源空间

主导航＋内容两栏，Source 二级列表留在独立来源空间。类型与工具在紧凑的同一顶部行：左侧书籍为唯一可选类型，漫画、有声书、视频为禁用占位，鼠标和键盘均不能切换；右侧展开搜索／筛选、合并排序依据与方向、卡片大小与添加，无额外大标题。不设独立继续阅读区域，以最近打开排序配合位置恢复。生效条件可见可清除，图标有名称、悬停说明及键盘焦点。书卡以真实封面为主体，下方为书名，底部右侧为三点菜单；封面完整展示不拉伸，长标题可查看完整内容。不增加进度槽、常驻状态下拉框或重复来源名，封面／书名进入阅读，菜单不触发阅读。只有多页才显示完整分页。

书卡菜单以紧凑行距提供书籍详情、编辑书籍信息、禁用的移动到其他来源，以及带当前状态的阅读状态二级入口，底部以分隔线隔开删除书籍。移动配“暂未开放”文字，不附底部延期说明。删除打开确认框，按 [PRD 4.2.1](PRD.md#421-本轮材料目录与阅读管理) 说明清理与保留范围及不可撤销性；首版不提供一并删除选项。取消或 Escape 返回原入口，提交中防重复和关闭，失败保留确认框并可重试；成功刷新目录与来源计数，回到有效页，并将焦点交还仍存在的目录入口。素材库与来源空间使用同一交互。阅读状态进入同一弹层的子菜单，提供未开始／进行中／已完成，返回入口、左箭头或 Escape 回父菜单，再次 Escape 关闭；方向键跳过不可执行项，操作不误触阅读。

书籍详情使用独立路由、公共中性外壳、紧凑返回栏与左对齐的封面／信息布局；显示书名、封面、所属来源、导入时间、阅读状态、最近打开及章节数量，保留阅读／编辑入口。缺少封面或解码失败时使用三斜线装帧占位，真实封面与原重试入口优先；不展示推算的本书学习成果。来处区分素材库、来源视图和全部书籍窗口，详情进入阅读后可返回详情，再回原来处；无有效来处回素材库。

卡片和详情共用编辑弹窗，编辑应用内书名、预览并选择静态 PNG／JPEG 自定义封面、恢复原书封面；不提供 EPUB 替换、来源编辑或移动表单。保存同次提交书名与封面意图，失败保留草稿；冲突保留草稿并允许重新读取当前信息，不以旧版本覆盖。取消／Escape 在有草稿时确认放弃，保存中不关闭或重复提交。保存后同步目录、详情和阅读书名／封面，保留目录条件与有效焦点。

成功数据确认整个库无书时，网格区域显示整片可点击的低对比虚线导入区，无内部按钮；隐藏顶部重复加号与相邻分隔线，有书后恢复加号。区域使用完整按钮语义，Tab 可聚焦，Enter／Space 开始既有导入；取消恢复区域焦点，完成后恢复有效入口焦点。有书但条件零结果显示清空／调整条件；加载、错误、当前页空列表均不足以证明真空库。未实现拖拽时只表达点击导入。

主导航使用“来源目录”；折叠入口可放品牌旁图标，不保留底部文字菜单。公共控件可复用，各页面保留独立布局组合空间。现有 URL、导入归属／迟到保护、状态版本、阅读返回及位置恢复契约继续生效。

应用公共外壳默认使用白底、灰蓝导航与蓝色操作色，素材库、来源、详情、设置、片段及加载／错误页共用；页面组合只决定内容布局，不再通过额外类名选择新旧外壳。侧栏宽屏可展开／收窄（208／60px），图标保持名称和焦点提示；窄屏临时抽屉。Source 上下文列表只在 Source 空间，工作台合并重复全局导航，保留内容讨论控制。阅读器继续使用独立纸面主题。设置保留全部现有接入能力。

来源空间为主导航／来源列表／来源内容三栏；来源列表全高独立滚动，搜索、排序、新建集中于栏头。窄屏提供可达来源切换，全部来源可浏览，不以首个 API 页冒充全量。右侧紧凑名称、可选说明及来源信息／编辑／删除菜单，保留概览／素材／片段／讲解四视图。

宽屏来源栏可拖动或用方向键、Home／End 调整宽度，并保存本地偏好；默认 260px，范围 220–360px。搜索框按 Escape 收起并将焦点交回入口，收起后仍显示可清除的搜索条件。全空来源在概览集中展示添加片段与导入素材入口。

概览按 updated_at 降序预览 2 条讲解，按 created_at 降序预览 3 条片段，辅助预览 3 份所属素材及约 4 行已有备注，完整备注从来源信息查看；条数为展示参数，计数来自真实统计。讲解直达所属 Segment 的确切修订，素材直接进入真实阅读。概览素材“查看全部”进入当前来源素材视图，查询不继承完整列表旧搜索，失败／加载／空态分开；仅书、仅片段、无讲解、全空及零来源如实显示。

素材视图保留真实类型数量及有界样本。查看全部固定 Source 与类型，在素材背景上打开大型模态窗口；独立滚动，窄屏全屏。打开新增浏览器历史，筛选输入不逐字新增历史；后退先关闭窗口，刷新重建窗口。Escape／关闭回同一素材视图并恢复合理焦点；必须实现焦点约束和背景不可交互。

窗口打开书进入普通阅读页，返回恢复原窗口的条件、排序、页码、列表位置；站外直达窗口关闭安全回 Source 素材视图。旧 expanded=book 无 view 的直达按素材窗口理解。来处校验应用内路径，不任意跳转或无条件 browser.back；无来处材料回素材库，片段回 Source 列表，所属 Source 单独导航。

阅读工具紧凑按需展开；章内进度不等于完成。尺寸／侧栏／字号变化按稳定锚点恢复，不保存动画中间布局。状态刷新不重挂载 Reader，再开仍等待位置写队列排空并 fresh GET。

普通主导航与主动选源默认概览；显式视图与查询、同路径刷新、浏览器历史、阅读后的来处恢复优先，不能被偏好初始化覆盖。来源记忆只保存有效身份，不覆盖 URL。普通记忆失效可降级首项；显式来源失效显示不可用。当前来源被搜索隐藏或不在首批时按身份核实，不能静默切换；左右检索保持各自作用域。

### 书籍详情统计

`/materials/:id/details` 独立加载后端统计汇总，不挂载阅读器、不下载全书 token；书籍信息、统计的加载与失败分别呈现，统计失败可重试。没有可用分词代次时，字符／汉字统计仍可展示，词法部分明确“尚未准备”；读取统计不隐式分词，也不更新阅读状态、最近打开或位置。统计不作为阅读或既有注音准备的前置条件。

范围说明使用“当前材料版本的全部可提取正文”，包括目录和后记；同 resource_id 的重复 spine 只计一次，不合并不同资源中的相同文字，不称作小说正文。词次／词种注明固定分词配置和词典形口径，保留助词、助动词，过滤空白、标点和零跨度记录；字符数采用 NFC 正文码点数，含空白与标点。曲线横轴为“本书最高频的前 k 种词”，纵轴为“词次覆盖率”，不表达理解率或学习者掌握率；空分母显示“—”，曲线为空。计算规则和输入身份由后端维护，显示结果绑定确切版本与代次，迟到结果不替换新目标。

### 设置顶部分类

设置复用公共主导航，内容区使用紧凑页头与学习偏好／模型与服务／对话与权限三个顶部分类；验证记录通过模型页次级入口进入。

学习偏好将学习背景、讲解预设和默认预设放在同页；模型与服务将讲解／讨论默认模型放在服务列表之前；新对话默认权限单独保存。条目整理尚未开放，界面说明阶段边界，保留已有提取模型存储值。无可选模型、设置加载失败与服务列表加载失败分别呈现。

服务列表显示名称、协议、已登记模型与文本验证摘要，详情承载模型管理、连接设置和对应服务的验证记录。模型发现、手动／批量登记、启停、凭据、协议覆盖、参数和删除确认保留；普通与流式能力分别反馈，结构化未开放验证集中说明。验证历史由服务端按服务、登记模型身份及状态筛选后分页。

模型选项同时显示 Provider 名称和模型 ID。模型行用图标与文字分别显示“未验证／验证中／可用／验证失败／中断”，提供原因与对应记录入口，状态基于当前配置；刷新可继续查看运行状态。模型行的“可用性验证”菜单提供普通文本、流式文本和两项重新验证，各入口说明调用次数：单项 1 次，组合 2 次。结构化输出标明尚未开放验证，列表获取、文本验证与其他能力分别表达，不用一个“连接正常”概括全部能力。

新增和编辑使用一致的模态表单。页面表单与弹窗各自保存；学习背景与默认预设同次提交原子保存，其他分组只更新自身字段。未保存修改在分类切换、站内离开和浏览器历史导航前提示，可继续编辑、放弃或保存后离开；刷新和关闭使用浏览器原生提醒。保存失败保留草稿，保存中不允许取消已提交请求，后续编辑重新标为未保存。草稿和密钥不写入浏览器持久存储。

### 阅读器 R1.1

#### 阅读外观与工具显隐

Reader 不渲染主导航，也不修改应用原有侧栏偏好；加载、错误及不可用材料仍有可靠返回或重试。顶部保留返回、书名／章名与低频书籍信息，底部保留章内进度、临时返回点、上一章／目录／下一章导航组与工具；窄屏进度移至顶部章名旁，显隐不改变正文宽高或留白。

目录与书内搜索共用左任务面板和页签，切换保留查询；设置和插图库在右侧，阅读工具面板均非模态，不圈定 Tab 焦点或禁用正文。正文延伸至页面底部，不为阅读工具预留固定底部区域；侧栏保留完整圆角和 12px 侧／底边距，左导航与右工具独立共存。导航上方的书名、阅读信息和页签固定，仅各页签内容滚动；宽屏章内进度置于紧凑浮动工具栏内部，工具栏外的空白不截获点击。目录为工具栏唯一导航入口，可切换搜索页签；任一页签打开时再次点击目录关闭整个导航面板，其他工具同键关闭、同侧异键切换，关闭或完成定位只收起发起操作的一侧。窄屏保留两侧状态，最近使用的一侧显示在前，工具按钮切回被遮住的一侧先恢复其内容。图片查看器独立覆盖阅读器，不受工具面板尺寸或滚动裁切；打开时背景虚化并压暗，图片居中，背景暂停交互。

Escape 先关闭最上层。正文点击图片直接打开查看器，一次关闭回到原阅读位置；从插图库打开则关闭回图库，保留图库页码与滚动位置。查看器支持关闭按钮、Escape 和点击背景空白处关闭，并恢复合理焦点。窄屏控件与面板可滚动，隐藏工具不能进入 Tab 顺序。图标工具有悬浮／键盘焦点名称提示，专注提示显示当前开启／关闭状态；专注偏好与当前工具显隐分开，普通单击、实际鼠标移动与 Tab 可唤出工具，静置隐藏不破坏选区、拖动、控件或已打开面板。失败、冲突及无法恢复的反馈始终可见。书籍信息分别标明书名、所属来源、阅读状态与阅读位置保存状态；导入提示说明格式与兼容性处理。历史交互依据见[交互优化](handovers/archived/reader-r1/INTERACTION_POLISH.md)。

纸面提供白／黑／跟随系统，不反色图片；主题与专注保存为本浏览器跨书偏好，字体／宽度／注音逐材料版本保存。字号／行距／横竖排继续经位置 API 保存，合法旧值不按演示范围裁减。顶部标题栏与底部工具栏共用随纸面变化的半透明背景和轻微模糊，文字与图标保持清晰。工具栏不透明度滑块范围 0–100%、步长 5%、默认 80%；0% 完全透明，100% 不透明。调整即时保存为本浏览器跨书偏好，恢复阅读默认值时重置，不改变正文几何布局。

横排正文从顶部标题栏后滚过，章首保留起始间距，章末提供可滚动留白，使最后一行能完整移到工具栏上方；竖排每列保留上下安全空间。工具显隐不改变这些空间或位置采样边缘，排版留白不计正文长度。正文两侧留白支持滚轮／触摸板滚动，面板独立滚动；竖排纵向手势沿阅读轴推进。适用阅读方向的方向键、PageUp／PageDown 和空格平滑滚动，遵循减少动态效果偏好；位置恢复仍即时执行。

#### 跳转链与返回点

返回来处恢复素材库的筛选／排序／页码／列表位置，或来源概览、素材视图和 expanded=book 窗口；无有效内部来处回素材库。相邻切章、目录、搜索结果与图库明确前往共用一个会话原点，连续查阅不覆盖它，实际新位置继续持久化；图库浏览／放大／切图／关闭不导航。例如 A→B→C 后返回 A；在 B 继续阅读到 B′ 后，返回 A 的入口仍保留，下一次跳到 C 时才将原点更新为 B′。

继续阅读信号采用以下交互判定：页面在前台且有焦点，主动净前进至少一个阅读视口，首末移动相隔至少 5 秒。单纯停留、短时查阅、工具面板滚动及排版恢复不计；后台或重排中断尚未确认的信号，已确认信号保留到下一次实际跳转。判定仅管理临时返回点，不标记已读或学习完成，也不改变独立的章节位置保存。历史依据见[跳转链与继续阅读](handovers/archived/reader-r1/INTERACTION_POLISH.md#2026-10-16-跳转链与继续阅读)。

返回按钮悬停与键盘焦点提示为 `返回“章节名 xx%”`，使用建立返回点时的章内进度并四舍五入为整数，无法计算时只显示章名。实际返回定位成功后清除原点，后续跳转再建立新原点。返回按当前排版恢复，不恢复旧设置；身份或 DOM 位置无法核验时明确失败并保留返回点供重试，不猜测同句位置。刷新或离开后不承诺保留临时原点，内容身份与引用校验仍由 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)规定。

#### 书内搜索与图库

书内搜索使用去首尾空白、NFC 后的全书原文字面查询，不搜索注音、OCR 或 UI 合成章名；支持重复／重叠命中和同资源连续 part，不跨原资源或章边界。显示真实总数，每批 40 条，条目显示章节与纯文本上下文，点击按确切版本／章／part／资源与码点范围定位并高亮。图库按真实图片出现顺序有界分页，同图多次出现分别展示，缩略图与大图按需加载；浏览、缩放及切图不改正文位置。

正文与图库共用图片查看器。默认完整适合窗口，支持放大、缩小、恢复适合窗口及放大后拖动，触屏支持双指缩放；上一张／下一张按书中出现顺序切换。查看器提供“复制图片”和“下载原图”：复制用于粘贴图片，下载保留原始格式；复制失败明确反馈，不以复制链接替代成功。查看器中的“在图库中查看”切换到当前图片出现项所在页并突出该项；“前往书中位置”才移动正文并进入正常定位链路。

无图、无命中、加载与失败各自表达，失败保留查询并提供重试。材料统计放在书籍详情，不进入阅读工具。只读查询与阅读状态的边界见 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)，页面、浏览器和扩展兼容性以[实施基线](handovers/MVP_IMPLEMENTATION_BASELINE.md)链接的实际验收记录为准。

#### 注音与正文复制

全量注音使用持久分词结果：首次进入旧书先准备，成功后恢复阅读，失败可重试。阅读设置提供原书／全量范围和展示／按需／隐藏方式，不放重新生成入口；默认原书展示，偏好逐材料版本保存。全量补充未被原书 ruby 覆盖的汉字，按需可悬浮、轻点、选区或正文 R 键查看。字号、行距、宽度、字体、方向与注音范围调整在当前阅读内容中重排并恢复原文锚点，不先展示章首；全量数据尚未就绪时保留当前范围与画面，请求成功后再应用，失败可重试。显示／隐藏保持排版空间；后台状态与内部词典信息不进入日常阅读流程。

复制使用所选原文纯文本，保留编译正文的换行与空白，排除原书和自动注音的 rt／rp；不改变选区或注音显示。注音生成、覆盖保护及引用身份仍由 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)维护。

#### 章节位置与进度显示

材料普通打开恢复全书最后的逻辑章和内容位置；目录选择其他章恢复该章上次位置，无记录则到章首，选择当前章保持位置并关闭目录。目录顶部提供当前章“回到章首”，将会话返回点更新为操作前的位置；已在章首时重复操作保留原返回点，不清空其他章记录。搜索、插图定位成功也更新章节位置，预取、失败跳转及恢复中的临时位置不更新。历史依据见[章节位置记忆](handovers/archived/epub-reading/CHAPTER_MEMORY_ACCEPTANCE.md)。

底部上一章／目录／下一章沿用阅读器章序，横竖排一致。相邻章有记录时恢复，无记录到章首；首末边界禁用对应按钮，不循环。切章从请求开始到稳定呈现前禁用相邻按钮，失败保留原章并允许重试；未呈现位置不写入记录。工具栏切章保留左右面板与搜索，目录点击仍关闭左面板；新的明确导航或工具切换使旧请求失效。窄屏进度移到顶部章名旁，相邻按钮提示含目标章名；章末入口暂不增加，方向键仍用于正文滚动。历史依据见[底部相邻章节导航](handovers/archived/reader-r1/INTERACTION_POLISH.md#2026-10-16-底部相邻章节导航)。

目录条目右侧以低强调整数百分比显示上次章内位置，无记录留空。当前阅读页与目录共用以下显示口径：

- 未到章末时按稳定正文位置计算，图片处取图片前已有正文比例，最高 99%。
- 最后一行文字或最后一张图片末端进入稳定视口可读区时显示 100%，不要求滚过底部留白或空白片段；一屏完整呈现的短章同样显示 100%。
- 纯图片章到末尾显示 100%，此前目录显示“有记录”，阅读工具栏显示“章内 —”。
- 章末状态与原文字／图片恢复锚点一起保存，不将锚点替换成最后一个字符。重开、刷新或跳回章末时呈现当前排版末屏；回看离开末尾后重新计算，字号、方向或窗口变化先恢复锚点再按稳定视口判断。

100% 仅表示当前位置到章末，不表示累计已读，也不自动改变材料阅读状态；总阅读进度仍后置。历史依据见[章末进度与真实书复核](handovers/archived/epub-reading/CHAPTER_MEMORY_ACCEPTANCE.md#2026-10-16-真实书复核与口径调整)。资源身份、fragment、位置版本与章归属由服务校验，重排后的附近恢复与精确引用校验保持独立。材料自身或所属来源删除后的可读与位置保存边界遵循 [PRD](PRD.md)。

## 讲解浏览、人工保存与按需讨论

`/segments/:id` 是片段阅读与讲解页，Workbench 仅是其中按需展开的讨论区域。片段正文、工具栏与讨论背景沿用公共外壳的颜色变量；EPUB 阅读器保留独立纸面主题。

片段页使用专用三栏布局：左侧约 56px 窄工具栏、中央阅读区、右侧按需讨论。进入片段页隐藏全局主导航，不改写全局侧栏偏好；窄屏工具栏转为顶部紧凑操作栏，讨论展开时占满内容区，阅读 DOM 与滚动位置保留，隐藏阅读区退出键盘和辅助技术的操作范围。关闭讨论将焦点交回开关。

工具栏顶部负责返回明确来处，中部负责讨论显隐，底部菜单负责片段资料编辑与删除。中央显示所属来源与“片段”身份。精确出处独立呈现服务端核对的材料名与章名，长名称视觉省略并保留完整标题；“在原文中定位”跳转确切目标，与返回来处分别表达。材料不可用时保留可靠名称与定位状态，片段内容仍可阅读。手动片段无需精确出处。资料浮层挂载或后台刷新重新核对出处时，保留已有出处文字与布局，核对完成前暂不可定位；首次加载显示等待，失败或失效提供反馈。

内容卡片集中显示目标原文、已保存前后文和当前译文。前后文只显示内容，辅助技术保留范围名称；分别预览最接近目标的两行，预览合并空白、提高对比度；完整资料保留保存时的文本。目标原文预览最多四行，无语境不占空行。卡片内朗读入口只播放目标原文，沿用声音设置、错误反馈与播放条。播放条悬浮在阅读栏底部，正文保留滚动空间；窄屏讨论展开后播放条仍可操作，讨论输入区按播放条实际高度避让。正文可选择，独立的“查看完整原文与资料”按钮打开资料浮层；关闭恢复当前可见入口和阅读位置。片段页的普通按钮、链接与焦点采用黑白灰，删除、错误与警告保留语义色。

原文卡底部右侧的独立“复制分享”图标打开居中略偏上的模态浮层，背景压暗并轻微模糊，中部为可滚动、可选中文本的只读预览。底部只有一个主复制按钮，旁侧下拉切换默认“复制原文与出处”、“仅原文”和“仅出处”，按钮文案与预览同步；切换不写入剪贴板。默认模式按已保存前文、目标原文、后文排列，有语境时用引用块区分目标，保留原有文字和换行；末尾附可靠材料名、核对后的章名及手填出处，无材料名时回退来源名。出处省去字段标签和章内百分比，空字段省略；仅原文保持目标文本原样。内容范围、隐私和失败反馈遵循 [PRD F2](PRD.md#f2-source-与片段)。浮层打开时背景不可操作，键盘焦点限制在浮层内；支持外部点击和 Escape 关闭、关闭后恢复入口焦点；窄屏切到讨论时收起。分享组件在页面加载时订阅同一出处核对查询，打开或重开分享不另触发核对；必要后台核对不显示加载说明，预览区域保持固定高度。失效时只保留可靠材料名；需要回退来源名时，含出处复制等待来源首次读取，已有可靠材料名则无需等待来源。“仅原文”始终可用，读取失败明确反馈并可重试或复制现有内容。

当前译文直接读取 Segment.translation，可为人工填写或采用后修改的文字，不要求等于任一关联结果。关联翻译记录在同一卡片内独立展开，保留当次译文、语境和模型；回看不生成、不采用、不改写当前值。当前译文为空但有关联记录时仍可查阅；两者均为空时不保留空翻译区域，读取失败提供重试且不隐藏已有当前译文。资料编辑继续通过既有入口维护译文，采用行为沿用 PRD 4.8。

资料查看与编辑沿用“原文与语境、译文与听写、出处与备注”三组顺序，组内依次为前文／目标原文／后文、译文／听写、只读精确出处／自由文本出处／个人管理备注。阅读隐藏空字段与空组；编辑保留全部输入，前后文可独立展开，已有内容默认展开。固定原文显示为可选择、可滚动的只读文字，不占用禁用输入框；译文、听写、前后文和文字出处会进入新任务的模型输入，个人管理备注只用于管理。资料浮层和编辑均显示服务端核对的精确出处，编辑中的出处只读且不提供离开草稿的跳转。入口统一为“查看完整原文与资料”和“编辑片段资料”。

编辑只提交本次改动字段；冲突后保留草稿，重新读取完整当前资料供核对，读取成功并明确确认后才允许重试。未修改字段保留其他操作的新值；当前资料读取失败时仍可查看草稿并重试读取。

讨论面板使用单行标题栏，返回对话列表与收起面板分别使用导航箭头和无箭头的分栏面板图标，提供名称与悬停提示；新建对话使用加号，保留名称与悬停提示；第一条消息形成的标题只用于列表查找，详情不重复堆叠。可展开的“参考原文与前后文”读取当前已保存资料，并说明新任务与历史输入快照的区别。用户消息右对齐、淡色气泡、最大宽度约 85%；助手回复使用透明背景和内容区全宽。角色名称保留在辅助技术语义中，回复的复制操作在悬停／键盘焦点时显示，触屏常显；已有成果继续提供确切讲解入口。

输入区以多行问题和发送按钮为主，只保留模型、审核模式两个设置按钮。打开后直接列出可选项，当前项有勾选标记，单击选项即切换并收起；模型列表底部保留生成方式。浮层互斥，不改变输入区或消息区高度，支持 Escape 与外部点击关闭。临时要求直接写入聊天消息，新请求沿用设置中的默认讲解预设；不提供独立的本轮要求或预设覆盖入口。恢复旧失败任务时，将原问题与旧补充要求一起放进可见聊天框；已受理请求仍按冻结内容核实，不改写历史快照。资料编辑不常驻原文固定规则或模型输入用途的说明段落；模型不可用、配置读取失败、提交不确定、运行及待审核状态继续提供原因与操作。返回列表或收起讨论保留本页草稿与运行协调，不等同于停止。本轮未接入单条回复直接保存讲解、讨论主视图或自动概括标题，相关输入范围与写入权限仍由 PRD 规定。

讲解集合负责列表、新建及其 AI 生成选项；单篇文档负责全文编辑、重命名、版本信息与删除。新建只出现在讲解列表，以一个“＋ 新建讲解”菜单提供“自己编写”和“使用 AI 生成”；打开菜单不创建内容。具体讲解的标题行左侧提供返回列表图标，右侧保留当前文档操作，不再单独显示集合工具栏。加载、失败或跨片段无效详情仍提供返回入口。标题使用较小字号，长标题与版本状态按可用宽度换行。当前版本可编辑，历史版本在标题旁标明只读并提供“查看当前版本”；“版本信息”展示讲解标题、讲解 ID、所读修订与当前修订。新建菜单支持键盘导航、Escape 关闭和外部点击；正在生成时只禁用 AI 选项。取消人工新建回到菜单入口，新建保存成功并打开确切修订后聚焦文档返回入口；编辑已有讲解沿用编辑入口的焦点恢复。目录默认折叠，只显示章节标题，减少头部留白并以一条底线衔接正文；正文的首个简单总标题与讲解名称一致时可承接页面标题，重复标题与空前言不占额外阅读空间；重命名后页头使用新名称，原正文标题保留在正文，原始 Markdown 和 Section 锚点保持完整。重命名位于“更多操作”，当前或历史阅读均可修改讲解名称；弹窗预填名称，保存失败保留草稿，关闭恢复菜单入口焦点。左侧讨论开关始终使用对话气泡图标，展开状态和操作名称随显隐更新；右侧讨论栏保留独立的收起图标。讨论开关只更新显隐，保留当前线程与讲解选择；列表返回恢复本次列表滚动位置。

普通原文／讲解回看、确切修订直达及人工编辑不启动工作台，不查询模型设置、讨论或任务。显式展开讨论、未显式收起的线程直达或快捷生成才激活讨论；URL 中 chat=0 优先于 thread，首次进入保持纯回看；激活后在同一 Segment 页面内保活，收起与返回讨论列表保留草稿、待核实提交、审核补充要求及协调器状态。同片段参数变化不重挂整个页面，切换 Segment 隔离状态；离页后的草稿持久化不扩张。

Segment 讲解区提供新建入口，直接输入或粘贴 Markdown；表单只提供可选标题与正文，统一记录为用户保存；保存无需模型配置，成功后打开确切修订，不创建讨论线程或模型任务。首版不做批量文件导入、URL 抓取或富文本编辑。当前修订可全文编辑，旧修订只读；提交携带基础修订，冲突、空白、超限或保存失败保留草稿，不覆盖新版本。取消有未保存修改时确认放弃，路由离开和关闭页面保留现有草稿提醒；不承诺关闭页面后恢复人工草稿。编辑器固定打开时的原文摘要和基础修订，后台刷新不替换编辑依据；冲突保留草稿并刷新相关读取，重新打开最新版本后再编辑。片段后台读取失败时页面改为错误状态，已打开的编辑器保持挂载；已删除资料不继续显示，只保留本次编辑草稿供复制。

首次持久讲解保存会固定目标原文，提交前显示提示；打开、取消或失败保存不固定。前端不提交未变化正文；服务端无变化校验不产生空修订或成功凭据。响应不确定时固定本次完整请求并禁用编辑，重复提交同一请求核实；成功打开返回的确切修订。明确失败后保留草稿，不覆盖后来保存的成果。人工入口继续沿用讲解归属、确切修订、来源返回和删除门禁，不改变讨论权限。

### 定位与返回

片段路径保持`/segments/:id`。查询参数表达当前阅读和讨论目标：

| 参数 | 含义 |
| --- | --- |
| `analysis` | 明确打开的讲解；缺省展示讲解列表 |
| `revision` | 在该讲解内打开确切修订；缺省当前版本，不能脱离`analysis`独立使用 |
| `thread` | 明确打开的讨论；缺省讨论列表 |
| `chat` | `1`展开讨论，`0`收起；未指定时由是否存在`thread`决定 |

阅读选择和讨论选择可以同时存在。打开成果写入讲解与确切修订；切换讲解或返回列表时清除旧修订。刷新只读取已有内容，不重发生成或审核请求。浏览器历史中的目标变化不会将同片段页面重新挂载。

本页发起的讨论或快捷生成有了已保存成果后，只有当前讲解与确切修订仍与首次提交时一致，才自动打开成果；用户已选择其他阅读位置时保留该选择，仍可从成果入口手动打开。丢响应后的核实或同请求重试沿用首次提交的阅读位置。相关验收见[架构重构记录](handovers/archived/ARCHITECTURE_REFACTOR_ACCEPTANCE.md)。

指定讲解与讨论必须属于当前片段；不能因它不在已加载的首批列表中就认定无效，也不能把另一片段的内容配在当前原文下。无效目标显示错误并提供回到当前片段列表的入口。

**返回来处**与**所属来源**是两种导航：前者使用应用内入口记录的路径和名称，后者始终前往片段所属的Source。站外打开或没有有效来处时，前者明确显示“来源目录”。查询参数更新保留来处记录，不使用无条件浏览器后退跳出应用。

当前选中讲解只表达阅读位置；“展开讨论”不自动授权修改，也不声称将这份讲解注入模型上下文。讨论继续遵守当前片段范围与明确目标规则。

## 学习衔接

材料选区与精确出处往返按 C1／C2 接入；交付状态与验证范围见[实施基线](handovers/MVP_IMPLEMENTATION_BASELINE.md)。

### 选区与资料往返

首版选区使用单个 chapter part iframe 内的原生选择，支持跨 DOM 节点；跨 iframe 拖选、跨章和追加不连续选区不在范围。选中只保留临时状态，不调用模型；点击“保存为学习片段”后捕获此次选区快照，准备草稿并确认原文和来源，最终提交成功才创建片段和固定原文。Reader 内新建片段统一走此入口，来源等其他手动创建入口保留。后端出处与回读支持同一逻辑章内的有序多资源范围，严格校验与规范化身份见[PRD 4.7](PRD.md#47-当前-epub-阶段安排)和[架构](ARCHITECTURE.md)。

已有片段仅按确切出处提供有界候选，由用户显式选用并保留其语境；不按相同文字自动合并，候选失效不静默新建替代。新建时预装整理过边缘空白和连续空行的有界前后文，按整理后码点计预算并说明自动摘录，显示目标与简短预览，完整语境可展开修改或清空；可直接保存。语境可同章跨 part，目标仍为确切选区。创建或选用成功后关闭草稿并留在原文，顶部可关闭提示提供“打开片段”；明确打开后进入既有片段／讲解路由，可保存人工讲解或显式启动讨论，不扩大 Agent 的资料读取范围。

#### 片段标记与页边入口

“保存为学习片段”位于原生选区浮动工具栏，完成选择后出现；支持 Tab 进入与 Escape 关闭，保留原生划选和复制。已存片段以低强调细下划线表示，竖排沿文字旁侧，注音不加线。普通轻点可见标记的基字打开已有资料，单片段直接预览，多个确切命中先选择；修饰键、拖动、长按划选、键盘扩选及复制保留。轻点标记不同时切换工具栏或按需注音；双击不增加等待，首击可能先显示预览，形成选区后以选择为先。

页边使用扁平小符号或聚合数字，至少 44px 命中区域只放正文外真实留白；竖排优先底部，无空间时使用本章列表，不挤压正文。入口固定在目标首处原文，随正文滚动，排版变化重新定位，滚动不切换锚点或临时合并入口。单片段直接预览，再点同一入口收起，其他入口切换目标。聚合候选与完整本章列表显示原文摘要和精确到分钟的保存时间，不显示 ID 后缀或额外选择提示，完整 ID 位于保存信息。全部分页读取完成后才开放完整列表和标记；本章列表始终提供集中入口，加载与失败分别反馈。

#### 原处预览与记录浮窗

预览默认紧凑横排。类型标签下的操作行左侧提供列表返回（由列表进入时），右侧提供“打开片段”；随后依次为原文引用、译文、讲解、备注与保存信息。原文引用以浅底色和细竖线区分，长原文可展开；优先显示已有译文，没有译文则直接读讲解，两者都没有时显示已保存原文。多份讲解默认最近更新，显示篇名并允许切换和加载更多，正文摘录不冒充译文。备注低强调，保存信息在底部默认折叠，不另加分隔线。

“本章记录”中的讲解完整展示、内容区独立滚动，标题栏仅保留关闭按钮，不提供展开／收起。“此处记录”紧凑模式显示“讲解预览”，仅实际截断时显示底部渐隐。“展开”进入右侧覆盖式完整阅读侧栏，正文不重排、目标不随滚动变化；“收起”回到紧凑预览，保留当前目标、类型标签、所选片段／讲解和临时手动位置，叉号完全关闭。目录与侧栏共存，同侧设置或图库替换侧栏，窄屏遵循前侧规则。普通标记只打开预览，“打开片段”才离开阅读器，携带当前讲解及确切修订，返回仍用片段精确出处。

横排正文中只对应单一翻译目标、不含学习片段的划线，普通轻点在完整原段之后展开最新成功译文；短选区不拆原段，跨段目标在最后一段后显示。一次只展开一处，再点同处收起，点击另一处切换，正文滚动保留。译文字号略小、低强调，不附记录工具栏；开合保持原文位置，淡入淡出遵循减少动态效果偏好。页边入口仍开完整浮窗；竖排、重叠多目标或无法安全插入的作者版式回退浮卡。译文不加入原文定位或保存，可独立复制，混合复制只提取原文。

正文划线预览贴近实际点击的行／列，横排优先下方、上方回退，竖排优先侧方；页边预览以所点按钮为锚点，左右页边优先向外侧留白展开，不足时向正文侧展开，竖排底部入口优先向上。窄屏统一底部浮卡，以原文强调对应目标。

宽屏记录浮窗可拖动标题栏，按钮与内容区保留操作；标题栏聚焦后可用方向键移动。拖动后停驻屏幕，背景点击、正文划选和滚动保留，其他标记在同一浮窗切换内容并沿用位置。关闭或切章清除手动位置，下次跟随入口；窗口和内容尺寸变化约束位置，确保标题和关闭可达。窄屏底部卡与展开侧栏不拖动；同一处不重复显示段尾译文和浮窗，已停驻时点击正文标记也在浮窗切换内容。

同时只保留一个预览。正文空白与两侧页边普通轻点清除原生选区及选区工具栏，收起未停驻的紧凑预览，本次不再切换阅读工具栏；新划选、拖动、长按、修饰键及控件操作保留。未停驻浮卡在卡外普通轻点、原文划选或正文滚动时收起，固定本章列表与展开侧栏保持，卡内独立滚动。候选指向／聚焦临时强调原文，选中后持续强调全部出处范围。切章、失效或删除清理旧目标，重排重算标记与入口，草稿切换保护遵循 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)。

#### 阅读会话往返

同一标签页从阅读器进入片段页时，短期保留最近一本书的正文与 iframe。返回先核验材料可用性、内容版本和阅读状态，再复用正文并刷新片段、译文与讲解；`?segment=` 仍按片段出处定位。暂停时隐藏阅读器，禁用输入、布局采样和延迟位置保存，完成已有位置写入。打开另一材料、离开片段往返范围、暂离超过十分钟或刷新后释放；不可用或版本不一致不展示旧正文。持久位置、引用和删除边界继续遵循 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)。

#### 语境、出处与定位反馈

阅读设置的“正文标记”分组分别控制阅读记录下划线与页边入口，统一适用于学习片段和翻译，默认开启，当前浏览器内跨书、刷新与标签页同步。两项都隐藏时，本章记录仍可访问。保存提示不抢焦点，悬停或焦点停留期间不自动关闭。

C2 在学习偏好提供独立保存的“学习片段语境”分组，提供预装开关、前后句数及字符上限；默认值与计数规则由 [PRD 4.7](PRD.md#47-当前-epub-阶段安排)维护。本次草稿可临时调整，临时调整不改写默认设置；修改预算不立即重填，重新按预算取文是明确操作，保留已修改内容供用户决定替换。修改或清空的字段不被首次预填、迟到结果、设置变化或重开覆盖，选用已有片段也不触发语境更新。本次流程内收起再展开保留草稿，取消或离页后的草稿持久化不扩张。

取文失败保留目标与草稿，允许重试、手动填写或仅保存目标；出处校验失败仍拒绝保存。切换目标、取消或离页使旧结果失效。界面标明语境截断，用户改写后不继续标为逐字原书引用；用户手动输入沿用现有长度限制，不按自动预算裁剪。划选、预装、编辑及保存不调用模型。

片段资料与编辑入口将精确出处显示为只读“材料名 · 章名 · 章内约 N%”，采用服务端解析结果；不可定位时保留原状态及可靠材料名，缺失部分不补造。source_ref 独立保留，有精确出处时显示为“出处补充”，否则为“出处说明”。

带出处的片段提供“返回原文”，深链接按 Segment 身份解析，不在 URL 放全文。返回原处与书内搜索共用临时定位高亮：精确目标稳定呈现约 2.5 秒后，以约 260ms 淡出并清理，背景与文字颜色同步恢复。正文主动输入、轻点／划选提前开始淡出，新导航、切章或离页立即清理，减少动态效果时直接消失。重排不续期、不重新变亮或复活，不清除永久学习／翻译标记，下划线关闭仍可定位。阅读器完成现有注音准备并验证同章全部目标范围后，从第一段范围起点定位；部分范围无法投影时明确定位不完整。等待、准备失败和重试保留此次目标，不能因普通阅读恢复丢弃它。定位失败不保存未呈现目标、不提前消费临时返回点；来处导航、会话返回点与位置保存分别沿用现有规则。版本或快照失配保留可见资料的历史文字并说明无法定位，已删除资料遵守不可见门禁。

### 阅读翻译与设备朗读

本节维护翻译与设备朗读的交互呈现，产品规则及原始方案入口见 [PRD 4.8](PRD.md#48-阅读翻译与设备朗读)，交付与验证以实施基线为准。选区工具条提供翻译、设备朗读及保存；普通选择保持原生行为，不自动调用模型。

#### 翻译卡片与历史回看

翻译以不重排正文的覆盖卡呈现，与已有学习资料预览互斥，同一时刻只有一个当前内容卡。首屏突出短原文引用、译文和主要动作；原文按实际显示长度折叠，生成信息、本次语境和历史按需展开。横排优先放在选区上下，竖排优先放在侧边；正文滚动或重排使原屏幕位置失效后，卡片停靠右侧。窄屏卡片放在底部并避让朗读控制；卡片内部可滚动，关闭入口保留在顶部。加载、失败、停止和关闭分别表达，关闭不取消已受理任务；当前目标不随滚动、新选区或迟到响应漂移。

标题栏同一行提供重译、停止、收起图标和进度，“语境与设置”默认折叠。重译时保留旧译文，完整新结果读取后才替换展示，失败或停止仍可读旧文。“上一版／返回新版”只切换查看一对已保存结果，其余历史从完整列表读取，不触发模型调用。宽屏可拖动标题栏及键盘移动，窄屏保持底部停靠。

译文从正文标记、本章记录或原处再次划选进入；底部工具栏不再提供“最近翻译”。确切目标的详情保留分页历史和任务状态，旧结果说明实际语言、模型和语境，重译是明确动作。本章记录和划选翻译详情去除“保存为学习片段”“另存新片段”及独立采用表单，保留已关联片段的打开入口。正文划选保存草稿新增可编辑／清空译文，按 [PRD 4.8](PRD.md#48-阅读翻译与设备朗读) 的确切匹配规则，优先使用本 Reader 会话最近在翻译详情选中的匹配成功结果，否则取最新匹配成功结果；只预填一次完整译文，修改、清空或开始提交后拒绝迟到覆盖。语境继续独立预装，不套用翻译历史语境；选用已有片段不覆盖其译文或语境。新建成功留在阅读器并提供打开片段入口，Segment 中可找回关联结果，普通回看不发起模型调用。

#### 本章记录与翻译标记

右上角“本章记录”提供“学习片段｜翻译”标签页，翻译按正文位置排列，相同确切出处只显示原文与最新有效成功译文，不显示语言、已留存或译文份数；历史仍可回看。正文中翻译用低强调红色虚线，片段用实线；竖排沿文字旁侧绘制，注音不加线。重叠部分不叠线，点击相连重叠记录共用“此处记录”面板，通过两个标签切换；归并不改变底层身份。新译文完成后刷新标记，回看或切换标签不发起生成，切换标签保留各自选择与草稿。

纯翻译命中直接展示最新成功译文。单条翻译从正文或页边直达详情，不显示返回列表；由列表进入时，返回箭头与记录标题同排，进入详情后焦点移到返回按钮。返回或 Escape 回列表并恢复原条目焦点，直达详情的 Escape 关闭浮卡。类型标签用紧凑行高，不另设返回／朗读工具行。译文原文右上角使用朗读图标，悬停及辅助名称为“朗读原文”，播放时换成停止图标；声音不可用和错误保留可见反馈。历史列表只显示生成时间、语言和译文，原句集中于顶部详情。

#### 朗读条与声音浮层

设置分别提供默认翻译配置和设备朗读。翻译先管理一个默认方案、目标语言及语境预算，不复制 Provider 凭据；设备声音选择和语速保存在当前浏览器，设置变化不覆盖进行中的翻译或保存草稿，输入默认值及任务快照由 [PRD 4.8](PRD.md#48-阅读翻译与设备朗读)维护。

朗读条采用一个圆角容器，播放图标、原文摘要、以短竖线分隔的语速／声音区和关闭图标不重复描边。设备支持时，朗读中可暂停、暂停后继续；未开始或不支持暂停时保留停止。结束或停止后提供重播，整体不自动收缩；设备暂停若实际结束朗读，按真实终态提供重播。关闭同时停止，关闭译文卡后播放控制仍可找到；离开阅读或片段页面停止并清理目标。

声音浮层优先在设置区上方展开并右对齐，突出原生声音选择、当前匹配声音、0.5–1.5 倍速滑块（0.1 步进）、常用预设及恢复默认；重新检测位于“更多选项”。外部点击、Escape 或再次点击入口关闭，保留键盘焦点反馈；完整错误在浮层查看，条上保留简短提示。偏好更改后短暂提示，下次播放或重播生效，继续不重建当前朗读；完整设置页提供日语试听，无可用声音或错误准确反馈。不展示音频已保存、逐词跟读或尚未接入的远端 fallback。

## 后续方向与未决事项

未来空间等待使用反馈。Source 可有多份 EPUB，手动 Segment 无需虚构材料；本轮集中材料目录限于已接入 EPUB，不扩展通用媒体框架。

按来源回顾学习、跨来源检索积累和主动学习活动具有不同职责；这不要求现在建立全部一级导航。独立Segment概览、独立Analysis页面、最终空间命名继续开放，按实际阅读与查找需求再决定。
