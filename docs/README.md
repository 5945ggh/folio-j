# 文档导航

开发前先读仓库根目录的 [AGENTS.md](../AGENTS.md)。长期规范保留在本目录：

| 文档 | 用途 |
|---|---|
| [PRODUCT_DIRECTION.md](PRODUCT_DIRECTION.md) | 产品方向讨论底稿：保留长期思路、理由与开放问题；方向性提案不自动成为实施要求 |
| [PRD.md](PRD.md) | 当前产品范围、已确认行为及 `[TBD-xx]`；产品决策以此为准 |
| [GLOSSARY.md](GLOSSARY.md) | 领域术语、身份与引用边界 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 数据关系、不变式和待细化的接口草图；草图不等于已实现协议 |
| [INFORMATION_ARCHITECTURE.md](INFORMATION_ARCHITECTURE.md) | 截至2C的阅读、讨论、导航与入口职责；区分当前落地和未来方向 |
| [TECH_STACK.md](TECH_STACK.md) | 技术选型、分发阶段与明确不选的方案 |

[handovers/](handovers/README.md) 保存当前阶段的实施指导和已归档任务书。阶段文档帮助安排工作，不能覆盖 PRD 中已确认的行为，也不能把旧任务书、实验结果或架构占位恢复成新需求。遇到未决行为，先查看 PRD 对应的 `[TBD-xx]` 与当前占位方案，再在依赖该决定的切片中细化。
