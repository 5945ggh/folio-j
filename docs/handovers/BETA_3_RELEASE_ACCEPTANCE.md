## Windows 免安装包暂缓

11 月 16 日，用户按离线材料在 Windows 构建并试用后，反馈数据目录创建与恢复仍有异常，甚至卡死；安全软件是否相关尚未确认。用户决定本轮暂缓免安装包，目录访问故障与首次目录选择交互留待独立修复。

已有 `windows-handoff`、bundle 和验证材料保留为历史候选，不再作为 beta.3 发布前置条件，本轮不继续打包或排查。后续可评估系统文件夹选择器与默认数据目录；将默认目录改到 C 盘根目录尚未决定，当前实现和产品契约不变。
