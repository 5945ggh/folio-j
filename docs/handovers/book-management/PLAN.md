# 书籍详情、信息编辑与卡片菜单

> 2026-10-19。产品行为见 [PRD 4.2.1](../../PRD.md#421-本轮材料目录与阅读管理)，页面与返回路径见[阅读与导航](../../INFORMATION_ARCHITECTURE.md)。当前状态由[实施基线](../MVP_IMPLEMENTATION_BASELINE.md)维护。

## 范围与顺序

先更新负责规范，再并行实现后端信息持久化与前端详情／共享编辑弹窗／菜单，最后集成、离线检查与浏览器验收。本轮不新增依赖，不执行模型调用，不实现移动、删除或替换 EPUB。未触及现有 TBD。

菜单在素材库、来源概览、素材视图和全部书籍窗口复用。详情只显示能够确切取得的信息，不统计同来源下的片段或讲解为本书成果。移动、删除始终禁用并标注“暂未开放”；阅读状态收到二级菜单，不附底部延期说明。

## 接口与存储契约

- `GET /api/materials/{material_id}/details` 返回 `MaterialDetailsResponse`：沿用 `MaterialCatalogItem` 字段，增加 `original_title`、`chapter_count`、`metadata_revision`、`custom_cover`。原书标题与章节数来自已保存的不可变编译包；不触发阅读打开、不准备或重算注音。
- `PATCH /api/materials/{material_id}/metadata` 接收 `MaterialMetadataUpdate`，返回同一详情响应。字段为 `title`（NFC、去两端空白、1–300 字符）、`expected_revision`（非负整数）、`cover_action`（`keep`／`replace`／`reset`，默认 `keep`）和可选 `cover`。只有 `replace` 接受且要求 `cover`，其字段为 `media_type`（`image/png`／`image/jpeg`）、`data_base64`（严格 base64，解码后上限 4 MiB）。使用现有静态图片校验器限制 1600 万像素并拒绝动画／异常文件。
- `Material` 新增独立 `metadata_revision`，初值为 0；使用增量迁移 `0012_material_metadata`。每次有效保存核对修订并在短写事务内原子更新书名、自定义封面和修订，陈旧提交返回 409；与阅读位置及阅读状态的 revision 分开。
- 自定义封面保存在独立 `material_custom_covers` 表（`material_id`、`media_type`、`data`），不混入可重建的 `material_covers` 自动缓存。恢复原书封面仅清除自定义覆盖，回到现有自动提取／占位规则。
- 目录和详情封面 URL 带信息修订，避免编辑后继续使用旧图片／失败状态；封面读取优先自定义覆盖并保留 Source 存活检查。缓存重建发布后仍须保证自定义覆盖优先。
- 编辑不修改 `source_id`、原始字节、字节摘要、材料与版本身份、不可变编译包、阅读位置、使用状态、历史注音代次或 Source 标题。重导相同字节复用已有材料，保留用户信息。
- 所有业务读取、写入及封面请求均检查 Source 存活；源删除与陈旧编辑不能绕过门禁。路由只负责调用服务，客户端类型通过 `just gen-api` 生成。

## 验证

后端覆盖详情无阅读副作用、信息原子保存、同字节重导保留信息、冲突与删除门禁、无效图片／类型／大小、封面恢复及缓存重建、不可变内容与阅读记录保持、空库迁移和存量增量迁移。前端纯逻辑覆盖草稿／保存意图及安全返回路径。

集成后运行 `just lint`、`just test`、`just build`、`just check-docs` 和 `git diff --check`。浏览器实际检查素材库与来源中的菜单、禁用项、详情返回路径、编辑书名／封面／恢复封面、取消草稿、失败与窄屏。结果记录于 [ACCEPTANCE](ACCEPTANCE.md)。

## 用户反馈后的界面清理

先保留并运行已有书籍信息与返回链回归，再调整菜单行为、详情布局及旧样式。阅读状态收到二级菜单，补齐进入／返回、键盘和禁用项回归后实现；删除底部延期说明，压缩宽度与行间距。详情使用素材库现行外壳、紧凑页头及左对齐信息布局，保留接口、编辑与阅读返回链。

并行只读审计旧设置页面及 CSS 的引用。只删除确认无运行时引用的旧选择器。用户进一步要求清理暖色遗留外壳：将现行灰蓝导航、白底与蓝色操作提升为公共默认，删除暖色外壳及重复覆盖；回归片段工作台、加载／错误页、设置与阅读器。最后独立审查清理范围，运行工程检查，并用浏览器对照素材库、来源目录及设置页验证桌面、窄屏和来源书籍窗口。
