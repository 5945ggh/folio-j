## 范围与实现

保留现有浅色视觉、尺寸与页面布局，补齐应用浅色、深色与跟随系统。设置增加“外观”分类，本浏览器即时保存颜色选择；读取设置 API 失败不影响外观页。启动脚本在首屏绘制前恢复颜色选择，运行中的系统变化与其他标签页选择由同一主题控制器处理，Storage 不可用时保持内存选择。

公共页面接入语义颜色变量，保留原有浅色差异；阅读器继续独立选择纸面。阅读器颜色以 CSS 为单一来源，显式桥接到 EPUB iframe，纯配色更新与字体／注音事件绑定分开。设计与维护规则见[设计系统](../DESIGN_SYSTEM.md)，偏好与呈现机制见[前端架构](../ARCHITECTURE.md#6-前端结构)。

本轮没有新增依赖、修改数据库或 API schema，也未改变既有 TBD 决策。其他阅读器重构与用户 CSS 留待后续。

## 浏览器观察

验证使用本机隔离 Chrome、真实 React 页面与 Router／QueryClient，以及模拟 API；不访问真实网络或模型。

- `app-theme` 的 1280／390px 与系统浅／深四种组合通过。设置选择、独立浏览上下文恢复、真实 storage 事件与系统媒体变化均生效。素材库及导入弹层、来源、书籍详情与统计错误、服务设置弹层、片段／讲解／讨论在浅／深模式下布局完整，采样文字对比度最低为 4.50:1。
- `theme` 的 1280／320px 与系统浅／深四种组合通过。覆盖阅读器确认框、讲解预览、目录进度、错误、作者 CSS 优先级、图片与原文节点身份；采样文字对比度最低为 4.67:1。
- 长章节定位第 350 段、非零滚动后往返切换纸面，原文屏幕坐标、iframe／Document／定位叶子与 ruby 身份、原生选区保持稳定，字体／注音样式未重写，稳定后的观察窗口中没有额外位置 PUT。
- 人工查看浅色外观页、深色外观页、390px 导入弹层及桌面片段／讨论截图：保留原有布局与层次，深色控件和正文可辨，窄屏导入弹层位于屏内。

浏览器检查发现并修复了隐藏文件输入被公共表单宽度撑大，以及深色主按钮白字对比度不足；无溢出与对比度断言均保留。离线浏览器 runner 关闭 HMR 与文件监视，避免其他工作区编辑触发测试页面重载。

首轮完整回归在 `inline-records` 的字体调整后重开译文用例失败。因果隔离确认：将旧动画收尾放在布局更新回调内，已经晚于锚点采样。最终由 `ReaderLayout.commit` 按既有几何判定调用采样前的 `stabilize`，纯配色与普通行内重排不进入该准备步骤；精确失败用例与长章节主题保持用例均已重新通过，原断言保留。

后续 `chapter-records` 的旧断言只接受样式源码中的十六进制常量，不能识别新变量规则。现改为读取实际 `::highlight()` 的计算颜色并解析 RGBA，继续验证实线与虚线同色、红色语义及虚线较低透明度；11 组本章记录回归均通过。

目录概览首次打开导入弹层时，来源选项由独立查询加载。完整回归暴露旧测试仅等待弹层打开便读取原生 select 的竞态；现先等待预期来源选项出现，再保留原有来源值、禁用状态与请求归属断言。1280／390／320px 三组回归通过，生产行为未修改。
