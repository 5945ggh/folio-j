# 素材库 A.1 实施与回归计划

2026-10-05 实施安排。用户已选择 A（轻原生）；离线原型检查不作为生产证据。验收证据与限制见[本轮验收记录](ACCEPTANCE.md)，当前交付与提交状态见 [MVP 实施基线](../MVP_IMPLEMENTATION_BASELINE.md)。

## 范围与顺序

1. 将已确认行为同步到 PRD、信息架构；保留上一轮验收的历史身份。
2. 先锁定空库／无结果／加载／失败、状态版本与导入迟到响应、阅读返回恢复的已有行为，再分小增量调整素材库工具栏、书卡与整区空库入口。公共控件可复用，页面不强制共用外壳。
3. 独立修复声明封面优先、稳定有序首张可用包内图片回退与版本缓存；用合成 EPUB 覆盖声明异常、损坏首图、无图、安全限额、旧失败缓存。不得改写不可变材料或要求重导。
4. 集成后执行 `just lint`、`just test`，使用独立测试库进行浏览器验收；两本真实样书仅在用户本机验证，不发布参考封面。

## 验收与边界

- 检查真空库全区点击、Enter/Space、导入取消／完成焦点；搜索与筛选可见可清除、无结果、加载、失败与重试。
- 检查真实封面／旧缓存、菜单与状态错误恢复、单页／多页、长标题、桌面／窄屏、导入已有／新来源、阅读返回后的条件与位置。
- 检查来源页、Reader、Segment 工作台的已有导航、状态与恢复无意外回归。保留来源删除门禁、导入归属与迟到成果保护。
- 不重做 Source 三视图、阅读器或工作台；不新增书架、进度、播放器、删除／元信息编辑、Occurrence 等未来能力。

具体候选顺序与缓存实施规则见[封面工程契约](API.md)，代码集成后核对。长期行为见 [PRD](../../PRD.md#421-本轮材料目录与阅读管理)及[信息架构](../../INFORMATION_ARCHITECTURE.md)。
