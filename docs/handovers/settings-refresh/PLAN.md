# 设置页顶部分类调整

2026-10-15，用户选定视觉草稿中的“顶部分类”，授权据此调整实际实现。主代理负责范围、接口、集成与验收，实施子代理按文件分工，完成后独立 CR。

## 范围与约定

- 复用素材库主导航的宽度、底色、品牌与选中态。设置使用紧凑页头和学习偏好／模型与服务／对话与权限三个顶部分类，窄屏保持可达。
- 学习背景、讲解预设及默认预设放在学习偏好；讲解／讨论默认模型与服务列表放在模型与服务；新对话权限单独保存。条目整理模型保留存储值，当前界面说明功能尚未开放。
- 服务列表采用紧凑摘要，详情承载模型管理、连接配置与该服务验证记录；全局验证历史从模型页次级入口进入。保留模型发现、手动／批量登记、启停、凭据管理、协议覆盖、参数、删除确认及普通／流式验证。
- 新增和编辑使用一致的模态表单。未保存修改由明确保存／放弃管理；分类、站内导航、浏览器前后退与刷新受保护。保存失败保留草稿，保存中不允许误导性的取消，后续输入使“已保存”失效。
- 草稿及密钥不写入浏览器持久存储。验证继续由真实后台状态驱动，不将视觉草稿的模拟结果带入产品。

## 接口与文件分工

1. 后端及回归测试：新增 `PATCH /api/settings`，仅更新提交的 profile／defaults 字段；同次学习背景与默认预设保存原子提交。未提交的失效模型不阻止其他分组保存。保留既有 PUT 接口；验证历史增加服务、模型与状态筛选。同步 OpenAPI 和生成客户端。
2. 设置页、表单与草稿管理：`SettingsPage`、`LearningSettings`、新增默认模型／权限表单、共享编辑弹窗及导航保护、设置主样式、`main.tsx` 与设置 API 客户端。共用生成类型，不新增依赖。
3. 模型服务界面：`ProviderSettings`、相关拆分组件、`RunHistory` 及服务专属样式；使用共享编辑弹窗，不改其他代理拥有的文件。
4. 主代理：文档同步、独立 CR 派遣、完整检查与隔离数据库浏览器验收。

共享编辑弹窗放在 `frontend/src/settings/SettingsForms.tsx`，导出 `SettingsEditorDialog`：`id`、`title`、`dirty`、`pending`、`save: () => Promise<boolean>`、`onClose`、可选 `className`，`children` 为接收 `requestClose` 的 render prop。组件统一保护关闭与导航，真实保存回调自行报告错误。设置页其他表单通过同模块的草稿注册入口参加导航保护。

## 实施与验证顺序

先补齐缺失的行为回归，再调整对应实现；保留现有模型验证测试。分步覆盖部分更新不覆盖无关字段、无效输入原子失败、验证历史筛选分页、草稿修改／重置／保存快照和导航判断。

集成后运行 `just lint`、`just test`、生产构建、文档检查与 `git diff --check`。独立 CR 关注状态竞争、未保存保护、错误／空态、已有接入能力与路由回归。

浏览器在独立数据库和离线适配器下检查桌面与窄屏：三类设置、保存再修改、保存失败、离页继续／放弃／保存后切换、弹窗取消与返回、服务和模型管理、发现缓存与验证状态、历史筛选，以及素材库／阅读器导航。不得写入日常数据或调用真实模型。实际结果写入本阶段验收记录。
