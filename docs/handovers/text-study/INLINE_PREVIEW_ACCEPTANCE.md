## 已实现行为

正文细线覆盖的基字支持普通轻点，单片段直接预览，多片段先选择；页边入口改为扁平符号和数字。预览复用现有 Segment 与 Analysis 读取，原文置顶为浅底引用块，随后呈现已有译文、讲解与备注。多份讲解可切换，正文标题及确切修订保留；默认紧凑，可展开右侧覆盖式阅读侧栏，收起后继续阅读。

字符级实际 Range rect 决定命中，整段可见范围决定浮卡锚点，两个范围分开。拖动、长按、非折叠选区、修饰键和扩展控件不触发预览。按需注音在事件分发结束后检查消费状态，标记轻点只打开预览。双击未增加等待优化；首击可先显示预览，原生选择形成后以选区为先。

独立审查发现并修复：触屏 ruby 同次切换注音与打开预览、预览内 Tab 被选区工具栏抢走、正文 H1 被展示整理遗漏、展开时未使旧导航请求失效。定点复审通过。浏览器验证另发现两行原句被浮卡遮挡，已将定位锚点扩大到当前 frame 的完整可见目标，点击命中仍限实际字符。

### 段尾译文平滑开合（2026-10-24）

本轮以 `b3d90d7` 为代码起点，在工作区补齐后文位移与译文淡入淡出。用户试看后反馈位移偏快，时长从 200ms 调整为 300ms，缓动使用 `cubic-bezier(.25,.1,.25,1)`，减缓起步。未新增依赖、后端 schema、模型调用或 TBD 决策。

展开只插入一次最终高度，再对受影响的后文和后续 iframe 做 FLIP；收起保留译文占位，让后文先平滑回位，结束时一次移除占位，避免 iframe 缩短裁掉正在移动的末尾内容。页边按钮等待 React 提交新坐标后续接位移；普通块使用 transform，独立换行叶等 inline 内容使用临时相对 top，结束精确恢复原样式文本，并保留动画期间其他声明的修改。作者变换、休眠 inset 等复杂布局保留原样式并跳过位移。

同一译文在收起期间再次展开会复用节点，反向淡入并取消旧关闭计时器。跨目标切换保留当前视觉位置，前后 iframe 与内部正文的位移分别合成；标记重测暂时移除视觉效果读取 canonical 几何，随后恢复动画。原生滚轮、选区与设置重排先完成当前位移，再采样稳定位置；切章、销毁和减少动态效果模式清理动画。
