# 阅读器原处预览验收

2026-10-23，实施起点 `54214a2`，分支 `codex/reader-inline-preview`。实现已提交 `cbf5851`；用户认可当前视觉效果，并确认在实际阅读中继续迭代。未新增依赖、后端 schema、模型调用或 TBD 决策。

## 已实现行为

正文细线覆盖的基字支持普通轻点，单片段直接预览，多片段先选择；页边入口改为扁平符号和数字。预览复用现有 Segment 与 Analysis 读取，原文置顶为浅底引用块，随后呈现已有译文、讲解与备注。多份讲解可切换，正文标题及确切修订保留；默认紧凑，可展开右侧覆盖式阅读侧栏，收起后继续阅读。

字符级实际 Range rect 决定命中，整段可见范围决定浮卡锚点，两个范围分开。拖动、长按、非折叠选区、修饰键和扩展控件不触发预览。按需注音在事件分发结束后检查消费状态，标记轻点只打开预览。双击未增加等待优化；首击可先显示预览，原生选择形成后以选区为先。

独立审查发现并修复：触屏 ruby 同次切换注音与打开预览、预览内 Tab 被选区工具栏抢走、正文 H1 被展示整理遗漏、展开时未使旧导航请求失效。定点复审通过。浏览器验证另发现两行原句被浮卡遮挡，已将定位锚点扩大到当前 frame 的完整可见目标，点击命中仍限实际字符。

## 页边入口原生滚动、重复点击与卡片精简（2026-10-23）

本次基于 `bb632aa` 整理提交。页边入口改用片段首处原文的内容坐标，作为正文滚动容器的绝对定位子节点；横排左右留白、竖排底部留白容纳入口，可读正文尺寸保持原值。滚动不重新测量、夹紧到视口或改变分组；排版与资料变化时重建几何。44px 点击区域限制在既有章节范围内，防止末段入口撑出额外空白。再次点击同一入口收起浮卡，点击其他入口切换；合组入口遵循相同行为，并同步 `aria-expanded`。

卡片底部将“保存信息”与“打开片段”放在同一行，移除保存信息上方与旧独立操作区的分隔线；展开后的保存详情在整行下方显示。浏览器已验证折叠与展开效果。

实际浏览器检查横排正文宽度为 760px、竖排列高为 558px；竖排 `scrollLeft` 从 -77px 变为 -185px 时，正文与三个入口均横向移动 108px，入口内容坐标保持不变。横排也保持原文与入口同步移动；两种排版均验证重复点击收起。

离线组件浏览器回归使用原创合成章节和完整 API mock，覆盖 600px 与 1280px 视口：窄屏隐藏无留白的横排入口，正文宽度保持 564px；宽屏覆盖横排／竖排、单片段和合组开关、入口切换、滚动同量、字号重排与切章清理。无尾边距的末段另行比较入口显示／关闭后的 `scrollHeight` 或 `scrollWidth`，确认章节滚动范围不变。运行器通过 Chrome 管道等待真实渲染终态，避免虚拟时间推进与 scroll／ResizeObserver 回调竞争；没有新增依赖或调用真实模型。

独立审查发现的末段入口溢出已修复，定点复审通过。`just lint`、`just test`（后端 570 项、前端 401 项）、`just test-browser`、`just build`、`just check-docs` 与 `git diff --check` 均通过；构建保留既有单个 JS bundle 超过 500kB 的提示。未新增 TBD 决策；实体触屏仍未实测。


## 页边点击、入口定位与翻译卡片（2026-10-24）
