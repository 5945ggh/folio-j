# 文本与资料调整验收样例

2026-10-20，S0 固定验收输入与预期。规则见 [PRD](../../PRD.md)、[架构](../../ARCHITECTURE.md)；切片和范围见[计划](../archived/text-study/PLAN.md)。这些是测试要求，不表示已通过；各切片实际结果见对应验收记录；B1／B2 之后推进 A1／A2，C 样例保留至对应实现。

## B1 行为基线

| 样例 | 应证明的结果 |
| --- | --- |
| 普通 NFC 日文、空资源、含非 BMP 与 ruby 的编译正文 | 仅文本资源即可分析；改动前后配置、完整 payload、摘要与记录数一致 |
| 同 resource_id 在 spine 重复两次 | B1 保留两次输出；完整结果与章节投影的既有语义明确 |
| `㍿` | 正跨度与零跨度记录均保留，表层与原始码点可核对 |
| 分块边界及超字节预算 | 资源正文可重建、偏移不漂移，不把 chunk 当句子统计 |
| 首次导入、重建失败、相同结果重建、迟到完成、Material／Source 删除 | 既有发布原子性、代次复用、旧结果保留与删除门禁保持；独立删材料保留学习积累，重导身份不复活旧请求 |

## B2 可手工核算的统计

纯逻辑样例使用明确构造的词法记录，测试统计规则；另用真实本地 Sudachi 覆盖输入适配。构造记录不冒充真实词典的切分结果。

基础资源 r1 的正文为 `猫猫犬。\n`，词法记录为猫、猫、犬、句号和换行；r2 正文为 `猫鳥`，词法记录为猫、鳥。过滤标点和空白后，N=5，V=3，H=2，H/V=2/3；频次为 3、1、1，80% 需 2 种、90%／95% 需 3 种。字符数为 7，不同汉字 3，单次汉字 2。

| 变化／边界 | 应证明的结果 |
| --- | --- |
| r1 再出现一次 | 统计仍为基础值；B1 原始资产不被去重改写 |
| 新 r3 与 r2 文字相同但 ID 不同 | 新资源分别计入，不能按文本摘要去重 |
| 同 ID 正文摘要或分析结果不同 | 明确失败，不静默选第一条 |
| `㍿` 的正跨度／零跨度词法记录 | 只计算正跨度记录，原资产保留全部元数据 |
| 飲ん、飲み 的词典形均为飲む但读音不同 | 合并同一统计键；不以读音拆开 |
| 空字典形、空白和 `*` | 回退 surface；过滤集合与回退行为集中定义 |
| 助词、助动词、数字、OOV | 合法正跨度记录保留，OOV 不代表学习者未知 |
| 空文本、纯标点、全过滤记录 | N/V/H 为 0，比率和阈值为 null，曲线为空 |
| 扩展区汉字、兼容汉字、々、〇、假名、非 BMP | 严格执行选定 Unicode 名称规则与码点计数，记录 Unicode 版本 |
| 大于 512 词种、多个阈值落同一点 | 返回点数有界，首尾与阈值保留，阈值来自完整序列 |
| 无代次、切代次、切规则、改标题／封面／usage／位置 | 正文与词法依赖分开；元信息不触发重新计算 |
| 同键并发、容量淘汰、失败重试、等待中删除来源 | 计算合并、内存与并发有界、可重试，不返回删除资料 |
| 详情失败／加载／空态、窄屏及返回目录 | 统计不阻断页面，说明准确，不触发阅读打开或分词准备 |

## A／C 样例

| 切片 | 固定验证场景 |
| --- | --- |
| A1 | 无模型配置直达确切修订；首次回看无工作台查询；启动后收起保留草稿、审核说明与待核实提交 |
| A2 | 两页面修改原文／讲解竞争、响应丢失重放、同键改 payload、无变化保存、失败不锁、删除不解锁、旧数据保护 |
| C1 | 同章连续多范围、相邻范围拆分归一、重复 spine、乱序重叠／跨章拒绝、NFC 组装、跨 Source 拒绝、删除竞争；材料删除保留片段与历史出处，重导不换绑 |
| C2 | 单 iframe 跨 DOM 选择、原书 ruby／全量注音、非 BMP／跨节点 NFC、重排、迟到 frame、准备失败后保留目标、多范围全部高亮 |

浏览器多范围回读由 API fixture 预置同章出处，不能用原生跨 iframe 拖选假设代替。验收证据记录测试库、样例来源、实际命令、页面观察及限制。

## C2 自动预装语境固定验收场景

C1／C2 的固定验收场景；原实施结果见 [C2 验收](../archived/text-study/C2_ACCEPTANCE.md)，后续调整见[阅读体验记录](../archived/text-study/READING_EXPERIENCE_ACCEPTANCE.md)与[保存表单验收](../archived/text-study/SEGMENT_SAVE_FORM_ACCEPTANCE.md)。产品规则以 [PRD 4.7](../../PRD.md#47-当前-epub-阶段安排)为准；这里固定输入与观察项。未另说明时，自动预装开启，前／后各至多 3 句、200 Unicode 码点；`【】` 仅标记目标选区，不属于正文。

| 编号 | 固定输入／操作 | 应证明的结果 |
| --- | --- | --- |
| C2-01 | 普通划选后取消；重新划选，点击“保存为学习片段”，移动浏览器选区，再取消或最终提交 | 普通划选不调用模型、不保存；点击入口固定草稿目标与出处，后续浏览器选区变化不改草稿；取消不创建 Segment、不固定原文，最终提交才原子创建片段、出处并固定原文 |
| C2-02 | `前一。前二。左残【学ぶ】右残。後一。後二。後三。`，使用默认预算 | 前文为 `前一。前二。左残`，后文为 `右残。後一。後二。`；从目标两侧向外取，当前句未选残部各计该侧一句，目标不占预算，输出保持阅读顺序 |
| C2-03 | 一侧有 4 个短句；另一侧有 1 个短句；分别使句数先达上限和字符数先达上限 | 句数与字符数同时作为各侧上限；满足先到的限制就停止，不为用足预算扩取，也不把一侧剩余预算借给另一侧 |
| C2-04 | 将字符上限设为 100；分别把前句数、前字符数、后句数、后字符数设为 0，再测试负数和非整数 | 支持 100 等非负整数；任一侧句数或字符预算为 0，该侧为空，另一侧按自身预算；拒绝负数及非整数 |
| C2-05 | 目标前为 210 个 `あ` 加 `。`，目标后为 210 个 `い` 加 `。`；字符上限各 200 | 前文保留最靠近目标的 199 个 `あ` 加 `。`，后文保留最靠近目标的 200 个 `い`；两侧均标记截断，字符硬限优先于完整句界，不裁掉邻近内容以保远句 |
| C2-06 | 含空格、换行、标点、非 BMP 字符及分解形式 `カ`＋结合浊点；原书 ruby／自动注音开关前后重复预装 | 在不可变 NFC 正文上确定目标与原句界，按整理副本整体 NFC 码点计预算；保留的内部空格、LF、标点及非 BMP 各按码点计。排除 rt／rp 与应用文字，读音显示不改变结果，不用字节、UTF-16 单元或模型 token 计数 |
| C2-07 | 同章相邻 part 的前后文、章首／章末、重复 spine 中不同出现位置；界面尝试跨 iframe 拖选 | 语境可按章内 part 范围跨 part 获取，章边界停止；重复 spine 按实际阅读顺序和出现身份取文；目标选择仍限单 iframe，不截断跨 iframe 选择后冒充完整目标 |
| C2-08 | `「行く。」と答えた。次だ。`、`本当！？　そうだ。`、由换行分开的两个无终止标点段落 | 实施前先为各 fixture 固定句界与精确预期，再测试预算；引号、连续标点不产生空句，无终止标点段落有确定的计句规则，不能仅以总长度正确替代句界验收 |
| C2-09 | 自动预填后编辑或清空任一侧，另用“清空前后文”同时清空两侧；先编辑或清空，再应用延迟预填结果 | 两侧均可单独编辑、清空，也可一键清空；清空计为编辑，不被迟到预填覆盖，取消时保护草稿；最终保存用户确认的内容，两侧为空也可仅保存目标 |
| C2-10 | 本次保存流程内收起再展开已编辑草稿，在草稿内调整取文范围；另在学习偏好页修改默认自动预装开关，再打开新草稿或已存片段 | 草稿内仅提供范围配置，默认开关由学习偏好维护；收起再展开、范围或默认设置变化和迟到结果不覆盖现存草稿或已存前后文；默认关闭时新草稿不预填，仍可手填或仅保存目标 |
| C2-11 | 对已编辑草稿明确执行重新摘录；另在默认自动预装关闭时新建草稿后主动摘录；随后更换目标并应用旧目标的延迟结果 | 显式摘录采用执行时的目标及范围，不受默认预装开关限制，也不改写默认设置；有已改内容时先保留草稿供用户决定替换；调整范围本身不覆盖草稿，更改目标使旧结果失效 |
| C2-12 | 同一确切出处出现已有 Segment 候选，用户显式选用；另用无匹配出处新建 | 选用已有 Segment 保留其前后文，不用新预填覆盖；新建按当前草稿保存；相同文字或出处候选不触发静默复用 |
| C2-13 | 语境预装失败后手填或仅提交目标；另让材料出处校验失败、材料删除或版本不符 | 预装失败仍保留目标及出处草稿，可重试、手填或仅保存目标；出处校验失败则不保存，不留下片段或原文固定等部分成果 |
| C2-14 | 预填后手动输入超过自动字符预算但符合既有输入限制的前后文，修改预算并保存 | 自动预算不裁剪手动输入；保存沿用既有输入限制，预算变化不重写用户内容；改写内容不继续标为逐字原书引用 |
| C2-15 | 划选、预填、编辑及保存后检查调用记录；明确启动模型，再编辑已存前后文并启动下一任务 | 只有明确启动模型才产生调用；任务使用启动时已存语境并保存输入快照；后续编辑只影响新任务，不回写历史任务；语境不扩大目标解析范围 |
| C2-16 | 多范围出处回读、字号／横竖排变化、迟到 iframe、准备失败，以及 C1 出处保存竞争 | 继续满足上表 C1／C2 的原有样例；自动预装不改变目标范围、全部范围高亮、精确出处校验与失败保留目标的要求 |
| C2-17 | 保存学习偏好的语境配置，刷新后在另一材料打开新草稿；在草稿中临时调预算，再开另一新草稿 | 已保存默认值跨材料生效且刷新后保留；本次临时调整只用于当前草稿，不改写默认设置，配置保存不覆盖现存草稿或已有片段 |
| C2-18 | 标题加多空行、内部纯空白行、CRLF、Unicode White_Space、FEFF／零宽与变体选择符；预算正好完整或停在句间空白 | 只整理两侧副本，保留原句界与句内内容；按整理后 NFC 码点预算取近端，纯空白及没有新正文的句间裁切不假截断；调用前后章节、预算、exact、摘要与 spine 深比较不变 |

句界、混合长短句截断与 Unicode 选区的精确输入见 [C2 精确样例](C2_EXACT_CASES.md)。本轮新增副本整理、Unicode White_Space、CRLF、句间空白预算及深比较出处不变的固定样例；保留原分句输入及坐标。运行纯逻辑测试时使用本地固定正文，浏览器测试核对草稿、保存时机、调用记录及迟到结果；不访问真实模型。

## C2 阅读标记与只读出处验收

| 场景 | 预期 |
| --- | --- |
| 正文单击、拖选、双击、键盘扩选与复制 | 片段功能不处理或延迟正文点击；原生选择结束显示保存入口，固定本章列表和草稿不因正文操作关闭 |
| 新建／选用成功 | 留在原文与原位置，提示不抢焦点；关闭、超时或明确打开分别生效，悬停／焦点期间暂停计时 |
| 横竖排页边入口、密集与重叠范围 | 至少 44px 点击区域只放真实正文外留白，空间重叠聚合；竖排优先下侧，无足够空间则只用本章列表，不改变正文宽度 |
| 固定本章列表与跨资源出处 | 两项标记隐藏也可进入完整列表；列表保持横排，以创建时间和完整 ID 区分同文。hover／focus 强调全部范围，明确打开才导航 |
| 超过 100 条记录、扫描页为空、查询失败 | 取完全部游标页再开放完整列表和标记；加载及失败独立显示，不冻结半份候选或复用失效缓存 |
| 两项偏好与旧值兼容 | 下划线和页边入口独立，默认 true；新字段优先，缺项分别从旧 studySegments 回退，false→false、true／缺省→true；跨书、刷新及 storage 跨标签同步 |
| 滚动、重排、切章、旧 frame 或删除 | 贴句面板随滚动关，固定列表可保留；重排清临时强调及旧页边入口后重测，切章及失效清理旧候选，切换操作保护草稿 |
| ruby、字号、窄屏与搜索 | 基字细线不影响排版，注音无细线，页边入口不覆盖正文；窄屏本章列表可用；黄色搜索高亮独立 |
| 普通、重复 spine、跨 part 与 NFC 出处显示 | 总长 10 起点 0／3→0%／30%，总长 3 起点 1→33%；长 10 资源重复两次，第二次起点 3→65%。跨 part 只取第一段起点；跨 NFC 组合边界省略百分比 |
| 改名、删除、错误版本与快照失配 | display 读取当前可靠名称；全部验证成功才附章位置，否则只保留可靠材料名和原状态，不补造 0%；source_ref 不变且显示为出处补充／出处说明 |

本轮证据见[阅读体验记录](../archived/text-study/READING_EXPERIENCE_ACCEPTANCE.md)；[原阅读标记验收](../archived/text-study/READER_MARKS_ACCEPTANCE.md)保留当时行为、数字与限制。
