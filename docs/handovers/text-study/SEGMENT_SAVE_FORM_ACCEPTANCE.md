# 学习片段保存表单验收

2026-10-22，代码起点 `b4dbd93`，分支 `codex/reading-experience`。本轮调整保存表单的信息层次、两行语境预览、阅读器主题、摘录设置入口和双侧清空；不变更 API、数据库或模型调用协议，未触及 TBD。

## 行为与独立复核

- 删除目标固定、空白整理和预算范围等常驻小字说明；来源、原文、语境与操作分别呈现。
- 前后文默认各预览至多两行，展开后编辑全文；保留自动摘录、已编辑和截断状态。折叠项的可访问名称只包含侧别与状态，完整文字由编辑框提供。
- 配色使用阅读器主题变量；面板主体独立滚动，标题及保存栏保持可见。
- 草稿内只保留四项摘录范围和明确的重新摘录操作。学习偏好的默认开关决定新草稿是否自动预填，主动重新摘录不受该开关限制，也不改写默认配置。
- “清空前后文”同时清空两侧，展开后仍可单侧清空。两侧都为空或保存锁定时禁用一键清空；清空计入编辑保护。

独立审查发现 CSS 截行不会缩短读屏名称，已用 `aria-labelledby` 和视觉预览的 `aria-hidden` 修正。增量复核确认首个 legend 中的一键清空按钮显式受锁定状态约束，连续两次编辑使用同步更新的草稿引用，保留两侧清空与迟到结果保护。

## 浏览器观察

使用 Codex 内置浏览器。初次在本地开发服务检查草稿，随后以 SQLite backup 从本地库创建 `/tmp/folio-segment-panel-review/app.db`，在 `127.0.0.1:8012` 托管构建产物。片段保存和默认摘录配置修改均在隔离副本完成；样例来自用户本地 EPUB，不是模型响应录制。

| 场景 | 实际观察与证据 |
| --- | --- |
| 明色默认表单 | 原文为视觉主体，前后文各两行，设置默认收起；两段已删除说明不再出现。[明色界面](evidence/segment-save-form/light.png) |
| 暗色主题 | 背景、原文卡、语境正文、边框及保存按钮随阅读器主题切换。[暗色界面](evidence/segment-save-form/dark.png) |
| 390px 窄屏 | 面板与按钮未横向越界；展开摘录设置后主体可滚动，保存栏仍在视口内。[窄屏界面](evidence/segment-save-form/narrow.png) |
| 编辑、收起与重新摘录 | 手工追加语境后重新摘录显示替换提案，原字段保留手工内容；选择保留草稿后收起、再展开，手工内容仍在。 |
| 双侧清空与保存 | 一键清空后两侧均标为已编辑，按钮禁用；取消时出现放弃草稿确认。隔离库中清空后保存成功，并核对最新 Segment 的 `context_before` 和 `context_after` 均为空，目标原文保留。 |
| 默认关闭后主动摘录 | 在隔离副本关闭默认自动预装，重新加载并建立草稿时两侧为未添加；进入本次摘录设置并主动重新摘录后，两侧都有内容且标为自动摘录。 |

## 工程验证与限制

- 语境与草稿定向测试 64 项通过，包含新增双侧清空后迟到预填不覆盖空值、保存仍保留目标出处的回归。
- `just lint`、`just test`、`just build`、`just check-docs` 和 `git diff --check` 通过；完整测试为后端 510 项、前端 357 项，0 失败。
- 构建仍有既有的单包超过 500kB 提示；本轮未调整打包策略。

窄屏为浏览器视口模拟，未使用实体触屏设备，也未实测读屏软件。浏览器未注入延迟预填；迟到结果保护由纯逻辑回归验证。原型参考包的历史交互声明与本表单验收分别维护。
