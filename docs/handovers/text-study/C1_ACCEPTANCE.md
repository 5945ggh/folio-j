# C1 材料出处验收

2026-10-22。代码起点 `dda3bf9`，以本轮未提交的现行规范更新为需求依据；用户已覆盖此前 C 暂不实施安排。范围为 [PLAN 第 9 节](PLAN.md#9-c1-稳定材料出处与校验)。

## 交付与独立审查

新增 `segment_material_provenance` 一对一记录及 `0004_segment_material_provenance` 增量迁移。Segment 创建入口接受可选材料出处和 UUID request_id，服务端校验同 Source、版本、spine、资源正文摘要、exact 和同章连续性；规范合并相邻范围后整体 NFC 组装目标。片段、出处、幂等依据和原文固定同事务提交。

新增历史出处解析、确切出处的有界候选匹配及显式选用复核接口。材料独立删除保留片段及历史出处；重导不换绑；Source／Segment 删除继续阻止读取。人工 Segment 保持兼容。OpenAPI 与前端类型已由 `just gen-api` 生成，手动表单从生成的 SegmentUpdate 取字段类型。

实现和测试分别由 `c1_backend`、`c1_tests` 负责，独立审查者 `c2_case_review` 检查事务、范围与读取门禁后通过。审查及测试期间修复了人工创建的关系懒加载回归，并补上单范围跨 part 时跳过中间正文的拒绝检查。没有未解决阻塞项。
