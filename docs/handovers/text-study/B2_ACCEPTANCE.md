# B2 文本统计与书籍详情验收

2026-10-20，接续 B1 提交 bb900ce；本次仅实施 B2。A／C 生产行为未改，未新增依赖或数据库迁移，既有 TBD 未关闭。

## 结果

普通文本资源可直接调用 `nlp/statistics.py`，获得字符／汉字和词法统计。后端独立 GET `/api/materials/{material_id}/statistics` 绑定版本及可选确切代次，返回冻结汇总和最多 512 点覆盖曲线。详情新增七项指标、80%／90%／95% 阈值与口径说明，不加载阅读器或全书 token。

正文和词法缓存分别依赖规则及输入身份；每应用实例内存有界、同键计算合并、并发与等待有上限，关闭排空线程。缓存前及计算后重验可见性；没有分词结果仍返回正文统计。API 与生成客户端同步提交。

## 浏览器观察

在独立 SQLite 验收库中使用仓库自制 EPUB 与追加的合成样例；无 Provider、无真实模型。开发服务器及 FastAPI 托管的构建版均实际打开，桌面视口 1280×900、窄屏 390×844。

- 普通书显示词次 30、词种 24、单次词种 19、比例 79.2%、字符 64、不同汉字 20、单次汉字 14；覆盖阈值分别为 18／21／23 种词。
- 窄屏指标为两列，曲线与阈值可读，document.scrollWidth 与视口同为 390，无水平溢出；桌面布局和折叠说明正常。
- 无 current 代次时仍显示字符／汉字，词法指标为“—”，明确尚未准备；空正文数量为 0、比率／阈值为“—”、曲线为空。
- 在测试库暂时注入坏分词资产，统计显示失败和重试，书籍信息及阅读入口仍可用；恢复原资产后点击重试成功，纯标点得到 0 词次和空曲线。
- 编辑测试书名后标题更新，统计结果保留，服务日志中该书 statistics GET 次数保持 3；返回素材库并由书卡重新进入详情后正常读取。
- 读取详情／统计期间没有 prepare、opened、聊天或模型请求。合成封面无可解码图片时沿用现有封面占位与重试入口。

桌面与窄屏截图、benchmark.json 保存在本聊天的本地产物目录 `folio-j-b2`，最终回复提供截图；测试库和故障注入仅位于本次临时目录，不写入日常库。

## 合成大文本与副作用核对

FastAPI 进程重启后对 180,000 码点、115,000 有效词次、2 个资源的合成文本请求统计：首次 HTTP 请求 **0.6563 秒**，缓存命中 **0.0038 秒**，响应 **1,538 字节**，正文与词法缓存结果合计 **1,090 字节**。样例词形重复较多，这些数值只说明该样例的运行结果，不代表真实长篇或所有硬件的性能保证；高词种数的 512 点边界由纯逻辑样例覆盖。

重复 spine 样书与普通样书的正文／词法统计完全一致。对普通、重复 spine、空正文、纯标点、无分词和合成大文本分别冷读与缓存读，前后数据库的 Run、usage、全书／章节位置、线程、Job 数量均为 0；分词代次数量保持 6，当前指针保持 5。证明统计读取没有隐式分词或阅读／模型副作用。

统计按当前资源范围和词典形规则解释，不提供难度、个人掌握率、逐汉字读音、自然句长或跨材料汇总。既有重复 spine 章节注音响应语义继续保留，统计去重不反写阅读资产。
