## 范围与实施顺序

资料阅读与编辑统一三组顺序，固定原文改为紧凑只读文字，复用精确出处核对。讨论面板整理顶部、消息与输入层级，保留当前模型和权限、可展开引用、复制与已有成果入口。

先用真实组件回归保护字段提交、草稿保活、停止、审核和成果入口，再分别调整资料与讨论展示，最后统一验收。讨论受理、提交核实与成果通知继续使用原协调逻辑；父页面继续维护讨论显隐和窄屏焦点。没有新增依赖、后端接口、数据库变更或 TBD 决策。

单条回复直接保存为讲解、讨论主视图、自动概括标题与提示词响应风格留在后续设计范围。

### 内容关系与行为边界

- 当前译文读取保存字段；人工修改后的当前译文不必等于任何关联结果。查阅历史只读取数据，不触发翻译调用或采用写入。
- 当前译文与关联记录各自可空：有任一内容即可查看，两者都空时隐藏翻译区；读取失败保留当前译文和重试入口。
- 前后文是已保存的学习语境，预览合并空白只影响呈现；完整资料与保存值保留。朗读只使用目标原文。
- 精确出处通过服务端校验，前端不拆混合 display 字符串；材料名可独立保留，章名只在定位校验成功后显示。手动片段或失效出处不阻断内容阅读。
- 新增字段、卡片职责与导航分别记录在架构和信息架构；未新增领域实体，未触及 TBD。讲解标题与工具栏进一步调整留待专门处理。
