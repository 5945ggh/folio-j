## 开发切片

### 切片 0 样书与定位契约验证

在隔离的试验范围内，验证“EPUB 输入 → 定位正文与受控资源 → 浏览器呈现 → 选区转位置 → 位置还原选区”。使用少量代表性 EPUB 与合成样例覆盖 ruby、重复文字、跨节点组合、图片及章节组织，检查 Yomitan 所需的实际文字扫描条件。不要只用旧代码存在或纯逻辑测试代替浏览器观察。

交付：渲染与迁移取舍、实际支持的选区范围、正文提取规则及测试样例；补齐下一切片 schema/API 草图、导入与文件生命周期，以及 PRD 当前阶段安排。可由 agent 依据样例和现有规则作出工程选择并记录理由；只有影响阅读体验或数据保留的重要分岔再单独讨论。

完成标准：能用真实浏览器验证选区往返，并解释失配或不支持的情况；长期规范与第一切片任务没有范围冲突。此时不交付模型问答、分词或大而全的阅读器。

### 切片 1 导入材料与基础阅读

连通托管 EPUB 副本、材料及版本持久化、来源下的材料入口、正文和资源读取、章节导航及基础阅读位置恢复。先让一本书能被导入、打开、离开并重新继续阅读。

完成标准：刷新或重启后内容和位置可找回；重复导入按契约处理；失败不出现可用的半成品，不遗留无主文件；Source 删除与迟到结果规则覆盖新增材料。若本切片不提供独立材料删除或复杂显示设置，应明确呈现边界。

### 切片 2 从原文接入现有学习能力

选取原文，查看和调整目标及语境，建立带材料出处的 Segment，进入已有工作台或明确请求生成 Analysis；再由片段或讲解返回对应阅读位置。已有相同位置的片段可供选择，不按相同文本自动合并。

完成标准：从阅读到学习再返回阅读的路径连通；目标原文与历史输入稳定；手动 Segment、原有讨论与讲解编辑不回归。这一切片先验证既有能力的实际价值，不依赖材料对话全部完成。

### 切片 3 材料对话与消息引用

扩展线程归属与输入快照，支持材料范围内的随手提问、消息原文引用、历史消息定位，以及从引用派生的阅读标记。已有后台执行、停止、恢复与记录能力复用，但逐项核对新的作用域。

实施前用具体交互定下：加入引用是否展开侧栏、无活跃线程时何时新建线程、同一问题多处引用、手动粘贴、上下文默认范围与费用控制。默认行为不能导致选中文字就调用模型，也不能因阅读器知道全文而默认向模型发送全文。

完成标准：发送时固定本轮目标；翻页不改变已受理请求；点击标记打开确切消息；重复或重合引用不丢失身份；无定位消息正常使用；刷新、失败、停止和线程隔离均有证据。

### 切片 4 从讨论形成持久讲解

从已有阅读讨论明确选择学习目标与相关问答，建立或选用 Segment，再整理为 Analysis；原阅读线程保留，并提供成果及出处入口。

完成标准：多处引用不会自动拼成一个目标；用户不必重新复制讨论；Analysis 继续归属 Segment；部分成功可找回，重试不重复创建已成功成果；材料对话不能借组合动作绕过现有编辑审核。

## 分词接入时机

分词可在切片 1 后、确有词级功能需要时作为独立切片加入，不必等待本阶段全部结束，也不提前阻塞切片 2–4。输入绑定已经固定的正文版本，结果作为可重建 sidecar；分词数据改变不产生新的材料核心版本，不改变引用与阅读位置。

目前只明确这些依赖方向，不实现 Lexeme 模型或 sidecar 存储。具体规则见[基线第 8 节](MATERIAL_BASELINE.md#8-分词与派生数据的后续接入)。

## 协作与验收

以切片为单位交付可使用的前后端路径，不将全部后端完成后才接 UI。每个切片使用短期 `codex/*` 分支；开始前确认当前其他修改的归属，不覆盖并行工作。

- 主代理负责范围、契约、任务派遣和集成验收；schema、迁移、API 与生成客户端由同一责任方协调。
- 契约确定后，后端实现、前端阅读交互和测试样例可在互不重叠的文件范围并行；前端不手写服务端接口类型。
- 测试代理优先准备有意义的正文与定位样例，独立核对边界；不要将同一份未确定契约分别交给多个实现代理自由设计。
- 按 [AGENTS](../../../AGENTS.md)执行 `just lint`、`just test`；schema 变化运行 `just gen-api` 并检查迁移；UI 在浏览器实际验收。文档变化运行 `just check-docs`。
- 测试继续禁止真实模型与网络调用。模拟模型证明的是交互和数据链路，不冒充真实教学质量；需要新录制时按仓库规则由人类执行。

当前交付物只是阶段计划与设计文档，尚无上述切片的实现或测试通过记录。
