# 切片 1 导入与基础阅读验收

> 2026-10-04；分支 `codex/epub-reading-foundation`，实现提交 `2214fc9`（编译与定位基础为 `d8f5bc4`）。切片 1 已通过实现、独立 CR 与主代理浏览器验收；范围仅含导入、目录组章、基础阅读及恢复，不包含切片 2 的学习入口。

## 已实现的路径

来源详情提供材料列表与 EPUB 导入；导入成功直接打开 `/materials/:id`。同一来源导入相同字节返回同一材料，界面说明已打开此前导入的材料；跨来源分别保存身份。正式页面沿用应用外壳，保留书名、目录、可收起的阅读设置／导入提示、章内进度与保存状态，不沿用实验室的调试 JSON、自检和样书选择界面。

目录优先 nav，目标全部无效时尝试 NCX，再回退 spine 并提示。章节可以包含多个原资源或同资源的 fragment 范围，保留原目录章名、层级、原始资源和 spine 出现位置。第 8 卷的「遠路」包含 `p-001` 图片章扉及 `p-002` 正文，在同一章节内连续呈现。每个 part 使用独立无脚本 iframe，隔离作者样式和重复 HTML id；图片从外层阅读视口取得稳定尺寸上限，避免嵌套 viewport 造成缩略图反馈。

横排／竖排、字号和行距可调整。保存位置绑定不可变版本、章、part、资源和正文码点；图片单独保存稳定图片编号与局部比例。章内百分比按当前阅读布局派生，重排后可能变化；它不是持久定位或“读完”标记。原书 ruby 保留，注音不进入正文偏移；自动分词注音仍是后续派生层。

## 存储、接口与数据保留

- `materials` 保存不可变原始 EPUB BLOB、源摘要、独立版本 ULID、产物摘要／契约、压缩编译包和导入警告；`reading_positions` 保存可更新位置和 revision。
- 原字节及产物在同一 SQLite 短写事务发布。请求体流式限制 32 MiB，编译产物预算 64 MiB，保留 ZIP 展开与构造时预算检查；编译、序列化／压缩与解压验证移出事件循环。无 staging 文件，不产生无主文件清理流程。
- 发布前再次校验 Source 存活，同源判重在写事务内完成；失败不发布半本书。读取原始字节采用 deferred 列，材料列表读取摘要，不逐书解压正文。
- 位置保存要求 `expected_revision`，校验完整版本／章／part／资源及文字或图片范围；旧 revision 返回 409。前端串行合并写入，冲突后停止自动重试并提供重新打开。
- 来源删除确认包含材料数量；所有读取／位置写入检查来源存活，删除后不可再读；原始托管字节暂不物理清理。未开放独立材料删除。
- 增量迁移 `0007_materials` 保留已有 Source／Segment 等内容，覆盖空库与从 `0006_analysis_execution` 升级；未重建日常学习库。
- OpenAPI 与前端客户端已重新生成。前端服务端 DTO 均取生成类型，数据读取／mutation 经 TanStack Query。没有新增依赖、模型调用或权限扩展；没有关闭既有 TBD。

## 浏览器验收

验收使用用户提供的 `temp/安達としまむら8.epub`，后端绑定本机并使用独立数据库 `temp/epub-slice1-acceptance/app-v2.db`；没有把样书或测试来源写入日常数据库。原 EPUB、生成全文、测试数据库与截图均在忽略路径内。

主代理操作正式页面得到的证据：

1. 从来源页面创建验收来源、选择真实 EPUB 上传，自动进入阅读；显示 7 个原目录入口及独立前置内容。
2. 「遠路」先呈现正常尺寸图片章扉，继续滚动进入正文，仍属于同一章节；原书 ruby 可见，未出现每个 iframe 独立滚动条。
3. 横排章中位置刷新前 scrollTop 2361、刷新后 2339，恢复误差约一行；不是按像素承诺恢复。
4. 快速连续调整字号和行距后保持原段落附近；横排切竖排仍回到同一段落。观察 570 px 与 1280 px 两种宽度，内容可重排。
5. 稳定竖排章中约 6% 时保存 `part 1 / p-002 / offset 786`，返回来源再打开仍在原处，无 409；滚动后立即离开再进恢复到约 9%，最终保存 `offset 1259`。
6. 停止并重启验收后端，再刷新同一材料，仍恢复约 9% 的章中位置。FastAPI 托管的构建产物也实际打开并验证刷新恢复。
7. 通过正式上传控件重复上传同一原书，返回相同材料 ID，并显示复用提示；SQLite 中仍只有 1 份材料，托管字节 SHA-256 与用户原文件一致。
8. 打开来源删除确认，显示“1 份阅读材料也将不可再打开，托管原书暂时保留”，随后取消。实际删除门禁／迟到导入由隔离 API 测试验证。
9. 在最终正式构建中连续切换 1280→570→1000 px 视口并立即返回来源、再打开，仍恢复章中约 9%；保存位置保持 `part 1 / p-002 / offset 1253`，与此前 1259 在同一原文附近，没有回到图片章扉。

补充真实样书编译：第 1 卷原文件约 13.4 MB，编译产物 38,362,081 字节、26 资源／9 章；第 8 卷产物 16,203,298 字节、24 资源／8 章（含前置内容）。初始 32 MiB 产物预算过低，已调整为有界 64 MiB；两本离线编译均通过，安全限额测试继续通过。第 1 卷仅验证编译与组章，正式页面逐项浏览器验收以上述第 8 卷为主。

## 审查与修复记录

实现由编译、后端、前端三个原生子代理分工。编译代理独立审存储／API／迁移，后端代理独立审前端，前端代理独立审编译；主代理集成并做浏览器验收。普通检查通过不替代真实页面验证。

已修复并补回归：

- nav 有条目但所有目标无效时未尝试有效 NCX；同文档 `#fragment` 被误解析为目录路径。
- 长 Text 叶子恢复只回段首，改为有界字符 Range 搜索附近可见行；非 NFC 长文恢复避免逐前缀平方级规范化。
- 迟到 iframe 加载／字体／RAF 回调误用新一代状态；窗口变化未重新测量；竖排图片局部比例方向相反。
- 用 iframe 自身 `vh` 和 1px 测量互相反馈导致大图变缩略图，改为外层稳定像素约束。
- 连续设置期间从仅加载好的章扉采样，覆盖原正文锚点；恢复期间只沿用原 pending 锚点。
- 返回来源再打开使用旧缓存进度／revision，导致回章首和 409；新一轮打开等待最后写入排空及 fresh GET，再固定初始化快照，保存成功同步缓存，后台刷新不重置已挂载阅读器。真实 QueryClient／QueryObserver 测试覆盖两次排队写入及中途缓存更新。
- 薄 CLI 重生成书籍时输出生产 contract 导致实验页不能打开，已保留实验兼容 contract 并重生成合成样书。
- 快速窗口重排时 scroll 可能先于 ResizeObserver，导致中间位置覆盖原锚点；稳定视口尺寸只在有效恢复完成后更新，尺寸变化期间禁止采样和延迟写入，旧恢复 pass 不得解锁。事件顺序回归与正式构建快速切换宽度／离开再进均已验证。

- 无分页、自动振假名、跨资源选区、创建 Segment、材料聊天或模型调用；这些不在切片 1 交付内。
- 原书完整 CSS 兼容不作承诺：CSS 背景资源／嵌入字体、复杂 SVG、DRM／字体混淆及全书固定版仍不支持；普通重排书内简单图片页例外见切片 0。
