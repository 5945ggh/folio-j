# EPUB 即时查词阶段计划

首轮试读使用读者自己的明镜日汉双解词典。从 EPUB 正文点词，沿日文释义或例句继续查，再逐层返回父卡和书中原位。先用这条路径检验查词质量、手势和卡片布局。

## 一、词典与查询

- 用明镜 Yomitan format 3 的真实文件验证导入、索引和显示。测试使用合成条目，真实词典保存在本机。
- 直接提交一个词时查询全文。给出点击位置时查覆盖落点的词，给出选区时查明确范围。有分词时可附带与原文对齐的 token、读音、词典形及词性。选区以读者指定的边界为准。词卡使用所在释义或例句作为新的查询原文。
- 在有界窗口内找覆盖落点的词。优先尝试 token 接缝，也保留原文字面的字符匹配和活用还原，覆盖词中部点击、跨 token 复合词和词内短候选。
- 按实际覆盖的原文码点长度降序。同范围内再用读音、词形和可对应的词性作软提示。合卡仅限同一词典版本中的有效 sequence，以最佳实际命中决定卡位和高亮，保留定义顺序及有差异的内容。

## 二、阅读与嵌套

- 阅读工具栏提供查词开关。点击模式下，正文轻点基字查词；拖选、长按选字、滚动、复制保留。下划线继续提示已存记录。点在记录上时，词卡提供原处入口，页边与本章记录也能打开原记录。
- 桌面按命中位置和可用空间展开各层词卡，允许局部重叠。窄屏参照试读参考图纵向错层，露出父卡与触发文字，当前卡可独立滚动。卡内点击日文进入下一层，保留父卡所读词条、命中和滚动位置。查无结果时保留来处，逐层返回，关闭整组回到原文。
- 鼠标可选按住 Shift 指向正文。此模式普通鼠标点击划线仍打开已有记录，移入词卡后可以松开 Shift。触屏使用轻点。词卡内可以点击日文，桌面 Shift 模式也可继续悬浮查词。

## 三、试读顺序

1. 建立导入与统一查词，固定复合词中段、活用、同形异读、明确选区、无 token、合卡与实际范围的样例。
2. 接到真实阅读器，先跑通正文、父卡、子卡、返回。核对中文译文和日文例句的操作、已有记录、横竖排及滚动位置。
3. 核对桌面鼠标两种手势、手机窄屏错层和长按选字。用真实词典记录查询缺口。实体触屏试读与浏览器模拟分别记录，按观察调整卡位、深层露出量和热区。

此前的[排序调查](../../../references/dictionary-context-ranking/REPORT.md)记录样本结构、旧排序方案与模型研究。首轮以本计划中的长匹配优先和真实试读为依据。

## 第一轮试读记录

2026-10-31，以本地 `main e2be0c3` 为起点。临时 SQLite 库分别导入合成 EPUB 和用户在本机提供的《安達としまむら8》，词典采用明镜 1.4.3。日常库与私有书籍、词典正文均独立于仓库交付。

- 实际 ZIP 含 139,462 行、61,259 份不同的释义正文。在这台机器上，通过本机服务导入用时约 14.6 秒，索引约 106.8 MiB。查询按需解码展示的定义。
- 桌面 Chrome 从「言葉」进入释义中的「人間」，宽屏同时显示两张可滚动词卡。390px 模拟触屏从「人間」继续点「人類」，三层同时露出父词和对应的日文片段。逐层退回并关闭后两端均保留原文滚动位置。竖排也已用 Shift 指向打开词卡，松键后可点击日文进入子卡。
- 在真实 EPUB「遠路」中点「昔話」，再点释义中的「出来事」，逐层返回并关闭，原文滚动位置保持一致。自动回归另以合成词典验证父卡滚动、返回、关闭与迟到结果。关闭页边后可从词卡打开原处记录，改用 Shift 后普通鼠标点击同一划线直接回看该记录。
- 词卡首轮支持明镜使用的文字、结构与日中语言标记。其他转换器、词典媒体资源、多词典混排及实体手机上的手势与舒适度仍待单独试读。

## 桌面试读调整

2026-10-31，从 `8fde140` 的首轮试读继续。桌面作为本轮主要验收端。在 1440px 的真实 Chrome 页面连续点「言葉 → 人間 → 人類 → 動物」，四张卡同时留在屏内。「人間」页分列明镜的两个词条；翻页按钮留在卡头，点下一页后原文高亮切到对应范围。五个宽度的浏览器回归另外核对长短页切换、向上开卡、父卡返回和背景不透明度保存。

明镜 1.4.3 的 ZIP 没有独立样式表。词头字号、词性与例句配色等来自释义节点的 style。已导入词典直接显示这些样式，深色纸面调整配色。独立样式表后续随实际含有该文件的词典单独验证，格式依据见 [Yomitan 词典制作说明](https://github.com/yomidevs/yomitan/blob/master/docs/making-yomitan-dictionaries.md#adding-custom-css)。

## 设置与词典切换

2026-10-31，从 `f63f3f2` 的桌面试读版继续。词典按本机服务安装，同时选用一本，所有书籍共用。在「设置 → 词典」管理安装与选择；查词手势和词卡透明度仍在阅读器里调整。操作见[使用指南](../../USAGE.md#即时查词)，索引随库备份与恢复见[升级指南](../../UPGRADING.md#数据与凭据)。

在独立试读库的桌面 Chrome 中，从 EPUB 打开「管理词典」，列表直接显示原有明镜 1.4.3 的 139,462 条记录。导入另一本合成词典后，明镜仍是当前选择；重复导入同一 ZIP，列表仍有两本。切换后点「返回阅读」，原书「言葉」显示合成词典的释义；切回明镜、刷新设置再返回，同一个词恢复了明镜的词条与例句。另在真实 EPUB 卷动到正文后进入设置并返回，滚动位置由 675px 恢复到 670px，仍为同一段。设置页以 1280、390、320px 三种窗口验证；窄屏检查使用桌面浏览器模拟。

桌面浏览器回归还模拟了另一标签页更新词典：只增加安装项时，正在阅读的词卡保留；当前选择改变后收起旧卡，下一次点击从新词典读取标题与释义。

## 词卡手势与键盘试读

2026-10-31，基于词典设置版 `35c2c05`。在桌面 Chrome 用明镜验证了按住 Shift 从正文「言葉」连续指向卡内「人間 → 人類」，松键后三层保留。只拖动最内层卡头可移开该卡；返回父卡后用 ← / → 切换匹配范围。也验证了鼠标先停在卡内日文再按 Shift，以及把背景不透明度降至 20% 时词卡文字仍然不透明。

五个窗口宽度的浏览器回归覆盖卡头移位、翻页后保留位置、首末页边界、选区与修饰键保护，以及窄屏整组移动。移动端使用桌面 Chrome 模拟窗口，实体触屏未复核。

试读后将词卡背景默认不透明度定为 72%。在 1360px 的 Chrome 中打开明镜「言葉 → 人間」，滚动词卡后从阅读设置切换到插图库，关闭图库后两张卡仍在原处。先开图库再查「言葉」时，重叠区域可以操作词卡，按 Escape 回到图库。
