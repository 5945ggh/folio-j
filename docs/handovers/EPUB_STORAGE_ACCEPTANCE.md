# EPUB 图片存储与编译器整理验收

## 首次去重实现（历史验证）

本节记录首次图片去重及过渡维护工具的验证。当前单格式实现与开发库重建见后续收口记录。

2026-10-25，以 `84d6573` 为实现起点。只优化 SQLite 编译包的物理编码，完整资源与章节 HTML、图片 data URI、产物摘要、材料／版本及定位身份保持不变；不修改原图或前端接口，不新增依赖，不触及 TBD。

先建立旧格式兼容与完整 JSON 往返回归，再实现共享图片池和所有业务读取入口；代码作者与独立审查分开。旧库维护另外覆盖预览、备份／凭据、进程锁、身份核验、失败回滚和重复执行。普通阅读不触发转换。

日常数据库只通过 SQLite backup API 复制到临时目录。真实书籍的计量、转换、全库非编译包字段校验及空间整理仅在副本运行，不将私人书籍内容、书名或凭据写入仓库。

## 验证结果

初始存储测试在缺少实现时收集失败；实现后覆盖完整 JSON 往返、Unicode／跨叶 NFC、重复 spine、原样图片、输入不变、旧格式、小图／无图回退、截断／尾随压缩流、未知版本、严格引用、图片池、资源／章节／part 数量、解压及还原预算、未知字段保留和重复转换。另以三本仓库原创合成 EPUB 的真实编译结果核对往返。

真实导入集成回归使用确定性生成的有效大 PNG，使编译包确实进入新格式；随后核对章节 HTML、图库原图字节、图片定位、全文搜索、文本／词法统计、片段出处保存／解析及本章片段扫描。既有旧 zlib 样例继续覆盖读取与失效反馈。

工程检查：`just lint` 通过；`just test` 的后端 725 项、前端 602 项通过；`just build`、`just check-docs`、`just gen-api` 及 `git diff --check` 通过，生成的 OpenAPI 与前端类型无变化。构建保留现有大 chunk 提示。

完整离线 Chrome 回归通过，覆盖阅读器、章节记录、横竖排、宽窄屏、图片／定位、片段、翻译与主题等既有场景。真实 DOM 断言确认 iframe 内容、原文投影、图片几何和阅读返回正常；浏览器使用离线接口夹具，新物理 BLOB 经真实后端的验证由上述导入集成回归承担。本次未修改 UI，无新增视觉设计或真实模型调用。

独立审查未发现阻塞问题，额外核对了精确 JSON 预算下的控制字符、非 BMP 字符往返及第二条压缩流拒绝。维护回归已固化 WAL 中已提交数据进入备份、恢复完整性，以及旧读事务占用检查点时准确报告“转换已提交，整理未完成”；独立验证另确认整理后 WAL 清零。维护与存储编码共 52 项定向测试通过。

## 限制

共享池仍将图片 data URI 保存一次，托管原 EPUB 另有原图副本；直接复用原 EPUB 图片不在本次范围。HTML 物理压缩不减少浏览器收到的逻辑章节数据，首轮不承诺阅读时间或内存下降。旧版本应用不支持新物理格式，降级需恢复转换前备份。

上述过渡维护工具已在下述收口中移除。当前开发库边界见[升级与备份](../UPGRADING.md#epub-存储格式与开发库重建)，格式和不变式见[架构](../ARCHITECTURE.md#31-实体)，当前交付状态见[实施基线](MVP_IMPLEMENTATION_BASELINE.md)。

## 2026-10-25 单格式与编译器收口

用户明确授权放弃现有开发数据并删库重建。先补单格式、一次压缩、空图片池和预算边界回归，记录 8 项失败，再删除旧裸 zlib 读取、大小比较／回退、转码函数及专用维护命令／测试。存储 interface 仅保留 encode/decode；版本标识、图片原字符串、完整逻辑产物与身份、严格引用、整流校验和 64 MiB 逻辑预算保留。envelope 另限 128 MiB，容纳结构开销；空 HTML 的超限骨架也在起始检查中拒绝。

编译器先用完整产物摘要和单次读取回归锁定行为，单次读取在原实现中因打开归档两次而失败。整理后由私有 `_Publication` 共享一次有界归档读取、包文档、类型化资源和全书输出预算，删除旧字典中转与未使用的中间摘要。所有成员元数据和 DRM 声明在读取内容前检查。5000 项、总展开 128 MiB、单成员 16 MiB、展开率 200，以及路径、重复、加密、XML／CSS／清洗和累计产物预算均保留；未删除公开逻辑产物中的完整资源 HTML。历史实验 CLI 继续维护其独立输出契约，不参与应用存储读取。

单格式存储 46 项、编译器／历史实验 58 项定向测试通过；真实导入、图片、定位、出处、翻译、统计与存储相关联测 163 项通过。独立只读审查未发现阻塞问题，并另用修改前编译器对比 16 组目录、NFC、ruby、缺图警告和重复 spine 输入，完整逻辑 JSON 全部逐字一致。
