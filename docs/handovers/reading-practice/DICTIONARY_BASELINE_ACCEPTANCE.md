# 基础词卡验收

实施与验收日期：2026-11-14，提交收口日期：2026-11-15。实现起点：`main 653a4d60`。产品行为见 [PRD](../../PRD.md#epub-即时查词)，交互见[即时查词](../../INFORMATION_ARCHITECTURE.md#即时查词)，使用步骤见[使用指南](../../USAGE.md#即时查词)。

## 范围

词法分析作为查词响应的独立部分，无已选词典或词典未命中时仍显示基础词卡；有释义时按原文范围共用基础信息。读音和罗马音对应表层，原形、词性和活用型按实际成分展示，未知或截取不完整的词元不补造信息。当前沿用 A 分词和既有词形还原，不改全书注音、统计或学习资料。有词典命中时只展示命中范围，基础分析不能以更长的范围抢占词典结果；全无命中才生成基础候选。

前端冻结词典身份，显式空身份也由服务端校验。删除最后一本词典后可继续基础查询，删除前的迟到释义不得重新出现。API 类型由 OpenAPI 生成；无数据库迁移、新依赖或新增 TBD。

主代理在 5198／8021 的临时 Vite／FastAPI 实例上操作合成片段，使用独立 SQLite 库：

- 无词典时开启点击查词，点击「書いた」显示 `かいた / kaita`、原形「書く」、五段・カ行及实际接续。
- 导入两条合成词典后，同一处显示「書く」的释义，同时保留「書いた」的基础信息。
- 点击「国家公務員」内的「公務」，只显示合成词典实际收录的「公務」。
- 点击词典未收录的「食べさせられなかった」，显示完整基础链与未找到释义提示。
- 长罗马音按用户反馈增加 `0.05em` 字距，与假名保留 `9px` 间隔；真实组件宽屏同行，320px 窄卡换到假名后方，不溢出。基础字段、接续和释义均可完整阅读。

本轮没有访问日常学习库或真实模型。

## 限制

本轮沿用 A 分词。明确划选沿用独立查询所选文本的入口，不带选区外语境；只选「食べました」中的「食」时，分析可能按独立名词读作「ショク」，不能把该结果视为原句读法。未重做 Windows、Safari、Firefox 或实体触屏验收。
