# 片段即时查词与共享模块验收

日期：2026-11-09。实施起点：`main e9b8eb16`，结果对应 `codex/segment-dictionary` 工作区。产品行为见 [PRD](../../PRD.md#epub-即时查词)，入口与生命周期见[片段阅读契约](../../INFORMATION_ARCHITECTURE.md#讲解浏览人工保存与按需讨论)。

## 范围与实现

片段左侧工具栏提供即时查词设置，支持原文、已保存前后文、讲解标题与正文中的点击、Shift 悬浮和明确选区查词。窄屏入口随工具栏移到顶部。词卡沿用分页、嵌套、拖动与逐层关闭，片段内采用应用颜色及实底表面。管理词典使用现有全局设置返回链。

前端 [dictionary 模块](../../../frontend/src/dictionary/Dictionary.tsx)接收文字窗口、屏幕锚点和可选高亮回调，共用设置、查询身份与词卡栈；阅读器 adapter 另转换 EPUB 选区及“此处记录”。DOM 文字手势由片段与词卡共用。查词方式及两项辅助开关移到独立浏览器存储，首次读取迁移旧阅读器值，保留同页与跨标签同步；写入失败保留当前呈现并反馈。

宿主负责正文滚动、讲解切换、模态框与页面隐藏时清理词卡。共享模块负责请求身份、词典身份及配置快照，关闭后迟到结果不能恢复词卡。清卡代次只重置文字手势去重，允许同一字符关闭后再次 Shift 查词；不保存学习内容。讨论 Markdown 未接入片段阅读查词，回复流式更新不清除阅读区词卡。

段落、语境与链接边界不拼接文字；行内格式及 ruby 基字可共同组成查询窗口，注音不进入查询。NFC 码点与原 DOM 范围双向映射，包含组合字符与补充面字符。无后端 schema、数据库迁移、新依赖或新增 TBD。

## 审查修复（2026-11-09）

审查发现两处遗漏：DOM 命中字形过滤排除了长音符，完整资料浮层也未接入查词。字符判断改用 Unicode `Script_Extensions`，覆盖全角及半角长音符。完整资料的原文与前后文复用 `LookupText`，只读 dialog 注册内部词卡挂载点；关闭资料、切入编辑或离页时清除词卡、选区和高亮，并拒绝迟到结果。词卡关闭后焦点回到资料阅读区，Escape 先退词卡，再关闭资料。卡内选区仍由词卡自身处理。

阅读器底部“此处记录”已有完整的 `StudyMarkHit` 回调适配，保留片段与翻译记录身份，本轮保持该实现。既有浏览器用例验证从词卡打开确切片段记录；未增加翻译记录专门场景。

主代理通过应用内浏览器操作完整资料中的原文，确认词卡位于资料浮层上、可操作；连续两次 Escape 分别关闭词卡和资料，焦点依次回到资料阅读区和原入口。新增 `scene=dialog` 在 1280／390 宽度覆盖长语境、长音符点击、Shift、原生划选、嵌套、模态层命中、焦点、滚动、编辑切换及关闭后的迟到隔离。共享文字窗口回归另覆盖全角／半角长音符。

修复后 `just lint`、`just build`、`just test` 通过；后端 1404 项通过、2 项 Windows 专属检查跳过，前端 826 项通过。片段查词完整组 9 场、阅读器查词 8 场、共享词卡布局 1 场通过；补充卡内选区隔离后重跑完整资料专项 2 场，并保存桌面／窄屏截图目视复核。新增测试的类型检查错误已修正，最终静态检查与构建复验通过。公共文档路径与差异空白检查通过，私有历史证据未核验。

## 限制

本轮使用合成词典验证片段接入与共享行为，未重做真实词典全量兼容性、实体触屏、Safari／Firefox 或 Windows 实机验收。已有兼容范围见[查词选项验收](DICTIONARY_OPTIONS_ACCEPTANCE.md)。未访问日常学习库或真实模型，未核验私有历史证据。
