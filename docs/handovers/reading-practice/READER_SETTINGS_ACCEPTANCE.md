## 实施范围

保留 17 个设置，按排版、注音、阅读界面、带上下文复制组织。常用项直接展示，低频选项、说明和格式示例逐层展开；各组独立恢复默认，复制恢复只改草稿。样式沿用 Reader 控件与阅读语义颜色，保持独立白／黑纸面。

复制编辑状态由当前材料的阅读会话持有，关闭设置、换工具、切章与正文再验证不丢草稿。表单和离开提示共用保存操作，已有请求不会重复发送。复制与学习片段共用一处导航拦截，先处理片段，再处理复制；取消任一提示即取消本次导航。确认框位于正文隐藏容器之外，查询再验证时仍可操作。

保留既有保存范围和默认值：排版的字号／行距／方向随阅读位置保存，本书版本的字体／宽度／注音和跨书界面偏好仍在浏览器，复制仍为数据库个人默认值。无后端、schema、API 契约、依赖或迁移变更，未触及编号 TBD。

## 浏览器验证

浏览器测试挂载生产 `ReaderSessionHost` 与 DataRouter，通过严格 mock API 构造保存、失败、冲突和查询挂起。使用仓库运行器执行：

```bash
BROWSER_TEST_SUITE=reader-settings pnpm --dir frontend test:browser
BROWSER_TEST_SUITE=reader-context-copy pnpm --dir frontend test:browser
BROWSER_TEST_SUITE=reader-layout-switch pnpm --dir frontend test:browser
BROWSER_TEST_SUITE=theme pnpm --dir frontend test:browser
```

| 场景 | 结果与覆盖 |
| --- | --- |
| 阅读设置 | 6/6；1280px 横排浅／深、390px 横排深／竖排浅、320px 横／竖排浅 |
| 带上下文复制回归 | 4/4；1280px 与 320px 的横／竖排，保护普通复制与已保存配置路径 |
| 阅读方向回归 | 4/4；1280px 与 390px 的横／竖排，原文定位及分组恢复后的呈现 |
| 主题回归 | 4/4；1280px 与 320px、模拟系统浅／深，独立纸面与片段确认框；该场景测得最低文字对比度 4.67:1 |

阅读设置完整场景覆盖：

- 17 项设置单一入口、默认折叠、隐藏控件不进入焦点顺序；恢复各组不改变其他组，重排保留原文位置与 iframe 身份。
- 关闭重开、工具切换、切章后的复制草稿与展开／滚动位置；复制摘要始终使用已保存值，收起后仍可发现错误。
- 保存失败与冲突保稿、重新读取并保留修改、恢复复制默认值只改草稿；后台保存成功与失败均等待原请求，不重复 PUT。
- 同一 Reader 的 query／尾斜杠变化、受控查询再验证窗口；窗口内离开提醒可见，取消后继续原页面。
- 真实创建学习片段草稿与复制草稿后依序处理两份草稿，取消任一提醒不会绕过另一份保护。
- PUSH／POP、进入保活片段页、换书、保存后离开和放弃离开；清理草稿后不拦截无关设置页导航。

独立预览另跑 6 个尺寸／主题组合并截图。主代理实际打开桌面浅色页面，展开复制组、修改句数并核对已保存摘要和未保存提示；同时检查窄屏深色截图。侧栏分组、分隔线、选中态与输入框延续 Reader 样式，窄屏面板内部滚动，控件没有横向溢出。
