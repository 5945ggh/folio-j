验收日期：2026-11-08 至 2026-11-09。实现起点为 `main fa284419`，验收对象为 `codex/focused-global-navigation` 分支完成的全局导航改动，已整理为本地提交并合入 `main`，尚未推送或发布。使用 macOS ARM64、隔离 Chrome 和合成阅读资料；浏览器 API 全部离线替身，不读取日常资料库或调用真实模型。

## 范围与取舍

片段工具栏顶部增加首页，底部增加独立的全局设置齿轮；阅读器顶栏提供相同入口，保留 Aa 阅读设置。首页统一指向 `/`，当前落点为素材库。完整设置使用原独立页面，页头与悬浮提示返回直接来处，分类和服务导航继续保留原书及目录父链。现行交互见[阅读与导航](../../INFORMATION_ARCHITECTURE.md#设置顶部分类)。

片段仅在本次明确的设置往返中保留一个实例及讨论输入，退出该路径范围、换片段或刷新后释放。这里按路径退出释放，避免配置较久后因固定租期丢草稿；关联原书继续沿用十分钟阅读保活。状态只在内存，未增加存储格式、依赖、迁移、API 或 TBD 决策。

返回片段前取消旧读取并发起新的可用性读取，等待和失败期间保留挂载、隐藏旧正文，重试恢复输入。隐藏或不可用页面不能响应迟到成果导航；设置期间完成的新建线程与讲解任务保留结果，返回后由用户选择，不改变原 URL 对应的讨论。尚未发起的自动讲解意图需明确继续，已受理任务仍按原协调器处理。

兼容回归发现设置页放弃修改后可能重复执行 `blocker.proceed()`；已将自动继续、保存后离开和放弃修改统一为核对目标身份且只执行一次的导航，原有确认规则保持。
