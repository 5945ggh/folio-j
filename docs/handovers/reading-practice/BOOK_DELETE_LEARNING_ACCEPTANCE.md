# 删除书籍时可选清理学习积累

> 2026-11-07，实现基于本地 `main 10d4b733`。产品规则见 [PRD F2](../../PRD.md#f2-source-与片段)，实现规则见[材料删除契约](../../ARCHITECTURE.md#31-实体)，使用步骤见[管理书籍](../../USAGE.md#整理来源与导入书籍)。

## 范围

书籍删除确认框默认保留学习积累。勾选“同时删除学习积累”后，按精确材料出处选取片段，删除范围包含人工讲解、历史修订、讨论与消息，并中断相关活动任务。

确认框展示读取时的规模，提交按实际材料关联处理。材料清理与学习内容软删除同事务完成。无材料出处的手动片段、其他材料及其学习内容保留。书签及备注保留并随材料隐藏。

接口沿用默认删除的 204 响应。可选清理返回材料身份和已删除片段 ID，重复请求也能清理对应缓存。材料身份墓碑允许明确重试或继续清理原材料的关联积累，重导的新材料保持独立身份。
