## 交付内容

阅读选区新增“带上下文复制”，使用已加载章节和本次确切选区在本地生成文本。目标、前后文和可选出处分别标明，复用 `prefillContext` 的校验、句界与双预算；沿用既有普通复制和片段分享格式。

阅读设置新增独立复制分组，提供两侧句数、出处开关、可展开字符上限和动态格式示例。数字草稿在 Enter 或失焦时提交，非法空输入不写成零；偏好在当前浏览器跨书保存。复制失败显示完整只读文本供手动选择，回执按选区、呈现代次与请求序号失效；不创建学习内容或发起模型任务。

## 浏览器验证

以下浏览器验证针对格式示例改为折叠之前的功能实现；最终折叠调整按用户要求未重跑浏览器，见下节提交前复核。

通过隔离 Chrome、合成章节与严格模拟 API，未连接日常使用数据库或模型服务。新增 `reader-context-copy` 场景 4/4 通过：1280px、320px 宽度各横排／竖排。

- 默认复制精确目标、三句前文与出处，排除 ruby 读音；普通复制仍仅含目标原文。
- 改为前文 0／后文 1 并关闭出处后，结果符合设置，重新挂载仍有效；空数字草稿不会误存零。
- 剪贴板拒绝时有明确反馈、完整只读文本和全选入口。
- 新选区清除旧反馈，旧选区迟到失败和离页后迟到成功均不会恢复界面。
- 桌面工具栏单行，320px 窄屏自然换行；工具栏与全部按钮位于可见范围内，复制后保留原选区。
- 模拟 API 仅允许 Reader 正常生命周期的位置、打开状态和注音准备写入，未发生学习内容或模型调用写入。

补跑既有相关场景 13/13 通过：`reader-clipboard` 1 场、`reading-aids` 5 场、`record-saving` 3 场、`reader-layout-switch` 4 场。覆盖原生复制、学习保存、语音和设置操作、横竖切换的文档身份与位置保持。

另在应用内浏览器打开合成资料预览，实际鼠标点击复制成功；从选区按 Tab 到保存，再 Shift+Tab 到复制并按 Enter，显示成功且选区保留。修改后文句数并按 Enter 后，预览出现对应后文，设置面板布局可读。
