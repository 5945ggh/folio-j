# EPUB 阅读浮窗验收

> 2026-11-01；实现基于 `main 74fc84e`，由 `8ab3b60`、`60a39a6` 交付，用户确认后合入本地 `main`。现行交互见[阅读与导航](../../INFORMATION_ARCHITECTURE.md#原处预览与记录浮窗)，视觉规则见[设计系统](../../DESIGN_SYSTEM.md#阅读器紧凑浮窗)。

## 交付范围

词卡、紧凑片段、紧凑翻译与记录列表共用纸面底色不透明度，沿用浏览器已保存的 `dictionaryOpacity`，范围 20%–100%，默认 72%。阅读界面和即时查词设置提供同步入口；工具栏不透明度独立。共享表面样式负责圆角、边框、阴影、9px 模糊和焦点，内容排版仍由各组件维护。展开侧栏使用实底，收起恢复偏好。

单一候选省略“此处记录”与空计数行；重叠入口保留候选、类型数量及返回路径。片段显示自身当前译文，以篇名选择讲解，底部“打开片段”携带当前讲解和确切修订；“展开”留在阅读器。紧凑翻译突出译文，历史与语境只在展开后出现，删除收进更多菜单并明确清除此处全部翻译。回看不触发生成，也不建立片段与阅读翻译之间的采用关系。

本分支承接此前的单版译文删除接口与并发保护，当前阅读器详情和列表均调用整组清除；接口回归继续保留。没有新增依赖、数据库字段或迁移，未触及 TBD。选区翻译的展开状态由 Reader 面板协调，独立挂载时使用组件本地状态；收起不销毁会话、历史选择或语境草稿。

## 真实浏览器观察

使用 ChatGPT 内置 Chromium 浏览器，桌面视口 1103×954，窄屏 390×844。真实书页运行于 `127.0.0.1:5188`，后端使用独立数据库副本；原日常数据库未改动。多讲解、重叠和历史版本由离线夹具提供，夹具加载真实 Reader、iframe 与导航组件。

| 路径 | 实际结果 |
| --- | --- |
| 真实书页单处“译” → 展开 → 语境 → 收起 | 紧凑首屏直接显示日文和 21px 译文，无类型行、历史和设置；展开后显示历史和语境，实底无模糊；收起恢复 72% 和 9px 模糊 |
| 更多 → 清除此处全部翻译 → Escape | 确认框明确全部历史、标记和停止重译的影响；取消保留卡片并恢复更多按钮焦点。未删除真实书页数据 |
| 阅读设置与词典快捷入口 | 72% 默认，两处调节立即同步；原生滑杆核对 20%、35%、72%、100%，工具栏仍独立。词卡背景随调节变化，文字与图标不透明；片段、候选列表和翻译均核对 35% 底色，侧栏仍为实底。35% 刷新和切换书页后保留，验收后恢复 72% |
| 聚合数字 → 多篇讲解片段 → 切篇名 → 翻译出处 → 历史 → 返回 | 先到候选列表；数量为片段数与翻译出处数，保存时间真实；切换篇名后显示对应正文，长文才渐隐；选旧译后收起保留，返回焦点落在原候选；再回片段保留篇名，片段译文未被阅读译文替换 |
| 仅保存原文的片段，黑纸、竖排、390px | 无空译文和讲解区，卡片自然缩短；底部卡宽 366px，未遮挡下方工具；日文、操作与焦点清晰 |
| 黑纸窄屏翻译展开／收起 | 展开实底为 Reader 黑纸色，内容可独立滚动；旧译和语境可读；收起恢复 72% 底色，保留旧译 |

完整浏览器夹具 `chapter-records`、`margin-record-targets`、`reader-settings`、`translation-removal` 在桌面横排白纸通过。它们覆盖原段尾译文、标记直达／数字候选、确切修订导航、返回焦点、停驻位置、标签选择、历史与语境草稿保留、设置离开保护，以及更多菜单整组清除、失败重试、同文异址隔离和已存片段保护。浏览器回归中的旧控件数量断言随新增滑杆更新为 17 项，并补充共享不透明度及独立重置断言；清除夹具补齐确认框挂载等待，并改为检查未删除的独立出处。

## 未验证项

未重跑全部浏览器矩阵。直接在内置浏览器打开 `translation` 夹具时，拖动用例缺少专用测试运行器注入的 `browserPointer`，因此未计为完整通过；展开／收起、窄屏停靠和历史回看按上述路径人工验证，既有拖动回归已按展开后才显示设置的新契约调整。连续切换预览夹具时曾出现页边入口／详情等待超时，桌面完整 `margin-record-targets` 单独加载后通过，预览状态另以真实按钮操作核对。未调用真实模型、验证设备音色和实际朗读，也未测试实体触屏、其他浏览器或 Windows 适配。
