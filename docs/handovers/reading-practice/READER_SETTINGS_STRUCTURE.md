# 阅读设置：现状调查与结构方案

> 调查日期：2026-10-29；调查基准 `main 7d57239`，包含复制配置持久化 `14fb998`。第 1–7 节保留调查时的实现事实、推荐结构与决策依据，第 8 节保留低保真原型记录；其中七组平铺、关闭即丢草稿和总恢复均指调查时实现。生产工作区进展见第 9 节，当前规则见 [PRD](../../PRD.md)、[阅读与导航](../../INFORMATION_ARCHITECTURE.md#阅读设置分组与会话)，交付与验收状态见[实施基线](../MVP_IMPLEMENTATION_BASELINE.md)。

## 1. 调查结论（main 7d57239）

保留阅读器内完整的设置入口，整理为 **排版、注音、阅读界面、带上下文复制** 四组。前三组各自直接展示少量常用控件，其余按需展开；复制组默认收起，用已保存配置和草稿状态作为摘要。每个控件只出现一次，每组独立恢复默认。

调查时有七个平铺分组、17 个可编辑值。复杂度主要来自三处：

1. 字号、纸面等短操作与说明、示例、复制配置表单占据同一层级，低频内容增加滚动距离。
2. 用途、作用域和保存方式交织。“全局”目前多指当前浏览器，而“本书”又包含数据库和浏览器两种范围。
3. 阅读外观即时生效，复制配置显式保存；复制草稿只在表单挂载期间保留。关闭或替换面板会丢弃草稿，不能将保存失败时的保稿理解为离开保护。

用户已认同常用控件优先、按用途分组、逐步展开说明和统一作用域表达，并确认具体四组结构、同次阅读中的草稿保留和取消总恢复。常用项的选择是初始设计判断，尚无使用频率统计；原型用于继续核对操作路径和信息密度。

需要保留的事实：

- 字号／行距的 Reader 首次使用与恢复默认是 22／2.0，后端 [ReadingSettings](../../../backend/src/app/material_schemas.py) 的缺省参数是 20／1.8。两者用途不同，后续应明确默认值来源；结构调整不顺带修改已有值。
- 浏览器外观保存失败时，本页仍使用所选值；全局浏览器外观有 storage 事件同步，本书浏览器偏好没有对应监听。
- 数据库排版设置复用阅读位置的版本与写队列，冲突会影响位置保存，不等同于复制表单的冲突恢复。
- 复制查询与保存以 revision 防止旧结果回退，实际复制只读取已保存值。跨浏览器共用数据库不表示已有实时推送。
- 调查时复制表单关闭即放弃未保存修改；保存期间只禁用内部字段，外层关闭和工具切换仍可用。关闭不撤销已经发出的保存请求。左侧目录／搜索与右侧设置共存，切章不必卸载设置；会话保留不构成草稿恢复承诺。

复制的状态依据见 [context-copy-draft](../../../frontend/src/settings/context-copy-draft.ts)、[context-copy-cache](../../../frontend/src/settings/context-copy-cache.ts)、[context-copy-query](../../../frontend/src/settings/context-copy-query.ts) 及[数据库验收](CONTEXT_COPY_DATABASE_ACCEPTANCE.md)。调查时普通设置页的离开保护尚未用于 Reader 的复制表单。

## 3. 推荐的信息结构

### 3.1 一处完整入口，四个用途组

保留底部阅读设置入口和右侧非模态面板。字号、方向、纸面、注音显示优先可达；把它们放在各自用途组的首行，不再复制一套“快捷设置”控件。

```text
阅读设置                                         关闭

排版
  字号                         ← 直接可调
  横排／竖排                   ← 直接可调
  ▸ 更多排版：明朝体 · 行距 2.0 · 宽度 760
      字体、行距、正文宽度
      恢复排版默认值

注音
  显示／按需／隐藏             ← 直接可调
  ▸ 注音范围：原书
      原书／全量
      查看注音说明
      恢复注音默认值

阅读界面
  白／黑／跟随系统             ← 直接可调
  ▸ 更多界面设置：专注开 · 下划线开 · 页边入口开
      自动隐藏工具、工具栏不透明度
      阅读记录下划线、阅读记录页边入口
      恢复阅读界面默认值

▸ 带上下文复制：前 3 句 · 后 0 句 · 附出处
    个人默认值 · 保存后生效
    前后句数、附带出处
    ▸ 字符上限
    ▸ 格式示例
    保存复制设置    放弃修改
    恢复复制默认值
```

这是内容顺序与展开关系，不规定像素、配色、卡片形状或控件最终样式。前四类常用值直接可达即可，不承诺任何屏高都能在同一屏完整显示。窄屏保留同一顺序和语义，优先保证控件可操作。

### 3.2 摘要、说明与状态

- 摘要帮助用户确认当前生效值，不能冒充草稿已经保存。复制存在修改时显示“有未保存修改”，其摘要仍以已保存配置为准；展开后的示例明确使用草稿。
- 字符上限为零时，即使句数大于零，该侧摘要也应显示“不附带”；发生字符截断时的说明保持现有行为。不能只看句数生成误导摘要。
- 竖排下宽度摘要显示“宽度仅用于横排”，原值保留，避免显示一个看似正在生效的宽度。
- 一般说明放到组内帮助，格式示例和字符上限独立展开；不再在每个字段下重复作用域与保存机制。错误、未保存、保存中、注音准备中等状态必须在组收起时仍可见。
- 展开某组不自动收起其他组；关闭面板后，在同一阅读会话再次打开时可保留展开位置。进入另一本书回到初始展开状态；折叠状态只属会话 UI，不需要数据库。
- 不给错误、未保存和保存中分配相同的笼统提示。正文稳定呈现与持久化成功分别表达，旧失败不能覆盖较新的成功操作。

### 3.3 与全局设置的关系

阅读面板保留完整阅读配置，便于看着正文调整；这次不新增全局“阅读”大页面，也不在两个入口各维护一套复制草稿。

全局设置继续负责应用外观、学习背景、片段语境、模型、权限、翻译方案和设备朗读。未来如需便捷入口，可在阅读面板提供直达已有分类的链接，但不把这些表单搬进面板。复制、翻译和片段语境仍独立，不合并成通用上下文开关。书签管理属于左侧书内导航，不成为阅读设置的一组表单。

## 4. 保存、草稿与恢复默认

### 4.1 保留两种生效方式

| 操作 | 建议行为 |
| --- | --- |
| 排版／注音／阅读界面调整 | 沿用即时呈现与自动保存，无面板级“保存全部” |
| 全量注音尚未就绪 | 保留旧呈现，显示准备状态；只有最新有效意图可提交，失败可重试 |
| 修改复制值 | 保留原始输入草稿，包括空输入；验证失败不改成零或默认值 |
| 保存复制值 | 沿用整组版本条件提交；保存成功更新已保存配置，实际复制不使用未保存草稿 |
| 复制保存失败／冲突 | 保留草稿并提供处理入口；重新读取后保留草稿仍表示再次提交整组，不宣称字段级合并 |
| 浏览器写入失败 | 保留当前有效呈现，说明本次已生效但未持久保存 |

### 4.2 复制草稿的关闭策略（调查时已确认）

“暂时不看设置”和“放弃修改”是不同操作：

这里的同一阅读会话限定为当前材料的 Reader 路由内：关闭设置、切右侧工具和切章只改变呈现；离开 Reader 路由（包括进入片段页）或换书进入离开保护，即使正文会被保活。保护必须在导航提交和草稿卸载前发生，选择继续编辑后仍保留原草稿与阅读状态。

| 场景 | 建议 |
| --- | --- |
| 折叠复制组、关闭设置、切右侧工具、切章 | 同一 Reader 会话内保留草稿；重新打开显示未保存状态，不自动保存 |
| 主动放弃修改 | 明确恢复已知最新的服务器值；需要重新读取时，失败仍保留原草稿 |
| 离开当前阅读／切换书籍 | 有草稿时提供保存后离开、放弃并离开、继续编辑；无草稿正常离开 |
| 刷新或关闭标签页 | 有草稿时接入浏览器原生离开提醒，不承诺离页后恢复 |
| 保存进行中关闭面板或切工具 | 可隐藏，已提交请求继续完成并更新缓存；不重新打开面板，不解释为取消 |
| 保存进行中通过应用内导航离开阅读 | 先等待该次保存结论再完成导航；失败保留草稿和当前页面，不重复提交 |

这比调查时“关闭即放弃”多出一个会话级编辑状态职责，须在实施范围中单列。草稿不写入 localStorage 或数据库，不扩大阅读正文缓存租期。阅读器暂离或保活不是绕过离开保护的理由。刷新、关页只采用原生离开提醒，不能承诺等待请求结束；进程退出不能保证拦截或恢复。

同会话保留已获确认，实施时同时接入相应离开保护，避免正常开关工具反复询问是否放弃。

### 4.3 按用途恢复默认

| 恢复操作 | 精确影响范围 | 生效方式 |
| --- | --- | --- |
| 恢复排版默认值 | 字号、方向、字体、行距、正文宽度 | 即时；不改注音、纸面、工具或复制 |
| 恢复注音默认值 | 注音范围与显示方式 | 沿用注音准备和最新意图规则 |
| 恢复阅读界面默认值 | 纸面、专注、工具栏不透明度、两种记录显示开关 | 即时；不改正文排版或资料本身 |
| 恢复复制默认值 | 复制的五项输入 | 只改草稿，仍需保存 |

恢复入口放在对应组展开内容末尾，旁边说明影响哪些设置。用分组恢复取代现有跨组三套外观的恢复按钮，不再提供总恢复。

分组恢复只更新该组字段，不能用一份完整旧对象覆盖其他组的最新状态。既有存储分散时可能部分写入失败，需要如实反馈，不能呈现为已完成的原子保存；恢复不涉及书签、备注、片段、译文和阅读进度归零。

## 5. 作用域表达与迁移候选

### 5.1 先把当前作用域说清楚

用途决定设置放在哪组，适用范围决定辅助标签；不要按数据库／浏览器建立主菜单。

| 当前实际范围 | 建议简短文案 | 展开说明 |
| --- | --- | --- |
| 数据库内的本书排版 | 本书 | 随本书阅读设置保存；保留材料版本校验 |
| 浏览器中的本书偏好 | 本书 · 当前浏览器 | 仅当前浏览器中的本书版本，换浏览器不继承 |
| 浏览器跨书偏好 | 所有书籍 · 当前浏览器 | 影响当前浏览器打开的所有书籍 |
| 复制数据库默认值 | 个人默认 · 所有书籍 | 使用同一后端的浏览器共用；不承诺实时推送 |

一组含不同范围时，标签放在相应行或一致的子组，不能用组标题上的单一“本书”遮盖差异。“本设备”也不等于“当前浏览器”，暂不使用“全局”作为唯一说明。应用外观与阅读器纸面继续明确分开。

### 5.2 本轮结构实施可以不做数据迁移

复制刚完成数据库迁移，继续使用该契约，旧浏览器复制值保持忽略。排版、注音与界面偏好可以先沿用当前读写，仅调整结构和准确标签。

后续是否迁移，按用户希望换浏览器后保留哪些习惯决定：

| 候选 | 值得讨论的原因 | 需先决定的行为 |
| --- | --- | --- |
| 把字号／行距／方向与阅读位置分开 | 配置保存不必依赖位置采样或位置冲突，所有阅读设置有更清楚的拥有者 | 哪份现有位置里的配置作为初值；新设置与历史阅读恢复谁优先；如何保留当前位置 |
| 让字体／注音等本书习惯跨浏览器一致 | 用户不必在每个浏览器重复设定 | 按材料还是版本；旧浏览器值与数据库值冲突时如何选；是否存在设备例外 |
| 宽度、纸面、工具栏等继续本地化 | 与屏幕和使用环境相关 | 是否需要跨书默认与逐书覆盖；未确认前不引入继承体系 |

上述是候选，不是迁移清单。不能为了让四组结构看起来整齐，就把所有配置放到同一个存储。未来若迁移，仍须备份、增量升级和明确旧值优先关系，不能复制本轮复制配置“忽略旧值”的选择到全部已有阅读偏好。

## 6. 调查时的方案比较与实施切分

| 方案 | 收益 | 代价 | 本轮建议 |
| --- | --- | --- | --- |
| A. 保留完整阅读面板，按用途渐进展开 | 边阅读边调整，一处找齐；不要求存储迁移 | 需要清楚区分即时值与复制草稿，并管理草稿生命周期 | 推荐 |
| B. 阅读面板只保留快捷项，复制等移至全局“阅读与摘录”页 | 面板更短，长期默认值有独立管理入口 | 新增分类、离开与返回流程；复制试调需切视图，容易重复草稿与控件 | 长期配置明显增加时再考虑 |

调查时建议按以下顺序收口，每一步根据前一步结果定范围：

1. 四组结构、同次阅读保稿和分组恢复已确认。
2. 做桌面和窄屏的低保真交互，验证首屏可达性、展开状态、保存反馈和键盘顺序，再定具体样式。
3. 实施前端结构、分组恢复和已确认的会话保稿。`ReaderSettings` 负责用途分组，复用既有取文、复制草稿、Query 缓存、注音提交与阅读呈现 module；折叠只隐藏内容，不卸载编辑状态。4.2 的编辑状态拥有者与导航协调单列实施，其 interface 同时供表单与离开保护使用。仅因共享显示样式不建立统一设置引擎，三种读写机制保持明确。
4. 如用户确认跨浏览器排版习惯或位置解耦，再独立设计数据契约与迁移。

未来结构验收至少覆盖：17 个设置都可达；每个值只有一个编辑入口；隐藏内容不进入 Tab 顺序；折叠不丢草稿；重开及换工具状态清楚；错误在组收起时仍可发现；复制保存失败与冲突保稿；每组恢复只改目标字段；横竖排及注音等待不跳离当前原文；窄屏、长标签和键盘操作可用。保存默认值不得改写已存在的学习内容。

## 8. 桌面与窄屏低保真交互记录

原型在本次对话中以交互预览交付，可切换“桌面阅读”和“窄屏阅读”。两种布局使用相同的演示状态：桌面保留正文与右侧设置，窄屏采用覆盖面板，书名和阅读工具仍可达；各组展开内容在面板内部滚动。

原型用中性线框和自写合成日语展示操作路径，控件尺寸、颜色、面板宽度及窄屏覆盖位置均不是视觉定稿。所有保存、失败和冲突仅为模拟，不连接应用服务、日常数据库或系统剪贴板；“试用带上下文复制”展示按模拟已保存配置生成的文本。

建议试用以下路径：

1. 调整字号或注音显示，展开更多选项；恢复排版后检查注音仍保留自己的值，体会各组的独立范围。
2. 展开复制组并修改句数，关闭设置、切换书籍信息、切章或切换桌面／窄屏，再打开检查草稿；收起的摘要仍显示已保存值和未保存提示。
3. 有修改时点书架或换书，分别选择继续编辑、保存后离开或放弃并离开。通过原型的“模拟保存结果”选择失败或冲突，检查草稿和处理入口。
4. 恢复复制默认值后查看未保存状态；保存前，试用复制仍采用此前已保存配置。格式示例随草稿更新，与实际复制的已保存值区分。

这一轮重点判断：常用项是否容易找到、展开后是否保持方向感、关闭与离开的差异是否清楚、保存状态能否在面板收起时发现。看过后再决定具体视觉样式，以及是否同时调整排版与注音的持久化范围。
