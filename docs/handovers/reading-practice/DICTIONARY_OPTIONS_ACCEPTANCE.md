# 即时查词辅助选项验收

日期：2026-11-03。改动起点：`main 9d860895`。交付范围为即时查词辅助选项与设置精简，代码、测试和文档作为同一批次收口。产品规则见 [PRD](../../PRD.md#epub-即时查词)，交互见[即时查词](../../INFORMATION_ARCHITECTURE.md#即时查词)，操作见[使用指南](../../USAGE.md#即时查词)。

## 交付范围

- 即时查词设置增加“自动扩展查词”和“辅助排序”，默认开启、独立切换，在当前浏览器跨书保存并跨标签同步。
- 关闭扩展后，点击候选必须从指向字符开始；明确选区始终精确匹配。限制在 sequence 最佳命中及结果截断前应用。
- 关闭排序后，仍按覆盖长度优先、词典原始顺序排序。基本词形还原、活用说明及同 sequence 的释义聚合保留。
- 配置随请求冻结并进入缓存键，切换清除整组词卡与高亮，旧请求不能恢复卡片。短视口内设置可滚动至管理入口。
- 请求新增 `auto_expand`、`assisted_ranking`，默认均为 `true`；已重新生成 OpenAPI 与前端类型。无数据库迁移、新依赖或新增 TBD。

## 实际浏览器观察

主代理通过浏览器打开临时 FastAPI／Vite 实例，使用独立 SQLite 库、合成 EPUB 与 format 3 词典。未访问日常学习库或真实模型。

- 设置中两项初始开启；逐项关闭时菜单保持打开，刷新后关闭状态保留。
- 两项关闭时点击「食べました」的「食」，得到「食べる」和实际活用说明。
- 同样点击「国際連合大学」的「大」：关闭扩展时只得到「大学」；重新开启后首项为「国際連合大学」，另有「大学」候选。
- 有词卡时切换选项，整组词卡消失，设置仍可操作。
- 浅色临时页面及深色合成场景中，开关、说明与焦点可辨。桌面菜单完整；320×320 和 640×360 的菜单限制在视口内，可滚动至“管理词典”。
