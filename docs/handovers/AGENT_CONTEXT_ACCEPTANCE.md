## 范围与决定

旧注入原样保留，首轮提供全部当前上下文，后续只追加变化模块的完整当前值。来源、片段、学习背景、讲解预设各自独立；本轮消息正文每轮单独追加。采用模块完整替换，清空字段与取消预设能明确覆盖旧状态，暂不引入字段级patch。

通用组装器不认识画像字段。显式插件元组决定顺序，插件可输出多个有稳定身份和版本的事件，分别进入system与context流。成员增删或换序时追加该流完整快照；规则升级在尾部更新，不重写原system。模板与插件事件均在受理时冻结。

基线与实际继承的成功Job一致；失败任务不推进，旧数据、损坏基线和协议切换保守重建。内部写作分支、工具结果、成果恢复和权限检查沿用既有执行路径。不新增依赖、API字段、数据库表或迁移；翻译路径不变。
