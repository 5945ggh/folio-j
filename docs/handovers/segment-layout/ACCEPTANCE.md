## 实现与保留

- SegmentFrame 提供 56px 局部工具栏，进入片段页不挂载全局主导航，也不修改其偏好。窄屏使用同组顶部操作，讨论占满内容区。
- 中央显示来源与片段身份、原文及补充资料、讲解集合和单篇文档。移除混合导航与重复讨论入口；新建／AI 生成归集合，编辑／版本／删除归单篇，片段管理归工具栏。
- 讲解目录可折叠且不显示内部编号；仅在展示副本中移出简单首标题，保留 Markdown、修订和 Section 锚点。空前言不占阅读空间。
- Workbench 保留首次激活后挂载、线程选择和迟到成果判断；人工编辑器保持独立挂载。原请求核实、摘要校验、基础修订和不可变修订协议沿用原实现。
- 用户的 AnalysisEditor、editor.ts／css／test 与 reader-refresh.css 相对开始时备份逐字节相同；已有文档修改保留。无后端／schema／依赖变更，无新 TBD。

## 2026-10-20 原文语境与配色收口

用户确认点击整张原文卡片直接打开资料浮层，并提供编辑入口。本轮以此前布局工作区为起点；页面内原文展开与补充资料折叠由该浮层替代。

- 新增 OriginalCard，显示保存的前文末尾、当前原文、后文开头；前后文最多展示约两行并向外渐淡，目标原文预览最多四行。没有语境时不占位；完整文字均保留在浮层中，没有改写数据。
- 浮层复用原生 dialog，直接展示完整语境／原文／译文／附带资料，提供编辑入口。Portal 放到阅读区之外的同主题容器，避免讨论开启并缩窄窗口时继承阅读区的隐藏状态。关闭将焦点交回当前可见的卡片或讨论开关。
- 片段空间使用黑色主操作与灰色辅助控件，覆盖新建、讨论设置、成果按钮、悬停与焦点；保留删除、错误、警告颜色。其他路由与用户此前修改的编辑器文件未改。
- 删除 SegmentPage 中原文展开状态、ResizeObserver 溢出测量及资料字段拼装；人工保存协议、讨论协调器和返回路径沿用原实现。无新依赖、后端变更或 TBD。
