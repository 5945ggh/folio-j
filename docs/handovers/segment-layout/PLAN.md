# 片段页布局调整

2026-10-20。用户已批准“左侧窄工具栏＋中央阅读区＋右侧讨论面板”。以当前工作区为起点，保留人工表单简化与公共配色调整。

## 范围与操作归属

- 片段页隐藏全局主导航，使用约 56px 的专用工具栏：顶部返回明确来处，中部讨论开关，底部片段管理。窄屏将同组工具转为紧凑顶栏；不改变其他页面的导航偏好。
- 页面身份显示一次来源名称和“片段”。原文作为共同参照，前后文渐淡预览，译文／完整语境／备注和日期放入资料浮层；移除行为不同却并列的原文／讲解／讨论导航。
- 讲解集合负责列表、新建和 AI 生成入口；单篇负责编辑、版本信息和删除。目录可折叠，默认不展示内部编号。减少重复标题与空前言留白，保留源 Markdown、Section 锚点和确切修订。
- 讨论仍按需首次挂载，启动后收起保活。开关只改变显隐，不重置线程或讲解；窄屏展示全宽讨论层，关闭后恢复阅读位置。

## 实施顺序与所有权

1. 先保存用户已有 diff 的只读备份，运行导航、生命周期、讲解写入等现有目标回归。新增纯展示规则先写测试再实现。
2. 主代理负责 SegmentPage、片段专用外壳和布局样式、浏览器集成及文档。独立开发代理负责 AnalysisPanel 与讲解展示规则／样式；独立审查代理核对生命周期、返回及保存风险。
3. 不改后台、模型调用、任务协议、用户已简化的人工编辑器或其配色文件；不增加依赖。资料浮层、列表切换和讨论显隐各自保留状态。
4. 先检查目标测试，再完成 lint、全量测试、构建和文档检查。浏览器使用隔离数据库，不迁移或修改日常数据。

## 验收

- 普通入口和历史讲解直达不查询讨论／模型设置；页面没有全局主导航，返回可恢复来源视图和查询条件。加载、错误及不存在状态也有明确出口。
- 手动保存、全文修订、旧版只读、冲突保稿与原请求核实不回归；人工表单仍只有可选标题和正文。
- 激活讨论后输入草稿，收起、切换讲解、再展开仍在同一线程；窗口跨越桌面／窄屏断点不卸载工作台，不触发模型调用。
- 片段和讲解的删除分别位于各自菜单；生成状态及停止功能保留。菜单键盘、Escape、焦点恢复和触屏名称可用。
- 原文卡片整卡可打开资料浮层，长短原文和语境都可完整读取；讲解标题与正文安全去重，代码块／格式化标题不能误删；空前言不产生空区块，锚点仍定位正确。
- 桌面三列、收起讨论、窄屏阅读和讨论均无横向裁切；滚动与返回位置实际核验并截图。

原有 A1／A2 内容与恢复约束沿用。本次不扩展材料出处、翻译、TTS、Occurrence 或新 TBD。

## 原文语境与中性色调整

2026-10-20 追加：原文卡片显示前后文，距离目标原文越远越淡；只使用已保存的 context_before／context_after，不推断语境。点击整体弹出资料浮层，取代页面内展开。无语境不占空行，长原文与全部附带资料仍可完整读取；关闭浮层恢复触发位置，保留页面滚动与讨论状态。

将原文呈现与浮层收进专用模块，删除页面上的展开状态、溢出测量和资料字段拼装；保存协议与讨论协调器不变。配色按用户提供的 Source 页面使用黑色主操作、灰色辅助操作与中性焦点样式，限定在片段空间，保留删除／错误／警告语义色。

先运行既有导航、生命周期与编辑测试，再实现并检查长短／缺失语境、键盘开关、窄屏浮层、资料编辑返回及全页按钮颜色；新增纯逻辑仅在必要时引入并测试。
