# 本轮 CR 修复验收

2026-10-24，以 `3a2501d` 为代码基准，修复广泛 CR 确认的问题。实现沿用当前产品范围，不新增依赖、数据库表或 TBD 决策；测试使用临时数据库、模拟模型和隔离 Chrome。

## 修复与回归

### 1. EPUB 完整产物预算

构建时对标题、属性、警告、JSON 转义和结构计账，超出 64 MiB 及时拒绝。重复大标题、各类元数据和完整 JSON 大小对照回归覆盖早期终止。回归入口：[编译回归](../../backend/tests/test_epub_compiler.py)。

### 2. EPUB 多目录编译

每资源复用叶子索引；少量实际请求的边界用标准库 NFC 前后缀判定并缓存，超过阈值再建立来源索引。回归覆盖长资源少目录、多目录、Hangul、前导组合符和跨叶重排序，固定样例保持 HTML、偏移和摘要等值。回归入口：[编译回归](../../backend/tests/test_epub_compiler.py)。

### 3. 审核批准与附加要求

批准始终先应用已展示方案；成功后再向模型传入附加要求。回归覆盖确切保存、决定重放和陈旧版本拒绝。回归入口：[审核回归](../../backend/tests/test_analysis_agent.py)。

### 4. 失败残文保留

快捷讲解遇到连接异常、超时或输出上限时保留已收到的脱敏残文，仍标失败、不保存成功讲解、不纳入后续成功历史；四类分支均有回归。回归入口：[运行回归](../../backend/tests/test_chat_runtime.py)。

### 5. 流式持久化节流

每调用合并增量，按 250ms 间隔写入，结束或异常立即刷新；授权与进度仅查询必要字段。受控时钟、事务计数及停止和删除竞态覆盖写入边界。回归入口：[进度回归](../../backend/tests/test_stream_progress.py)。

### 6. 历史分页与轻量摘要

工作台首屏读取最近 50 条，按需加载更早消息，消息页附带确切成果和失败重试摘要，避免逐条请求完整 Job。回归覆盖分页顺序、刷新去重、固定查询数与历史成果及失败操作。回归入口：[API 回归](../../backend/tests/test_chat_api.py)、[浏览器回归](../../frontend/browser-tests/workbench-history.tsx)。
