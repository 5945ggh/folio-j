# 本轮 CR 修复验收

2026-10-24，以 `3a2501d` 为代码基准，修复广泛 CR 确认的问题。实现沿用当前产品范围，不新增依赖、数据库表或 TBD 决策；测试使用临时数据库、模拟模型和隔离 Chrome。

## 修复与回归

### 1. EPUB 完整产物预算

构建时对标题、属性、警告、JSON 转义和结构计账，超出 64 MiB 及时拒绝。重复大标题、各类元数据和完整 JSON 大小对照回归覆盖早期终止。回归入口：[编译回归](../../backend/tests/test_epub_compiler.py)。

### 2. EPUB 多目录编译

每资源复用叶子索引；少量实际请求的边界用标准库 NFC 前后缀判定并缓存，超过阈值再建立来源索引。回归覆盖长资源少目录、多目录、Hangul、前导组合符和跨叶重排序，固定样例保持 HTML、偏移和摘要等值。回归入口：[编译回归](../../backend/tests/test_epub_compiler.py)。

### 3. 审核批准与附加要求

批准始终先应用已展示方案；成功后再向模型传入附加要求。回归覆盖确切保存、决定重放和陈旧版本拒绝。回归入口：[审核回归](../../backend/tests/test_analysis_agent.py)。

### 4. 失败残文保留

快捷讲解遇到连接异常、超时或输出上限时保留已收到的脱敏残文，仍标失败、不保存成功讲解、不纳入后续成功历史；四类分支均有回归。回归入口：[运行回归](../../backend/tests/test_chat_runtime.py)。

### 5. 流式持久化节流

每调用合并增量，按 250ms 间隔写入，结束或异常立即刷新；授权与进度仅查询必要字段。受控时钟、事务计数及停止和删除竞态覆盖写入边界。回归入口：[进度回归](../../backend/tests/test_stream_progress.py)。

### 6. 历史分页与轻量摘要

工作台首屏读取最近 50 条，按需加载更早消息，消息页附带确切成果和失败重试摘要，避免逐条请求完整 Job。回归覆盖分页顺序、刷新去重、固定查询数与历史成果及失败操作。回归入口：[API 回归](../../backend/tests/test_chat_api.py)、[浏览器回归](../../frontend/browser-tests/workbench-history.tsx)。

### 7. 稳定历史渲染

稳定消息与 Markdown 复用渲染结果，草稿输入和活动消息更新不重渲其他历史正文；真实组件的长对话浏览器回归同时检查复制、失败恢复和成果入口。回归入口：[浏览器渲染回归](../../frontend/browser-tests/workbench-render.tsx)。

## 验证结果

- `just lint`：ruff、格式、pyright、Biome、TypeScript 与脚本静态检查全部通过。
- `just test`：后端 663 项、前端 575 项全部通过；测试禁止真实网络与模型。
- `just gen-api`：消息摘要及反向分页契约已重新生成并随实现保存，无数据库 schema 变更。
- `just build`：通过；仍有单个 JS 包超过 500 kB 的体积提示，本轮不增加依赖或扩展分包范围。
- `just test-browser`：48 组隔离 Chrome 配置全部通过，包含原有阅读、资料、翻译、主题等回归及新聊天历史、渲染用例。
- `just check-docs` 与 `git diff --check`：通过。

浏览器实际观察：40 条历史回复可正常显示 Markdown，恢复的问题与附加要求留在底部输入框；活动任务时停止入口可用、发送禁用，模型和审核模式持续可见。1280／390 宽的渲染回归均通过。

## 独立复审

后台运行、EPUB、聊天查询与渲染均由未参与对应实现的代理复审，并通过独立离线探针或真实组件回归验证。

EPUB 复审发现一项新性能回退：少目录大资源遇单个 NFC 接缝时，新索引对全资源逐码点映射。补入少叶、多叶但少目录以及阈值切换回归后，改为按实际边界请求延迟建索引。8 MB／两章样例从问题版本的 5.003 秒恢复到 0.414 秒，原版为 0.399 秒；完整产物与 partition 相同。800／1600 目录性能及 20000 组 Unicode 边界对照重新通过，发现已关闭。

最终全量验收还发现新增失败分支测试把所有异常期限均设成 10ms，可能先触发真实超时。已将期限限制仅用于超时分支，以有界事件握手确保先收到待验证缓冲，并保留真实监督超时与残文断言，重复验证及最终全量通过；主代理另行复核该测试修改。

收口时未发现剩余可复现 P1／P2。

## 验证边界

离线与浏览器回归验证执行、数据及交互行为。未访问用户日常数据库，未调用真实模型，不验证第三方服务教学质量或实体设备兼容性。性能数字来自本机合成输入，回归测试使用操作计数与状态断言，避免依赖固定耗时阈值。
