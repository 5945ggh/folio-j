# 数据位置选择与启动恢复验收

2026-11-09，实施起点为本地 `main 61c153c6`。本批提供首次默认／自定义位置选择、打开已有学习库、记住位置、启动故障恢复，以及设置中的实际路径查看与复制。用户另报告 Windows 安全软件可能按进程拦截用户目录写入；该实机原因未在 Mac 复现，本批不修改安全策略、ACL 或自动提权。

## 实现与保护范围

生产启动使用同一个本机服务，未选数据或数据故障时显示独立启动页，完整应用的迁移、生命周期和记忆保存成功后再进入学习界面。旧默认库、旧配置、程序目录旧库与显式环境变量继续兼容。位置记录与学习内容分开：Windows 当前用户注册表，POSIX 独立 JSON；权限或记录保存失败均可读，不以空库代替失联库。

同一会话中已明确确认的位置若迁移失败，可重新验证并原位重试；纯进程锁残留可继续使用同一排他锁，不删除锁或放宽一般配套文件保护。已有模式核对 Folio-J 表与迁移记录，拒绝无关 SQLite。冻结入口非零交互失败等待回车，管道调用和正常退出不等待。

新增状态只承担启动职责：`StartupService` 管理尚未就绪、错误和已确认候选、主应用资源；`LocationStatus` 统一解析出的路径、来源、服务配置与错误；设置页只读实际运行路径，不参与切换。不提供扫描、搬迁、合并或运行中切换；无新增依赖、ORM 迁移、prompt 或 TBD。正常及独立启动路由的 OpenAPI 已重新生成。

## 本地验证

本机 macOS ARM64，最终交付检查通过：

- `just lint`、`just test`、`just build`、`just gen-api`、`just check-docs` 和 `git diff --check` 通过；后端 1508 passed、3 skipped，前端 826 passed。3 项跳过为 Windows 原生控制台与 Job Object 平台检查。
- 位置解析、Folio-J 身份、丢失记录不回退、权限提示、位置保存失败、孤立锁候选重试、迁移／真实应用生命周期失败及释放、CSRF／Host 拒绝、失败控制台暂停和管道不等待均有定向回归。真实重复停止屏障确认新生产入口仍等待清理，不因第二次请求强制退出。
- 数据位置浏览器回归 4 场、既有模型设置回归 2 场通过；覆盖窄屏／深色及复制、失败重试和草稿返回。
- `0.1.0-data-location-local.2` 本机生产依赖冻结包构建通过，原目录完成全部离线冒烟；tar.gz 解压到新中文空格目录后另测首次选择、创建合成来源、记住位置、原库失联、原位恢复及再次启动，同一来源与数据路径保持。所有检查使用独立临时 HOME、空 PATH 和合成数据；该工作区构建的 `dirty=true` 如实保留，不作为正式发行。

本地冻结包第一轮接力脚本将 `/var` 与规范化后的 `/private/var` 字符串直接比较而失败；改为比较规范化绝对路径后通过，未据该失败修改生产行为。最终源码快照与 Windows 构建身份以 Git 提交和 bundle 为准。

首轮全量测试发现旧 `test_windows_reload` 的 start 夹具只替换旧启动器，入口统一后误启了仓库默认库，而未进入合成 ASGI 应用；进程已退出。只读检查默认库 `quick_check=ok`、迁移仍为 `0004_translation_reader_removal`，该时间窗口内没有新增 Run／chat job，也未发现新的开始或结束记录；缺少事前快照，不能据此声称库文件逐字节未变。夹具现明确替换新的生产入口，所有子进程强制使用临时 HOME／USERPROFILE／数据库路径，并安装网络防护、断言没有创建数据库；真实重复停止验证由合成 ASGI 清理屏障承接。

真实浏览器以独立临时 HOME、配置及端口 `18012` 验证：首次页面未创建默认目录；相对路径被拒绝且保留输入；选择含空格和 `𠮷` 的自定义目录后进入素材库；设置显示相同数据库路径。停服后仅移开该临时库，再次启动出现恢复页且未新建默认库；放回目录、重试原位置后恢复同一库，设置路径仍正确。未触及日常数据库或调用真实模型。

设置浏览器回归覆盖 1280／320 像素、浅／深色、长 Unicode 路径、复制成功／失败、读取失败重试、离开取消与迟到隔离；既有模型设置回归覆盖分类切换、草稿保护及自动保存重试。截图为合成路径场景，实际位置选择与恢复另按上述真实浏览器流程验证。
