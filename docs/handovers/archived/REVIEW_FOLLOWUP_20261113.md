## 迁移入口保护

仓库与源码发行模板的 `just migrate` 共用 `app.launcher migrate`，取得与后台服务及备份一致的数据库排他锁后执行 Alembic。真实命令回归先建立空库，再准备有待执行迁移的库：持 worker 锁时命令失败且完整 SQL 转储不变，释放锁后升级成功。两份旧命令均先复现失败断言，替换入口后通过。

Windows 字节锁的 EACCES 只在成功打开文件后的 locking 阶段归为占用，文件打开权限错误保留原诊断；模拟回归先复现错误分类，再验证修复和描述符关闭。Windows 清单同步使用受保护的直接迁移入口。

本批独立快照的 `just lint`、`just test`、`just check-docs` 与 `git diff --check` 通过；后端 1540 passed、3 skipped，前端 829 项通过。测试保留真实网络禁用守卫，仅允许其本机 socketpair 自检。回归执行仓库和发行模板的命令，未重新打包和解压源码包，Windows 原生运行未验证。本批无新依赖、数据库迁移或 TBD 决策。

## 聊天上下文预算

`services/context.py` 集中 200000 字符上限及当前 messages／冻结 tools 的 JSON 计量。首次受理、每次派发和 `save_analysis` 提交前的后续请求预检共用规则，保持原执行器的口径。两种协议、两种权限下，恰好达到上限可进入模拟适配器；超出一字符返回 422，线程和片段不变，无 Job、消息、Run 或原文锁定。拒绝后可修改问题并复用请求 ID，成功后同请求仍幂等重放。

## 搜索结果预览

首次打开只等待命中类型的章记录，译文仍核对出处摘要与确切结果 ID。另一类 503 或挂起不阻断打开与展开，本类刷新失败隐藏旧内容并保留重试，成功复核确认目标移除后关闭预览。已打开译文按出处维持身份，同出处重译可继续切换版本；普通后台重读与设置往返保留同处记录的所选详情，恢复核验期间按类型隐藏内容。

提交前审查另发现并修复两处回归：搜索单类快照不能让普通正文在组合记录尚未核验时提前开启行内译文；关联译文列表读取失败时保留已打开的删除确认和失败回执，只隐藏未核验的普通列表操作。前者用浏览器先复现提前插入行内译文的失败，再验证修复；后者通过真实取消点击确认模态框可关闭且页面恢复操作。未引入新的确认步骤。

搜索预览的局部目标标记区分命中类型及身份，查询状态区分首次／恢复核验、普通后台重读、成功与失败；状态由现有 Query 和 Reader 会话派生，不新增持久化协议。普通后台重读后出现新增分页时，沿用完整分页核验门禁，旧详情暂隐但保持挂载与选择。
