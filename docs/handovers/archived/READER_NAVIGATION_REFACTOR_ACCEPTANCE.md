# 阅读跳转深化验收

> 2026-10-22，代码起点 `efdcf61`，分支 `codex/reader-navigation-depth`。实现、工程检查及浏览器验收完成，随本次提交交付。

## 范围与设计

把阅读跳转的请求失效、目标校验、章节记忆选择、临时原点和相邻切章锁集中到 `materials/reader-navigation.ts`。目录、搜索、图库、显式章首、相邻章和返回使用同一个生产 interface。产品行为沿用 PRD 4.7；保留 `ReaderLayout`、`PositionQueue`、`JumpReadingSession` 与现有 DOM 几何算法。

比较了命令式、语义事件和 React 事件绑定三种设计。采用命令式：调用方提交导航意图和发起侧，module 持有请求与 surface 的独立身份，状态快照直接供页面显示。语义事件会增加当前任务不需要的事件类型，React 绑定会把导航 module 与面板 prop 名称绑定；两者未采用。

章节读取继续使用现有 QueryClient。生产 DOM adapter 交接目标与呈现完成回执，布局和资源就绪仍由 `ReaderLayout` 校验。测试使用可控章节加载及呈现 adapter，直接验证同一 interface；没有引入新依赖、通用导航框架或存储协议。

## 清理计划与行为基线

先写清理计划，再由独立设计代理审查。审查补充了请求／surface 身份分离、完成回调捕获原始回执、返回原点修订和卸载后旧资格不能复活等条件。实现代理负责生产文件，测试代理负责表征与测试迁移，独立审查代理复核改动，主代理负责集成、文档与浏览器验收。

重构前原有 58 项针对测试通过。随后用 TypeScript AST 提取当时生产 `choose`、`navigateTo`、`stepChapter`、工具取消及恢复完成回调，配合真实 `ReaderLayout` 执行 9 项临时组合表征，全部通过。未在持久测试中复制页面流程。

表征覆盖连续 A→B→C 的原点、乱序请求、相邻锁直到稳定恢复、返回失败及重试、当前章不跳、重复物理章首、加载期间最新排版以及工具开关取消。临时脚本、原始源码、命令和通过证据保存在 `/tmp/folio-reader-navigation-20261022/`。
