# 设置页交互整理验收

日期：2026-10-31。起点为本地 `main b5ac4b7`，本记录覆盖 `codex/settings-polish` 上的设置页整理；此前学习偏好默认入口及自动保存已在起点提交中。

## 交付范围

- 模型配置按用途点选即保存；新对话默认权限点选即保存，已有对话保留自身权限。
- 自动保存成功提示约 2.5 秒后消失，每次保存重新计时；保存中、未保存及失败状态继续显示。失败保留输入，提供重试和放弃修改，离页保护沿用现有草稿机制。
- 服务详情按模型、连接设置和验证记录组织。连接与访问密钥分别提交；登记模型统一提供列表勾选和手动输入，部分失败保留未完成项。
- 验证记录提供模型与状态筛选，展开后先显示回复或失败原因，协议、提示词版本和用量放在调用详情中。
- 翻译设置直接显示阅读翻译与前后文范围，选择模型立即保存，语言及数字结束编辑时保存；冲突时保留草稿并对照差异，再由用户采用已保存设置或确认写入。

审查发现并修复两处保存边界：默认模型在失败重试与后台刷新同时发生时，可能把未编辑用途的旧值写回；快速切换后选回原值时，在途刷新可能覆盖最后选择。前者限定提交的用途，后者在保存期间保留输入，回归覆盖后台刷新、重试及排队切换。

现行行为由 [PRD](../../../PRD.md#f1-设置)、[设置交互](../../../INFORMATION_ARCHITECTURE.md#设置顶部分类)与[使用指南](../../../USAGE.md#模型设置)维护。本轮无数据库或后端接口变更，无新增依赖，未触及 TBD。
