# 维护性审计复核与局部收敛

2026-11-08，复核用户提供的 FJ-MA-001～004 静态审计。实施起点为 `main 1cca8c57`，改动位于 `codex/maintenance-audit` 工作区。三名子代理分别负责测量入口、预览职责和观察项核实，主代理集成并验证。四项发现均属实；本轮处理 001、002 和 004 的部分重复断言，003 保留观察。

## 核实与取舍

| 编号 | 核实结果与处理 |
| --- | --- |
| FJ-MA-001 | 修复前实际运行当前测量，在启动 Chromium 前报 `ERR_MODULE_NOT_FOUND`，将 `./chromium.mjs` 解析为 `frontend/chromium.mjs`。测量入口改为正常执行运行器文件，删除读取、替换并通过 stdin 执行源码的逻辑；运行器的场景工具恢复普通相对导入。专用 `reader-baseline.mjs` 插件只负责四个历史模块的内存替换及 Git 前提诊断。 |
| FJ-MA-002 | 正式 `StudyPreview` 调用方只有 `ChapterRecords`，主题测试 fixture 也只用嵌入模式。删除独立浮窗头部、定位状态与监听、独占参数、`studyPreviewPosition` 及其专属几何测试和定位 CSS。外层显式拥有 anchor 与展开／收起参数；内层保留内容查询、身份校验、选择、Escape、焦点和裁剪。共享标题／动作样式与 fixed／expanded 内容规则保留。 |
| FJ-MA-003 | 两种卡片确实重复测量朗读条避让、可用区域、手动边界及尺寸监听，但内容测量、观察对象和锚点语义不同，已有定位、约束与拖动函数共享。本轮不再增加统一 hook；下一次统一修改两处布局时，评估共享可用区域与最终位置计算。 |
| FJ-MA-004 | 删除已由浏览器计算样式覆盖的中间透明度、重排不重新变亮、新目标全亮、主题更新及禁止 `currentColor` 的精确字符串断言。保留终端透明度为零且注册表仍存、首次与重投影捕获前景色的检查，以及范围、Unicode、注册表、身份与清理保障。 |

004 的保留依据：现有浏览器场景在首次检查淡出前先切主题，主题刷新可掩盖首次投影未捕获前景色的错误；字号重排后只检查背景透明度。它们尚未完整覆盖上述三项单测，不能据已有浏览器测试将剩余字符串断言全部删除。

没有新增产品状态、持久化协议、依赖或 TBD 决策。历史插件仅供开发测量，不被生产代码调用。现行职责见[架构](../../ARCHITECTURE.md#资料写入与材料出处契约)，测量使用方式见[开发指南](../../DEVELOPMENT.md#阅读会话性能测量)。
