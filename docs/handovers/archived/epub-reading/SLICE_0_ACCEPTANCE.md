## 正文与位置规则

- XML 解码实体，统一换行；定位叶子保留源文本，所有叶子串接后全局 NFC。不使用 NFKC、不逐叶 NFC；源 EPUB 字节不改写。
- `rt`／`rp` 保留呈现但不进入坐标；脚本、样式、交互元素及显式 hidden／aria-hidden 内容不进入定位正文。CSS 不决定正文身份；选择或恢复含 CSS 隐藏正文的范围会失败。
- 块元素末尾在前一定位叶子尚未以换行结束时补一个换行；`br` 显式加入换行。源 XML 的正文空白保留，所以漂亮排版用的源换行也可能进入坐标；这是固定试验投影规则，不是屏幕排版读取。
- 每个正文叶子有连续编号；浏览器核对编号顺序、全文投影、版本、资源、码点范围及快照。重复文字不按搜索命中定位；相同文字的叶子交换顺序也会被拒绝。
- DOM 的 UTF-16 边界转换到 NFC 码点半开范围。代理对内部或跨节点 NFC 不可分离边界被拒绝；恢复后重新捕获并核对同一范围。
- 普通 NFC 正文反向查找线性扫描；非 NFC 正文使用 `Intl.Segmenter` 缩小转换范围并验证结果，不迁移 Unicode 字素属性表。当前浏览器具备该能力；缺失时不猜测分解正文的位置。
- 只支持当前单个已加载资源；同一 manifest 资源重复出现在 spine 时复用资源身份。显示组织不成为全书偏移，跨章节选区尚未实现。

## 隔离与明确限制

无脚本 `sandbox="allow-same-origin"` iframe 加 CSP；受控 HTML 清洗、事件／外跳链接剥除；图片仅包内 PNG／JPEG／GIF／WebP 转 data URL。ZIP 不解压到任意路径，限制成员数量、大小和展开比例，拒绝逃逸／重复路径。XML 实体声明在编码无关解析回调中拒绝，覆盖 UTF-8 与 UTF-16 LE／BE。

包内 CSS import 有深度、大小和循环上限；不支持的导入语法、远程引用或缺失文件产生 warning。CSS 的背景图片和嵌入字体 URL 目前未重写，CSP 阻止相应请求；这不等于完整作者资源兼容。文档必须是可解析 XML XHTML；全书固定版、DRM／加密及字体混淆、复杂 SVG／MathML、多媒体不支持。普通重排书中的纯图片固定页仅作为图片呈现。

当前目录按 spine 资源展示，未解析正式目录标题与片内链接；真实书有多个同名资源按钮。该 UI 用于选区试验，不是生产章节导航验收。尚无翻页、进度持久化、跨资源选区、学习入口或模型调用。

Yomitan 只验证普通可选择的 DOM 文本／ruby 条件；没有安装或实际运行扩展，不宣称兼容。

## 用户反馈与后续收口

首次验收后提出阅读方式和 Yomitan 两项选择。用户后续已确认：

1. 当前横竖排效果满意；分页与恢复交由工程判断，允许近似恢复，但调整字号／行距后应避免明显跳位，按拼好的逻辑章组织阅读进度。工程决定先做横竖排滚动，以资源正文位置恢复、百分比辅助显示。
2. 章节不能直接等于 spine 项；图文应连续组章，章名明确采用原书目录标签，不增加手动编辑或自动翻译。LearningJ 的双层身份可借鉴，具体组章不能直接照搬。
3. 原书振假名继续保留；后续分词注音不覆盖原书，作为独立派生显示层。

这些是后续实现方向，不表示当前试验页已经增加目录组章、自动注音或阅读恢复。章节与进度要求已补入[切片 1 草图](../../epub-reading/SLICE_1_DRAFT.md)。Yomitan 实测安排及剩余兼容边界仍待收口；材料入口与删除影响在切片 1 持久化前按草图具体对齐，不提前修改用户存量数据。
