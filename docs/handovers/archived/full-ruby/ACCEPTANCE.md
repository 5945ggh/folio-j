## 限制与范围

自动读音来自本地词典推断，仍可能误判专名和同形异音；本轮不提供人工纠错。跨 Text／格式节点／part、原 ruby 重叠或无法安全对齐的候选不显示自动读音，持久 token 仍保留。长输入的硬分块可能影响边界分词，不承诺与整段解码语义等价。

未实测实体触屏、Yomitan 扩展、Safari／Firefox、全部复杂出版物 CSS 或长期压力。恢复采用正文 1em 留白，极端作者自定义大号 rt 的全部排版不在本轮验证范围。所有实际写入发生在独立验收库，未调用真实模型。本轮未关闭既有 TBD，新增依赖仅为已批准的 SudachiPy 与 core 词典。

## 2026-10-07 阅读进度回归修复

后续用户报告切换注音显示及刷新会回章首。上一节验收遗漏了长章非零位置的纯显示切换和刷新后的迟到读音更新；该次“设置不闪章首”结论不能覆盖这些路径。本节记录复现、根因和修复后的实际证据。

### 复现与根因

修复前真实长章从 `scrollTop=5401.5` 点一次“隐藏→显示”即变为 `1`，见 `evidence/progress-regression/reproduction.json` 和 `before-fix-show.jpg`。冷打开预置的 `p-004` offset 12000 也被章首图片位置覆盖。

原地布局 effect 对整个 bookUi、主题和 readings 数据变化无条件调用尺寸探测，将 iframe 临时缩为 1px；纯显示切换及原书范围下读音迟到没有进入恢复状态，滚动被压回章首后又通过 observe 写入数据库。初始字体／图片完成后的多层 rAF 重复测量也可能发生在首次恢复已结束之后。

修复将几何设置与纯呈现分开，并将所有已就绪尺寸测量统一纳入“保护锚点与禁止采样→更新／测量→恢复→开放采样”的流程；移除初始多重 rAF 测量。新增三个回归直接抽取执行实际组件 callback，检查真实编排中的恢复锁与测量调用；DOM 与 restore 仍为模拟，以下浏览器与数据库证据补充实际行为验证。
