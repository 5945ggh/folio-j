## 已确认行为

- 新书导入完整生成并校验分词结果后才完成并允许阅读。处理期间显示准备状态；失败提供重试，不发布可进入的半成品。导入窗口已关闭时不在完成后强制导航。
- 已有书籍可直接补算，原书字节、材料版本、正文、阅读位置保持不变。普通准备复用有效结果；显式重建完整成功后才切换当前结果，失败继续使用旧结果，相同结果和配置不重复发布。
- 注音范围为原书／全量，显示方式为展示／悬浮展示／隐藏，首次默认原书与展示，之后保留明确选择。全量保留原书 ruby 并补充未覆盖的含汉字范围。悬浮／隐藏保留注音几何空间；触屏和键盘有对应的查看入口。
- 阅读设置不放重新生成入口，后端重建机制保留。调整设置在当前正文原地重排和恢复，不展示尚未恢复位置的新章首画面；全量数据未就绪时保留当前范围与正文。
- 原书 ruby 优先。无法可靠跨结构包装的候选跳过；送假名可可靠拆分时只给汉字部分注音，否则回退整词。无可用读音不强行补音。

## 数据与执行边界

采用 SudachiPy、SudachiDict-core 与 A 粒度。句级处理作为起点，一个操作复用分词器；长输入按 UTF-8 字节预算分块。处理窗口不形成 Sentence 实体，结果直接定位到不可变资源正文的 Unicode 码点半开范围。

分析代次记录材料版本、各资源正文摘要、分析器与词典版本、切分模式、分句／分块规则及结果格式版本。token 保存原文表层与范围、整词读音、词典形、规范形、完整词性及未登录词标记；不把词典内部 ID 或 token 序号用作永久原文身份。

生成移出事件循环和数据库写事务，发布前复核来源可见性、材料版本及当前代次。结果完整生成后在短事务内发布；不产生模型调用或 Run。SQLite 保存派生资产，保持空库与旧库可迁移。

前端仅使用生成的 API 类型与 TanStack Query。自动 ruby 包装必须保持定位叶子身份，排除所有 rt／rp，包装后重新建立正文 Text 映射。范围切换引起的重排沿用稳定原文锚点恢复；搜索高亮、选区和阅读位置不得依赖旧 DOM Text。

“返回跳转前”继续保留首次会话原点：连续 A→B→C 后返回 A，使用当前排版，成功后清除；实际 DOM 定位失败保留原点并明确反馈，不能在数据请求成功时提前消耗返回机会。

## 分工与验证

- 后端代理负责 NLP、持久模型与迁移、导入／补算／读取 API、生成客户端及新增后端测试。
- 前端代理负责准备状态、两维设置、ruby 包装与定位适配、独立新增前端测试。
- 主代理负责契约、文档、集成检查和独立数据库的浏览器验收；独立审查代理核对实际改动并报告缺陷。
- 保留已有测试优化工作，不改其现有测试文件或扩大其范围。新功能使用独立测试文件覆盖原文坐标、重建发布与注音关键行为。
- 完成时运行 `just gen-api`、`just lint`、`just test`、`just build`、`just check-docs`、`git diff --check`，记录实际结果。浏览器覆盖新导入／旧书准备、原书／全量三种显示、横竖排、搜索、重排恢复和失败反馈。

本轮不引入 Lexeme、Occurrence、材料对话、学习状态推断或读音人工纠错；不关闭既有 TBD。工程验收与真实阅读质量分别记录。
