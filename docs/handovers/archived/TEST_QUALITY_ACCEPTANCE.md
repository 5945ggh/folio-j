# 测试质量整改验收

日期：2026-10-23。范围为本轮凭据脱敏和测试质量整改；不改变产品范围、TBD 或分词／重复 spine 的既有兼容约定。

## 整改方法

先用字段解码、持久化结果和故障注入确认原测试漏检，再修复生产脱敏或替换断言。凭据、后端数据、前端由不同实施代理负责，主代理集成；独立审查代理只读复核，发现的脱敏边界回到实施代理补回归和修复。

只删除无效的局部检查：固定表数量、修改 HTTP 本地 JSON 后证明服务端缓存不可变、完整 CSS 源码表达式。大样本注音测试保留原文和装饰结果，去掉未形成性能保证的计时及命名。不可变修订、幂等、删除隔离、竞争胜负、Unicode 和历史兼容样本均保留。

## 实现与检查入口

- 凭据：真实 SDK 搭配 MockTransport，检查两种协议的流式／非流式工具参数、协议历史与原始响应；临时 SQLite 验证执行状态及后续调用历史。测试凭据均为合成值。
- 自动调度：[test_worker_dispatch.py](../../../backend/tests/test_worker_dispatch.py) 通过 API 受理、等待审核、批准和观察终态，不直接调用 worker；设置验证也通过正常 API 自动执行。
- 竞争等待：[race_helpers.py](../../../backend/tests/race_helpers.py) 回收暂停任务，各调用方限制整个竞争场景的执行时间，早期失败保留原异常。
- EPUB：独立 HTMLParser 提取实际 locator 原文并做 NFC，与码点范围比较；真实上传产物继续用于跨节点、非 BMP 搜索。并发导入要求两请求都进入编译后再发布，核对身份和实际复用事实。
- 排序与高亮：核对材料实际 ID 顺序、同时间次序和空值位置；高亮核对最终注册的全部独立 Range 端点。
- 浏览器：[browser-tests](../../../frontend/browser-tests/index.html) 挂载真实 MaterialsPage 和 StudySegmentPanel。`just test-browser` 自动启动本地 Vite、创建临时 Chrome profile 并回收；模拟 API 之外的 fetch 被拒绝，Vite 的 API 入口也拦截未模拟请求。

## 故障注入证据

所有变异仅发生在临时副本或独立进程内存中，正常代码不保留故障开关。

| 故障或等价调整 | 新测试结果 |
| --- | --- |
| 高亮只保留第一个区间 | 失败，缺少第二区间 |
| 最近打开排序忽略升序要求 | 失败，材料顺序不符 |
| 编译 HTML 的 locator 文字被改写，坐标和编号仍不变 | 失败，实际原文不符 |
| 并发提交复用旧材料却返回 reused=false | 失败，复用事实不符 |
| 聊天后台启动后立即退出 | 有界失败，任务未进入审核阶段 |
| 后置 CSS 覆盖卡片网格为 1fr | 失败，卡宽不随控件变化 |
| 交换 CSS min() 参数的等价写法 | 通过 |
| 双侧清空按钮误接为两次清空前文 | 失败，后文仍有值 |

## 验证结果

- `just check`：通过，包含 Ruff、strict Pyright、Biome、TypeScript、后端 570 项、前端 395 项、生产构建、文档链接和两项真实浏览器回归。
- `just check-assets`：通过，保留的 EPUB 定位、静态原型、原文解析及样本机械校验均通过。
- `git diff --check`：通过。
- 提交前简单独立复审：74 项定向测试和两项浏览器回归通过，未发现可行动的 P1/P2。
- 凭据回归先确认原实现失败；独立审查追加的重复键、部分 Unicode 转义与非法 escape 组合均补测并修复，最终定向复审 99 项通过，无剩余可行动 P1/P2。
- 浏览器故障注入确认错误布局／误接线会失败，等价 CSS 重排通过；缺少 Chrome 时命令明确失败。生产构建未包含测试入口。
- 构建输出仍提示单个 JavaScript chunk 超过 500 kB；构建成功，本轮未调整包拆分。

浏览器已观察到卡宽设置 140／280 分别呈现为 140／280px，容器缩至 120px 时卡片随之收窄；真实清空按钮、迟到设置读取及保存请求组合保留空语境和原出处。

## 验证缺口

- 未调用真实模型或外部 Provider；不证明模型教学质量或厂商所有非标准协议变体。
- 浏览器自动回归限于上述两个组合，API 使用模拟响应；没有覆盖全部页面，也没有运行前端到真实后端的完整浏览器链路。
- 本轮浏览器验证限于本机 Chromium 系浏览器；Firefox、Safari、实体触屏及扩展交互未验证。浏览器命令默认寻找 macOS Chrome，其他安装位置需设置 CHROME_BIN。
- 不扫描或改写历史用户数据库；修复保护后续处理与保存，不能据此证明旧记录从未包含凭据。
- 注音大样本用例验证正确性，不作为性能基准或复杂度保证。

- 提交隔离检查发现：纯 Git 快照缺少历史验收文档引用的 `temp/` 证据文件，完整文档链接检查依赖本地保留的这些资产；本轮新增文档和链接不依赖该目录。
