# 来源删除资源清理验收

日期：2026-11-01。基于 `f5a3c60`，实现位于 `codex/source-delete-cleanup` 工作区。原工作区的前端优化及 CR 改动未带入本次验收。

## 行为与范围

删除来源在同一写事务中清理全部下属材料的托管 EPUB、编译包、封面、阅读位置与使用状态、分词指针及全部代次，包括已软删材料遗留资源；材料保留身份、版本、历史出处、书签及备注，已有删除时间不改写。学习片段、讲解、讨论、任务及调用记录仍按既有规则软删除，译文结果与采用记录保留。

来源与单本材料删除共用 `services/material_cleanup.py`，由调用方持有事务；清理失败不提交任何部分结果。不自动追溯清理此前已删除的来源，不增加 schema、依赖、回收站或 VACUUM 入口。数据库空闲页供后续写入复用，文件不保证立即缩小。现行规则见 [PRD F2](../../PRD.md#f2-source-与片段)与[架构](../../ARCHITECTURE.md#31-实体)。

确认框说明原书和派生阅读数据清理不可撤销、本地原始 EPUB 不受影响，展示并重新核对书籍、片段、讲解、讨论、消息及活动任务数量。提交中阻止重复请求与关闭，失败保留确认框供重试。
