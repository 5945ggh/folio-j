工程检查：`just lint` 通过；`just test` 的后端 725 项、前端 602 项通过；`just build`、`just check-docs`、`just gen-api` 及 `git diff --check` 通过，生成的 OpenAPI 与前端类型无变化。构建保留现有大 chunk 提示。

完整离线 Chrome 回归通过，覆盖阅读器、章节记录、横竖排、宽窄屏、图片／定位、片段、翻译与主题等既有场景。真实 DOM 断言确认 iframe 内容、原文投影、图片几何和阅读返回正常；浏览器使用离线接口夹具，新物理 BLOB 经真实后端的验证由上述导入集成回归承担。本次未修改 UI，无新增视觉设计或真实模型调用。

## 限制

共享池仍将图片 data URI 保存一次，托管原 EPUB 另有原图副本；直接复用原 EPUB 图片不在本次范围。HTML 物理压缩不减少浏览器收到的逻辑章节数据，首轮不承诺阅读时间或内存下降。旧版本应用不支持新物理格式，降级需恢复转换前备份。

上述过渡维护工具已在下述收口中移除。当前开发库边界见[升级与备份](../../UPGRADING.md#epub-存储格式与开发库重建)，格式和不变式见[架构](../../ARCHITECTURE.md#31-实体)，当前交付状态见[实施基线](../MVP_IMPLEMENTATION_BASELINE.md)。

## 2026-10-25 单格式与编译器收口

用户明确授权放弃现有开发数据并删库重建。先补单格式、一次压缩、空图片池和预算边界回归，记录 8 项失败，再删除旧裸 zlib 读取、大小比较／回退、转码函数及专用维护命令／测试。存储 interface 仅保留 encode/decode；版本标识、图片原字符串、完整逻辑产物与身份、严格引用、整流校验和 64 MiB 逻辑预算保留。envelope 另限 128 MiB，容纳结构开销；空 HTML 的超限骨架也在起始检查中拒绝。

单格式存储 46 项、编译器／历史实验 58 项定向测试通过；真实导入、图片、定位、出处、翻译、统计与存储相关联测 163 项通过。独立只读审查未发现阻塞问题，并另用修改前编译器对比 16 组目录、NFC、ruby、缺图警告和重复 spine 输入，完整逻辑 JSON 全部逐字一致。

### 产物与安全边界

`CompiledResource` 删除 `html`，资源正文、正文摘要、CSS、html/body 属性、身份与元数据保留；完整 HTML 仅存于编译器私有 `_Publication`，供目录解析与分片使用。章节 HTML、图片原字符串及码点／叶子／spine 定位均保持原样。清洗、XML／ZIP／CSS 和中间工作预算不变，最终 JSON 预算改为只计实际保留的数据，继续限制 64 MiB。

逻辑契约为 `epub-reading-v2`，新产物按新模型与规则重新计算摘要。物理格式为 `FJEPUB` 版本字节 `2`，只保存章节 HTML 的共享图片池，不再含 `resource_html` 或资源 HTML 还原分支。模型与 envelope 拒绝冗余字段，即使旧 `html` 为空、旧 `resource_html` 为空数组也拒绝；v1、裸 zlib 和未知存储版本均拒绝。完整压缩流、章／part 数量、严格图片引用、128 MiB envelope 解压和 HTML 展开前的 64 MiB 预算均保留。

章节 HTTP 响应字段不变。`just gen-api` 已运行，OpenAPI 的 `ChapterPart` 增加 `additionalProperties: false`，生成的前端类型无差异；无 ORM 或关系表结构变化，不增加 Alembic revision。依赖完整资源 HTML 的旧实验导出 CLI `scripts/epub_spike.py` 及专属测试退役，历史三份静态 JSON、定位实验和合成 EPUB 生成器保留。
