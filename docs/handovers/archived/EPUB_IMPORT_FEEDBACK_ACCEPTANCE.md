# EPUB 导入书卡反馈验收

2026-10-25 实施，2026-10-26 完成提交前复核。产品行为见 [PRD 4.2.1](../../PRD.md#421-本轮材料目录与阅读管理)，当前交付状态由[实施基线](../MVP_IMPLEMENTATION_BASELINE.md)维护。

## 实现与边界

提交导入立即关闭弹窗，素材库和所属来源显示文件名占位、准备动画及不可点击状态。后端仍通过同一次 HTTP 请求完成编译和注音后原子发布，不增加数据库实体、接口或依赖。成功刷新目录，不自动进入阅读器；当前筛选或分页没有收录结果时，临时卡提供阅读入口。失败显示原因，保留原文件供明确重试，允许移除提示。

当前 QueryClient 的共享 mutation 承接站内导航后的状态。失败任务不会因默认回收期限消失；真实目录已显示的成功任务自动清理，临时成功提示可以关闭。材料和来源删除使相应导入结果失效，迟到响应及成功发布边界也不能恢复旧入口。

刷新、关闭浏览器页面后的进度恢复未实现；不把内存反馈称为持久后台导入任务。原文件只用于当前页面内存中的导入或重试，不进入浏览器持久存储。

## 2026-10-25 来源页导入布局修复

来源素材视图曾将导入书卡与正式书籍分别放在两个网格中，准备卡独占上方一排，已有书籍被推到下面；处理完成后移入正式网格，呈现为临时纵向排布。新增来源页几何回归先在旧实现复现失败：准备卡与已有书籍不属于同一个网格。

`BookGrid` 统一容纳导入卡与正式书卡，`ImportCards` 只输出卡片，移除独立区域及其样式。来源预览、全部书籍窗口与素材库复用这一结构；成功筛选外入口仍显示为网格中的临时书卡。没有修改任务状态、数据发布或重试规则。

实际打开包含两本已有书和一本待处理书的来源预览，修复前准备卡独占一排，修复后三张卡在宽屏并排。完成后的正常排序和状态文字消失可以改变位置或行高；验证要求共用网格并按可用列数换行，不锁定书籍排序或卡片内容高度。

本轮 `just lint`、`just test`（后端 743 项、前端 611 项）、`just build`、`just check-docs` 和 `git diff --check` 通过。导入浏览器回归在 1280 像素普通／减少动画与 390 像素三种配置通过：来源准备、完成和两笔并行导入均共用网格，测试容器宽屏为 5 列、窄屏为 2 列，列起点和卡宽保持一致。本轮没有重跑其余浏览器套件，完整 61 组结果属于前述初次交付验收。

## 2026-10-26 提交前 CR 修复

三路独立 CR 与主审核对全部工作区变动，确认来源概览未承接导入状态、复用已有书籍后目录刷新失败导致阅读入口丢失，以及 320px 展开搜索挤出添加按钮三项问题。新增浏览器回归均先在旧实现得到对应失败，再验证修复。

- 来源概览接入共享导入状态，待处理与失败任务参与空态判断，并与正式书卡共用紧凑素材列表。保留 55×77 封面，错误、原文件重试、移除、成功和预览范围外入口都能在概览使用。
- 实际呈现的书籍 ID 只负责隐藏重复卡片；目录成功刷新且停止获取后，才允许清理对应成功导入记录。刷新失败会重新显示可点击的成功卡，重试恢复后再由正式书卡接替；材料及来源删除的失效清理继续独立执行。
- 窄屏展开搜索时，搜索占满一行，工具按钮在下一行排列。320px、390px 的所有工具仍可见并可点击，Escape 收起与焦点恢复保持。

复审进一步确认“全部书籍”模态打开时，后方预览会提前清理成功任务，导致当前窗口的筛选外入口消失。对此补充真实“导入→打开全部→筛选→完成”回归，模态打开期间由当前可交互视图承接成功反馈。

三个新增套件分别覆盖概览状态、复用与刷新失败、搜索工具，在 1280／390／320px 下运行。复用用例在 POST 成功后挂起目录 GET，并等待 12 帧再返回 500，以覆盖成功回调与刷新之间的竞态。人工打开概览准备和目录刷新失败预览，看到紧凑占位卡、清晰状态文字，以及错误旁仍可点击的书籍入口。

最终 `just lint`、`just test`（后端 743 项、前端 611 项）、`just build`、`just check-assets`、`just check-docs` 与 `git diff --check` 通过。重新启动的完整 `just test-browser` 退出码为 0，70 组离线 Chrome 场景通过；最终验证期间代码快照保持一致。发现额外模态边界后曾主动中断上一轮浏览器运行，其部分结果不计入最终完整通过结论。
