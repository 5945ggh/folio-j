# 2C 后阅读与导航打磨验收

> 2026-09-30：本轮阅读、导航与讲解总标题增量通过离线验收。产品行为见 [PRD](../../PRD.md)，导航契约见 [阅读与导航](../../INFORMATION_ARCHITECTURE.md)。Occurrence 仍未实现，不因此视为首轮 MVP 全部完成。

## 范围与修复

- 来源目录独立为 `/sources`，普通片段入口默认阅读；讲解列表不自动打开缓存文档，原文可与讲解同时参照。
- 查询参数定位讲解、确切修订与讨论；校验当前片段归属，返回来处与查看所属来源分开。
- 对话内生成可提供独立 Analysis 总标题，使用 `tools_v4`；省略时沿用系统取名，Section 修改不改写总标题。
- 验收修复：无效／跨片段讨论返回列表后不再被快捷生成复用；失败查询的缓存不能触发生成。有效线程在本页收起或返回列表时继续保留挂载状态。
- 验收修复：从只有 `thread` 参数的直达入口返回列表时，显式保持讨论展开，避免删除参数后因默认值变化而收起栏位。

最终检查：`just lint`、`just test`、`just build`、`just check-docs`、`git diff --check` 均通过。后端 173 项、前端 18 项测试通过；空库执行 `just migrate` 成功。没有 ORM 或 OpenAPI schema 变更，没有新增依赖。

| 桌面长文阅读 | 1440×900 下原文参照固定，讲解与讨论独立滚动；讲解目录定位块，无横向溢出 |
