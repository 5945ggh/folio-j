## 性能测量

同一台机器经本地 ASGI 请求读取首章全部译文；每章 120 个原文位置，每处 3 个成功译文，每页 100 个位置，共两页。计时覆盖服务端请求至响应序列化，不含建库、浏览器和模型耗时。在基准提交与集成提交上分别取五次热读中位数。毫秒数用于比较耗时量级，不是交付阈值。

| 合成书 | 历史条数 | 基准 `92a14e0` | 集成版 `e47d3b4` |
| --- | ---: | ---: | ---: |
| 6 章、3.6 万码点 | 2,160 | 142 ms | 30 ms |
| 24 章、38.4 万码点 | 8,640 | 1,049 ms | 69 ms |
| 同上，另有 8 张插图，编译包 7.52 MB | 8,640 | 1,190 ms | 139 ms |

两本 24 章样书的两页累计候选读取从 34,560 行降至 1,440 行，进入完整校验的候选从 17,280 条次降至 720 条次。每页仍需解码材料并校验本章历史；SQL 仍需在材料成功历史中筛选。此处未增加索引、数据库迁移或跨请求缓存。

另测带材料出处的讨论受理：24 章纯正文约 25 ms，插图书约 99 ms；无其他写者竞争时，从取得显式写锁到提交分别约 4.7 和 6.4 ms。插图书两次解码合计约 81 ms。此次保留讨论受理的编译包复核，以免失去对同版本字节损坏、材料改名或删除的保护。

## 集成验证

`just lint`、`just test` 和 `just build` 通过。后端 1,306 项通过，两项 Windows 专用 Job Object 检查在 macOS 跳过；前端 821 项通过。本轮未在 Windows 实机、其他浏览器或真实模型上复验。

Chrome 的 146 个离线场景分段全部通过。首次连续执行在第 102 个场景停止，续验期间发现三处夹具使用了失效的呈现假设：

- 行间译文用固定坐标发送滚轮事件，实际命中浮卡内的引文。改为核验命中的 DOM：卡内滚轮保留预览，正文滚轮实际移动视口并关闭预览。原断言在 `92a14e0` 同样失败。
- 章节记录样书仅给段落设物理底边距，竖排时相邻记录按碰撞规则合并。改用逻辑段距，让需要单独命中的译文入口与邻项分开；章节记录 11 个场景通过。
- 阅读辅助的旧断言把 `color(srgb 1 1 1 / 0.72)` 当成近黑色，又要求短屏标题必须使用 CSS sticky。现在按实际颜色与底色叠加计算，译文在测试纸面上的最低对比度为 13.96:1（要求至少 4.5:1）；短屏直接验证正文滚动、标题可见及按钮命中。阅读辅助与两套主题场景均已复验。

这些夹具修正不改变产品行为。未新增依赖、数据库迁移或 TBD 决策。
