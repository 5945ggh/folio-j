## 自动语境契约与精确样例

在不可变原文上验证并确定目标及前后范围和原句边界，再整理两侧副本。使用 Unicode White_Space 集合；CRLF 转 LF。清空纯空白行的空白字符，内部连续空行折叠为一行；去除副本两端空白；正文行内普通空格、全角空格、标点、组合字符、变体选择符和零宽字符保留。标题按普通内容处理。

近端优先、残句计数、各侧独立句数／字符上限保持。字符预算按整理后整体 NFC 的 Unicode 码点计，内部保留的空格与 LF 各计一码点。每次加入远侧候选时按合并整理后的长度扣预算，不能先扣原始空白；字符不足时取贴近目标的部分并停止，最后再去除裁切边缘的空白。仅切开有内容的句／残部时 truncated=true；恰好完整候选、零预算或纯空白侧为 false。不清洗目标或定位数据。

下表用【】标目标；各侧默认 3 句／200 码点，另注预算覆盖默认。测试比较完整字符串、截断标记以及调用前后出处的深度相等。

| 输入／预算 | 精确结果 |
| --- | --- |
| `第1章\n\n　\n\n【学】` | 前 `第1章`，后空，均不截断 |
| `【学】甲。\n\n　\n\n乙。` | 后 `甲。\n\n乙。`，不截断 |
| `前の文。\n\n　\n\n【学】`，前 4 码点 | 前 `前の文。`，不截断 |
| `　\n\r\n【学】\n　` | 两侧空且不截断 |
| `甲。【学】乙。`，前字符为 0 或后句数为 0 | 对应侧为空且不截断 |
| `遠。あいうえお。近。【学】近。かきくけこ。遠。`，各侧 6 码点 | 前 `うえお。近。`、后 `近。かきくけ`，均截断 |
| `甲　乙。【学】丙 丁。` | 前 `甲　乙。`、后 `丙 丁。`，均不截断 |
| `甲。\r\n\r\n　\r\n【学】乙。\r\n\r\n丙。` | 前 `甲。`、后 `乙。\n\n丙。`，均不截断 |
| `𠮷が\n\n【学】😀　後。`，各侧 3 码点 | 前 `𠮷が`，不截断；后 `😀　後`，截断 |
| `甲\u200b\ufe0f。【学】乙\u0301。` | 前 `甲\u200b\ufe0f。`、后 `乙\u0301。`，均不截断 |
| resource A=`前。か`，B=`\u3099𠮷学後。`，目标 B 的 `[2,3)`，前 2 码点 | 前 `が𠮷`、后 `後。`，均不截断；B 的范围、exact、spine、摘要完全不变 |

现有 C2 句界样例用于锁定原坐标分句；副本整理替代旧的预装结果中“边缘空白逐字保留”的预期。旧 Segment、用户编辑／清空值和历史任务快照不批量更新。

## 只读出处契约与精确样例

后端在已有出处解析响应中提供 display 字符串，不持久化。已验证时显示当前材料名、章节名、章内百分比；删除／版本不可用／快照失配保留原状态，只展示可靠材料名，无法取得时省略。界面继续给出状态，不补造 0%。

逻辑章按 part 顺序连接其资源 NFC 正文片段，重复 spine 逐次计入；连接后整体 NFC。分母为该章总码点数，分子为第一段起点之前的章正文整体 NFC 码点数，向下取整 `floor(100 * prefix / total)`。空章不显示百分比；非空目标起点位于 `[0,total)`，显示 0–99%。若起点切开跨 part 的 NFC 组合边界，省略百分比。布局和阅读当前位置不参与。

固定样例：总长 10、起点 0→0%，起点 3→30%，总长 3 起点 1→33%；同资源长 10 在两个 spine 重复出现、第二次起点 3→65%；跨 part 目标只使用第一段起点。改名只更新显示名；source_ref 始终独立保留，精确出处下称“出处补充”，无精确出处称“出处说明”。返回原文继续验证结构化出处、版本及全部范围。

## 阅读入口契约与验收

正文无片段点击处理器，不依赖点击延迟；细线不消费正文事件。原生划选工具栏保留，普通正文操作不关闭已展开的固定片段列表或草稿。页边按钮只放在可验证的正文外真实留白，44px 点击区域，空间重叠时聚合；竖排优先底部真实留白，窄屏／不足时仅用始终可访问的本章列表。按钮不改变用户正文宽度。

页边入口与本章列表共用一个当前候选面板，列表保持横排；候选以创建时间和 Segment ID 区分同文记录。hover／focus 强调全部范围，点击明确打开。按章扫描全部分页后才开放完整列表与标记；加载、查询失败、删除、切章、旧 frame 销毁和重排清理临时强调与旧入口。贴句面板在滚动时关闭；固定本章面板可保留且明确注明本章范围。草稿存在时切换操作沿用草稿保护。

偏好 `marks` 按标记类型扩展；学习片段细线和页边入口独立。无新值时从旧 studySegments 迁移：false→两项 false，true／缺省→两项 true。新字段优先，storage 事件跨标签页同步；列表入口独立可用。

浏览器矩阵：横竖排、ruby、字号重排、窄屏、键盘；正文单击不弹片段、原生拖选／双击／键盘扩选／复制；重叠同文、密集及 >100 记录完整候选；两项偏好独立、刷新与跨标签同步；保存提示与精确返回、搜索高亮；改名／删除／失败降级。第三方扩展未实际运行时只报告事件边界。
