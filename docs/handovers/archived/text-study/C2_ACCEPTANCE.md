## 实现

- `reader-frames.ts` 集中 iframe 生命周期，学习界面只取得稳定的引用值和章数据。`reader-selection.ts` 严格处理 UTF-16／码点转换、跨节点 NFC、ruby、元素端点及出现身份；旧 frame、空选区、不连续或多 frame 选择明确失败。
- “保存为学习片段”固定本次选区。只按确切出处列出候选，显式选用时重新校验；新建片段沿用 C1 原子保存。响应不确定时冻结完整请求，原键核实；保存不启动讨论或模型。
- `study-context.ts` 按 `context-sentences-v1` 取章内前后文。句数／字符双预算、近端优先、残句计数、混合长短句截断、空白及 Unicode 码点均有逐字测试。part 不构成句界；章外正文不进入语境。NFC 跨资源可安全组装时按归一后的语境计数，跨目标边界无法安全分开时明确失败，保留目标供手填或仅保存。
- 草稿按字段保护编辑与清空；默认设置只在首次加载后捕获，预算变化不覆盖内容。明确重新取文先展示替换候选，保留原草稿；收起再展开保持输入，取消／离页保护修改并使旧结果失效。人工输入沿用各 100000 码点限制，不被自动预算裁剪。
- 独立 `segment_context_settings` 单例通过 GET／PUT `/api/settings/segment-context` 保存，预算为 0–100000 的严格整数，revision CAS 冲突保稿。缺省读取不写库，设置不进入模型参数或改写既有资料。
- Segment 提供历史出处状态与“返回原文”；`?segment=ID` 保留精确意图，经现有注音准备后定位首段并高亮全部范围。失败不提交未呈现目标，重试保留意图。来处通过受校验、限深度的 parent 链传递，保留来源筛选／详情入口，重复往返不增长。
