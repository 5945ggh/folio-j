# 复制设置数据库持久化验收

> 日期：2026-10-29；基准为 `d125fee`，验证对象为 `codex/context-copy-database` 分支。用户要求将复制默认值保存到数据库，并明确忽略旧浏览器值。行为见 [PRD 4.9](../../../PRD.md#49-阅读摘录书签与记录检索)，升级步骤见[升级与备份](../../../UPGRADING.md#当前迁移基线)。

## 实现

- 新增独立 `context_copy_settings` 单例与 GET／PUT `/api/settings/context-copy`。默认值保持前 3 句、后 0 句、两侧各 200 码点和附带出处；GET 无记录时返回 revision=0，不写入默认行。
- PUT 严格验证完整配置组，在短事务中比较 expected_revision，成功后递增版本，冲突返回 409。与片段语境、翻译配置和学习内容分别保存。
- 一次性增量脚本 `0002_context_copy_settings` 仅新增配置表，保留 `0001_schema_baseline` 和既有数据。应用空库顺序执行两份迁移，既有库仅执行新增脚本；重复升级不重置配置。
- 前端使用生成类型和 TanStack Query 预读已保存配置，移除旧 localStorage 读取、写入和跨标签页事件；不导入旧值。
- 设置改为显式保存，失败及冲突保留草稿。重新读取可保留修改或采用服务器值；恢复默认仅更新草稿。关闭设置面板放弃未保存草稿，界面注明此行为。
- 缓存保留较新 revision，保存前取消旧 GET；复制在用户手势中同步使用已保存配置。读取失败不阻止正文和普通复制，复制入口提供重试。查询遵循阅读会话活动态，迟到重试不清除后来产生的选区错误。
- 格式示例继续默认折叠；复制恢复与阅读外观恢复分别操作。
