# 阅读翻译：动画、缓存与删除验收

> 2026-10-30；基于原目录 `main 312b02a`，在 `codex/reader-translation-improvements` 实现并合入本地 main。工程与浏览器验证通过，现用库已升级，原目录开发服务已恢复；未推送远端。

## 范围与决定

用户报告同处译文每次展开均有卡顿、收回明显更顺滑，并要求统一阅读缓存限额、删除某处阅读翻译且保留已另存的学习内容。本轮产品行为见 [PRD 4.8](../../../PRD.md#48-阅读翻译与设备朗读)，缓存和执行契约见[架构](../../../ARCHITECTURE.md#312-阅读器-r11-呈现与只读派生查询)，操作见[使用指南](../../../USAGE.md#翻译与回看)。没有新增依赖或触及 TBD。

- 展开复用同次原文锚点，完整布局后只采样一次；正文末端测量复用同轮作者样式和裁剪几何。各文档动画准备后停在零进度，下一次 rendering update 同步启动，避免准备耗时吞掉开场。保留完整出处投影、章尾恢复、正文 DOM 与复制规则。
- QueryClient 共用 64 MiB／512 项的阅读缓存预算，覆盖查询数据、key、错误、原图 Blob 和 data URI；不复制 Query 数据。无数据的失败查询同样计入项数与字节估算。有 observer、在途查询和可见图像借用属于工作集，超额先驱逐冷项。预算是可重取缓存保留量估算，不覆盖 DOM、图片解码、临时计算或浏览器 RSS。后端沿用已有共享视图预算，去除全局大 HTML 图片偏移 LRU。
- 删除按确切出处移除全部已受理翻译历史，停止活动任务并撤销 token；旧请求和迟到结果不恢复标记。活跃片段的当前译文、讲解、采用快照和 Run 保留。原 POST 尚未核实时先核实；未冻结片段草稿解除失效关联并保留文字，冻结请求按原 UUID 核实。

## 调查与测量口径

现用库只读调查发现，旧详情路径读取一条 20 字译文时也加载约 15 MB 编译包。八次读取的暖中位数约 10 ms；交替比较去掉编译包读取约从 8 ms 降至 6 ms。它是确定的额外开销，不能独自解释每次展开与收回的主观差异。新路径通过 SQL 监听确认不再读取编译包。

旧有 404 段／3 iframe 合成场景开关均约 316 ms，未观察到大于 50 ms 的帧。增加至 557 段／2228 文本叶、首 iframe 550 段的密排样本后，每次开关约有 1.1 万次 Range 几何读取；一次复开首个采样已到 49 ms、译文已增长到 12 px。该观察提示开场阶段迟到，不等同于稳定复现用户环境。

优化后的同口径样本每次约 6700 次 Range 读取，减少约 40%；展开先显示零高度，再逐步增长。动画名义时长仍为 260 ms，稳定判定另含采样帧，不能把整个测试完成时长解释为用户可见动画时长。时延只作诊断输出，回归主要约束重复工作量、同步几何、原文身份和清理结果，避免把机器调度波动变成测试失败。
