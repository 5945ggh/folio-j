## 范围与规则

成功提示使用单行摘要和蓝色备注入口。附近已有书签时先提醒，可查看已有或仍然添加；关闭或超时放弃本次添加。继续添加及失败重试保留首次位置、请求 UUID 和继续添加标记，不改动已有书签。

列表摘要最多两行、备注最多一行，章节后显示可派生的章内进度。卡片打开完整详情，独立入口直接跳转原文。详情使用原生 popover，宽屏位于导航侧方，窄屏限制在视口内；备注草稿独立于浮窗保留。删除使用应用内确认框，取消为初始焦点，失败及版本冲突保留确认框供核对。

新摘要最多 120 个 Unicode 码点，优先选择当前位置所在句或短段落，长句再使用逗号边界，必要时裁切并标示省略。句末、连续句末组及闭合符沿用项目既有集合；小数与缩写中的 ASCII 句点不作为句界。同章可跨 part，不跨章，不包含注音。既有摘要保持原值，章内进度从不可变材料派生，无数据库迁移或历史记录重写。

附近规则集中在后端：同材料版本、章节、part、资源和位置种类；文字相距最多 24 码点且中间没有句末或换行，图片为同一图片且局部进度差最多 0.05。检查在写事务内完成，成功请求先按 UUID 回放。首版采用保守范围，跨 part 的相近位置不会提醒。

## 审查修复

主代理检查修复章末句号、尾部空白与闭合引号附近的摘要回退；确认按钮的悬停背景及文字成组设置，浅深纸面均验证对比度。创建状态增加迟到响应保护，旧的默认添加响应不能覆盖已继续添加的阶段。

独立只读审查发现详情只持有初始快照：另一窗口更新或删除书签后，列表刷新而详情可能继续显示旧值。补充选中项核验，普通查看同步新值，编辑草稿和删除确认版本保持独立，读取失败隐藏旧详情内容。

独立定点复核确认上述刷新缺口已解决，未发现新的明确竞态。新增浏览器测试曾静态导入 API module，早于全局 fetch mock 安装，导致首屏失败；现改为测试函数内动态导入，runner 同时在 Vite proxy 之前拒绝未被 mock 的 `/api` 请求，避免落入日常开发服务。最终矩阵使用该离线门禁通过。

## 限制

附近提醒使用固定的小范围容差，允许用户主动保存完全相同的位置；不会自动合并历史重复书签。章内进度不能代表全书比例。备注草稿仍限当前页面会话，刷新前需保存。验收使用合成材料与离线接口，不修改日常数据库；实体触屏设备仍未验证。无新增依赖，未触及 TBD。
