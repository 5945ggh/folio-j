# 阅读器配色收拢验收

2026-10-30，基于 `main 5db2742` 完成快捷入口与配色收拢，经 `codex/saved-segment-shortcut` 整理提交并快进合入本地 main；用户原有 README 调整单独提交。现行约定见[设计系统](../../../DESIGN_SYSTEM.md#阅读器的强调色与标记)。

## 变化

- 保存后的快捷入口保持原有紧凑尺寸，复用工具栏柔和蓝色；提示从 6 秒延长至 12 秒，保留悬停和焦点暂停。
- 普通浮层阴影、中性实心按钮悬停、浮动工具悬停统一引用阅读器 token，原色值及阴影几何保持。
- 书签卡片与编辑器共用局部派生底色；图片查看器的固定深色值集中到遮罩容器，原值保持。
- 译文卡片焦点优先读取阅读器焦点色；朗读滑块在 Reader 内读取纸面配色，在其他页面保留应用配色。
- 正文蓝色选区、红色学习／译文划线、搜索覆盖动画、弱阴影及渐隐遮罩保留原有用途和效果。未修改正文处理、布局、API 或数据库，未触及 TBD。

- `just lint` 通过；`just test` 通过（后端 925、前端 729）。
- 提交整理时 `just build`、`just check-docs` 与 Git 差异检查通过；生产代码沿用上述已验证版本。
- 隔离 Chrome 浏览器回归：`theme` 4 场、`reading-aids` 5 场、`reader-settings` 6 场、`reader-images` 5 场、`position-bookmarks` 4 场，共 24 场通过。主题套件的被测文字最低对比度为 4.67:1，不代表所有界面状态都已测量。
- 实际打开离线预览检查翻译卡片、朗读设置及保存提示；中性表面、紧凑布局、深浅模式均保留。测试接口离线，朗读使用无声模拟事件。
