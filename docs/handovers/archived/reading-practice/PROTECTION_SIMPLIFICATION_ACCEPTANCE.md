## 自用 API 调整

- `PATCH /api/analyses/{analysis_id}` 仅传 `title`，不再接收 `expected_title`。
- `PUT /api/settings/context-copy` 提交完整五项有效配置，不再接收 `expected_revision`；响应仍含递增 revision。
- `POST /api/translation-results/{result_id}/adopt` 与 `DELETE /api/translation-results/{result_id}` 退出。现行新建关联使用带精确出处和 `translation_result_id` 的 Segment 创建；移除阅读翻译使用材料及确切出处的整组 DELETE。
- Adoption 表、历史收据与结果去向读取不变。不建立旧写接口兼容层；未检查仓库外私人脚本。
