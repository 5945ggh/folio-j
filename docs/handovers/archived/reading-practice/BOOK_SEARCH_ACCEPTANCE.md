# 本书搜索实现与验收

> 2026-11-11；实施起点为 `main f1ec22a9`，分支为 `codex/book-search`。本记录对应该基线上的本地实现，尚未推送或发布。最终全量检查、11 个浏览器场景及隔离真实 API 人工复核均已通过。现行范围见 [PRD 4.9](../../../PRD.md#49-阅读摘录书签与记录检索)，交互见[书内搜索与图库](../../../INFORMATION_ARCHITECTURE.md#书内搜索与图库)，当前交付见[实施基线](../../MVP_IMPLEMENTATION_BASELINE.md)。

## 实现范围

阅读器提供独立“本书搜索”入口，与目录／书签复用左侧面板位置，目录退出搜索页签。检索当前书籍的原文、精确关联片段的原文／当前译文／备注、各确切出处最新成功阅读译文，以及书签摘要／备注；保持各资料独立身份。历史译文、讲解全文、跨书检索和模型读取权限不扩展。

默认全部内容按四类分组，各组独立折叠并预览两条；单类每批 40 条。原文计处数，资料计条数，按书中位置排序。统一折叠筛选区提供内容单选和章节组合多选；章节 popover 即时生效，支持全部章节三态，空选不发送无过滤请求。关键词为空时只浏览资料，不扫描原文；只有展示摘要中的实际匹配文字高亮。

桌面定位保留搜索列表，窄屏定位后收起搜索；同一 Reader 会话内保留关键词、筛选、分组与列表位置。原文走既有精确定位链路，片段和正常阅读译文打开现有资料预览。搜索启动的记录预览保持显式位置，避免跨章定位后的几何刷新清理刚打开的内容。失配译文仍可只读查看保存内容；失配书签保留详情并禁用前往原文。

原文搜索增加章节过滤，三类资料使用独立只读接口，OpenAPI 与前端生成类型同步更新。删除门禁、版本核验和查询迟到隔离沿用持久身份；书签详情读取期间发生新导航时，旧读取不能回跳或打开旧详情。无新增依赖、数据库迁移或 TBD。

## 浏览器行为回归

[搜索浏览器用例](../../../../frontend/browser-tests/reader-search.tsx)挂载真实 MaterialReader 与 iframe，所有 API 为本地合成响应，浏览器脚本阻止外部网络。三场景均覆盖：

- 独立入口、空关键词只读取三类资料，输入法组合期间不发中间查询，旧关键词迟到响应不覆盖新查询。
- 内容筛选、章节组合勾选与全选／半选／空选；空选明确空态且无无过滤请求，Escape 只关闭章节 popover。
- 分组独立折叠不改变条件或重新查询；全部视图两条预览，单类先显示 40 条，再请求 offset 40 并追加至 43 条。
- 关闭重开保留关键词与分页；长列表实际滚至 scrollTop 1200，重开待数据就绪后恢复滚动。
- 原文结果核验实际 iframe CSS Highlight 的确切文字；桌面保留列表，320px 跳转收起后可重开，片段打开现有预览且不挂工作台。
- 某类返回 503 时其他类别继续显示；书签详情 GET 挂起期间前往下一章，旧 GET 完成后不回跳、不写旧章位置、不打开旧详情。
- 正常阅读译文从第二章首次点击跳回第一章并打开详情，等待呈现与位置保存，再触发 resize 和延后观察，内容仍保留；失配译文与书签可读取保存内容并保持当前阅读位置，书签前往原文禁用。

## 隔离真实 API 与人工检查

使用独立合成资料库中的三章节材料，在浏览器中操作真实后端接口。搜索「雨」显示原文 45 处、片段 2 条、译文 3 条、书签 3 条；组合选择「窓辺」和「翌朝」后译文为 2 条。此处的真实 API 指本地应用后端，不包含外部模型调用。

这轮操作发现正常阅读译文跨章首次点击时，原文已经定位但详情未保持，同章第二次点击才打开。修复使搜索打开的既有记录预览保留显式位置，避免随后的几何更新清理它；上节三场景回归已验证首次跨章打开并稳定保留。最后一轮人工复核已确认跨章节首次点击可定位并保持译文详情。

直接进入独立搜索、未打开原书签列表时，搜索「下次」得到 3 条书签；在第三条详情编辑备注、去掉该关键词，保存后搜索自动更新为 2 条。书签创建、编辑和删除显式使搜索缓存失效，不依赖原列表是否已挂载。最终外观截图保存在本地 `.cache/book-search-acceptance/final-search.png`，不作为公共检出的依赖。

## 验证边界

验证使用合成资料和隔离库，未对日常学习库执行演示写入，未调用外部网络或模型。自动化窄屏模拟不替代实体触屏设备验收；本轮未进行真实大型书库专项性能测量。搜索状态只承诺当前 Reader 会话内恢复，不增加跨刷新查询持久化。

本批未推送或发布；后续设备验收与大型书库测量分别补记实际环境和结果。
