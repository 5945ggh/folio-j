## 初轮浏览器观察

环境为 macOS 的应用内 Chromium 浏览器；使用独立 SQLite 数据库、普通可重排合成 EPUB 与本地生成的静态 PNG，无模型调用，也不修改日常阅读数据。桌面及 390 × 844 窄屏均实际打开检查。

- 素材库、来源概览、素材视图及全部书籍窗口共用菜单。移动／删除有“暂未开放”与常驻原因，方向键跳过禁用项；打开菜单不会开始阅读。
- 详情显示真实原书名、当前书名、来源、格式、导入时间、阅读状态、最近打开和章节数。仅查看详情及编辑后仍显示“未开始／尚未打开”；实际进入 Reader 后才显示“进行中”及打开时间。
- 同次修改书名与上传 PNG 后，详情和目录显示新书名／封面，原书名保持；从来源书卡恢复原书封面后清除自定义覆盖，样书无可用原书封面时显示占位。
- 取消未保存修改先确认，继续编辑保留草稿，放弃后保留原信息；从全部书籍模态窗口打开编辑，关闭后仍留在原窗口且焦点回到书卡菜单入口。
- 双窗口编辑中，后提交的陈旧版本得到 409，草稿保留且保存禁用。显式重读先确认放弃草稿，随后加载当前书名；复核并修复重读后底层目录缓存未同步的问题，取消编辑后书卡已显示最新信息。
- 素材库条件及来源 `view=materials&expanded=book` 窗口经过“详情 → 阅读 → 详情 → 原目录”后恢复；无来处直达详情安全返回素材库。
- 窄屏详情单列展示，编辑表单及操作可达，没有页面横向溢出。专注阅读隐藏工具栏后可用 Tab 唤出，再返回详情。

## 用户反馈修正与旧外壳清理

初轮工程验收后，用户指出菜单过大、阅读状态占用主菜单，以及详情退回旧设置页风格。上述初轮观察保留当时结果，现行交互以本次修正及 [PRD](../../../PRD.md#421-本轮材料目录与阅读管理) 为准。

审计确认详情只传入无样式声明的 `book-details-shell`，落到旧暖色默认外壳；当前设置组件没有被旧路由替换。旧默认仍被片段、加载与错误页使用，因此按用户授权将现行中性外壳提升为公共默认，再删除暖色全局变量、重复覆盖和零运行时引用的设置样式。`styles.css`、`library-a1.css`、`reader-refresh.css` 合计净删 659 行；保留仍在使用的验证历史、共享提示、危险操作样式及阅读器独立主题。

- 菜单宽 220px、普通行约 30px；无封面失败项时实测高度 171px。移除底部延期说明，移动／删除仍有“暂未开放”并禁用。阅读状态主入口显示当前状态，点击进入同一弹层的子菜单。
- 已在素材库及来源全部书籍窗口验证：子菜单初始聚焦当前状态，Escape 先回父入口、再次关闭菜单且保留底层窗口；选择“已完成”后关闭，重开菜单回显已保存状态。左右键、上下键及禁用边界新增纯逻辑回归见[菜单测试](../../../../frontend/src/catalog/book-menu.test.ts)。
- 详情改为紧凑返回栏、小封面、左对齐书名和信息；桌面、390 × 844 窄屏均无横向溢出，窄屏封面与标题并排、信息在下方。素材库和来源使用同一默认导航。
- 回归片段页、加载页、错误页和当前设置页，默认外壳均为白底／灰蓝导航；展开与收窄实测 208／60px，窄屏导航抽屉正常。Reader 黑、白、跟随系统选项仍独立生效，测试后恢复原偏好。

本轮 `just lint`、`just test`（后端 296、前端 206 项）、`just build`、`just check-docs` 与 `git diff --check` 通过；构建继续保留既有大包提示。旧样式引用审计与最终实现分别经过独立只读审查，未发现阻塞问题。未新增依赖或触及 TBD，用户复核待进行。

## 提交前复核

本次对当前工作区进行独立前后端审查与集成复测，发现并修复以下问题：

- 元信息提交后，原 Session 保留旧 Material，而封面查询可能读到后续编辑，导致响应混合两个修订。响应现于写事务提交前组装；新增确定性交错提交测试，先复现旧实现失败，再验证响应保留本次书名、修订和封面状态。
- 编辑弹窗的取消操作有草稿确认，浏览器后退原先会绕过确认。现接入路由阻止与页面卸载保护，覆盖未保存输入、图片读取及保存／重读期间的离开；继续编辑取消导航，明确放弃后才继续。编辑会话由稳定页面组件持有，目录刷新移除书卡不会卸载草稿；保存完成使用最新的受阻导航状态，避免等待目录刷新时遗漏后退请求。
- 改名使书卡离开当前搜索结果时，弹窗关闭后焦点原先落到页面根部。现于目录新快照渲染后检查焦点，在原书卡不存在且焦点无效时恢复到仍有效的目录容器；来源素材预览使用同一恢复规则。

浏览器先复现草稿后退丢失，再验证后退出现确认、继续编辑保留输入、放弃后返回原目录。窄屏详情封面与标题并排、字段在下方，无横向溢出。另用独立 SQLite 库和合成 EPUB 验证保存及搜索结果移除路径，回归来源概览、片段工作台与设置页的公共外壳；日常阅读库未执行信息保存。

最终构建复测中，搜索仅命中一本书，改名保存后结果变为零，焦点位于有效目录容器。双窗口配合测试服务器延迟目录读取，验证另一窗口改名、原目录请求完成并移除书卡后，编辑草稿仍在；陈旧保存得到冲突提示并保留输入。另在 PATCH 成功、目录刷新尚未完成时后退，界面等待保存结束，释放目录请求后自动到达原后退目标，控制台无错误。

最终 `just lint`、`just test`（后端 297 项、前端 206 项）、`just build`、`just gen-api`、`just check-docs` 与 `git diff --check` 通过。构建保留既有单包大于 500 kB 提示。未新增依赖或触及 TBD。

## 限制

移动、删除只保留禁用入口；编辑不支持替换 EPUB。材料与片段的结构化关联、材料讨论及学习成果迁移仍等待后续切片。

未新增依赖，未触及现有 TBD。封面沿用已有标准库有界结构校验，未扩展图片格式或引入图像解码依赖。实际浏览器验收未覆盖 Safari／Firefox、实体触屏或所有真实 EPUB；用户日常使用验收待进行。
