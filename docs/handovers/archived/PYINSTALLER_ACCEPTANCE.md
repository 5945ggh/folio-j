# PyInstaller 目录包试做

2026-11-08，以 `e9aee1ab1961d96b809835e509f26ae75a86be88` 加 `codex/pyinstaller-browser-trial` 工作区改动试做。本记录只描述 macOS ARM64 本机实验；公开 beta 的正式分发仍为源码 ZIP。

## 目标与实现

保留现有功能和系统浏览器使用方式，用户无需安装 Python、Node.js、uv 或 pnpm。构建环境仅安装锁定的生产依赖与 `packaging` 组；PyInstaller 6.22.3 是新增的可选构建依赖，用于生成自包含目录，不进入生产依赖。Python 为 3.11.14，SudachiPy 为 0.6.11，Core 词典为 20260723；本轮不调整词典覆盖或格式。

生产入口在进程内运行 Uvicorn，提供启动、迁移、数据路径、备份与恢复命令。bundle 资源与用户配置／数据目录分开；源码运行仍使用仓库布局。运行方式与复现命令见[开发指南](../../DEVELOPMENT.md#实验目录包)。未修改 ORM／API schema、prompt 或 TBD。

## 首包结果

`0.1.0-frozen-trial.1` 目录常规文件逻辑大小为 262,078,559 字节（约 249.94 MiB），`.tar.gz` 为 97,919,638 字节（约 93.38 MiB）。统计不跟随符号链接重复累计。词典占 217,466,039 字节（约 207.39 MiB），前端产物约 1.38 MiB。压缩包和解压目录是两份文件；用户同时保留时需要相加。

首包移位后通过真实 HTTP 的页面／静态资源、EPUB 导入、分词／注音／统计、讲解模板、用户词典和手写讲解检查。测试发现 SIGINT 后 Uvicorn 已完成资源关闭，随后重抛 `KeyboardInterrupt` 导致进程返回 1；保留烟测的退出码断言并修复生产入口，再构建最终候选验证完整闭环。

## 最终验证

最终候选为 `0.1.0-frozen-trial.3`：目录逻辑大小 262,116,489 字节（249.97 MiB），分配大小 262,516,736 字节（250.36 MiB），压缩包 97,941,221 字节（93.40 MiB）。Core 词典约占目录逻辑大小的 83%；`libpython3.11.dylib` 为 16.09 MiB，前端产物为 1.38 MiB。目录大小包含运行所需内容，不含构建环境、用户数据、另存的压缩包或安装缓存。

将 `.tar.gz` 解压到中文空格临时目录，再复制并移位目录包。在空 PATH、独立 HOME／数据库和无源码工作目录下运行，完整烟测退出码为 0，覆盖：

- 数据路径查询不创建数据库，空库迁移、真实服务启动、SPA 路由及 JS／CSS。
- 原创合成 EPUB 导入、Core 分词、注音、词汇统计、讲解模板、Yomitan 合成词典导入和查词、手写讲解保存。
- 本机合成 Provider 的模型发现、Chat Completions 和 Responses SDK 调用，核对两条成功 Run 的输出、usage 与原始响应；只接受预定的 loopback 请求。
- 正常停服和重启，备份与恢复到新目录，拒绝覆盖已有目标；删除原始临时库后，从恢复库再次找回书籍、讲解、词典和 Run。三次服务停服均正常退出。

浏览器验证使用目录包的独立临时库及端口 18010：从空素材库选择合成 EPUB、新建来源并导入，点击书卡打开正文，观察到标题、日文正文、原书注音与图片正常呈现；异步前端分块和分词准备请求正常。验证后已正常停止测试服务，未触及日常数据库。

验证：`just lint` 通过；`just test` 后端 1403 passed、2 skipped，前端 810 passed；`just check-docs` 与 `git diff --check` 通过。完整测试首次受沙盒本机 socketpair 权限限制，有 5 项 EPERM；允许本机套接字后全量通过，测试的外部网络防护仍启用。没有以跳过失败代替通过。

工作区同时新增项目授权与设置页源码入口；最终候选重建前端并附带 `LICENSE`、`COPYING.md`，保留并发修改。代码与资源未再改变。

## 范围与限制

本轮不测真实模型服务、翻译质量或系统朗读声音；这些原有验证限制继续保留。没有完成其他电脑、Intel Mac、Windows／Linux 冻结包验证；未做正式发行签名、公证或带隔离属性的下载演练。PyInstaller 自动生成的本机 ad-hoc 签名不等同于正式发行签名。

PyInstaller 捆绑解释器与依赖，不承诺性能提升。与 Nuitka 的大小和性能比较尚未执行；本次结果不能推算成其他编译工具的实测收益。
