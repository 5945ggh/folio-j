# 片段目录出处与删除验收

日期：2026-10-30。基于 `main e8dc0bb` 完成片段目录出处与删除调整，提交整合状态见[实施基线](../MVP_IMPLEMENTATION_BASELINE.md)。现行规则见[来源空间](../../INFORMATION_ARCHITECTURE.md#素材库与来源空间)、[架构](../../ARCHITECTURE.md#311-目录与材料使用状态)及[使用指南](../../USAGE.md#阅读与保存片段)。

## 交付范围

- 概览与片段目录共用出处和添加时间组件。有效材料出处优先显示当前书名、核对后的章名及章内位置，手填出处作为补充；手动片段显示已填出处或“未保存出处”。材料删除、版本不可用及快照失配分别表达，不展示失效章名。
- 目录接口增加非持久化 `provenance_summary`，按页批量读取材料，同一 EPUB 每页只解码一次，复用既有校验与显示规则；耗时校验后复核可见性及材料身份。
- 片段目录三点菜单和片段详情共用删除确认，展示讲解及修订、讨论、消息和任务影响，提交前核对全部返回字段。范围变化需再次确认，提交中防关闭和重复操作，失败可重试。
- 成功清理目标及相关缓存，更新来源计数、概览、完整列表、讲解目录及阅读标记；列表回到有效页并恢复可用焦点，详情返回所属来源。
- 讲解菜单“删除此讲解”的文字使用危险操作颜色。

## 边界

本轮没有数据库迁移、新依赖或 TBD 决策，不操作现用数据库。沿用既有软删除与可见性门禁，不提供恢复入口；Occurrence 仍未实现，未扩大删除模型。并发删除可能让正在读取的目录出现短页，总数会按当前可见内容重新计算。
