# 设计系统

本规范维护现有视觉基线、颜色作用域与样式使用规则。产品行为由 [PRD F1](PRD.md#f1-设置)维护，页面职责和交互参数由[阅读与导航](INFORMATION_ARCHITECTURE.md)维护，运行机制见[前端架构](ARCHITECTURE.md#6-前端结构)。实际色值以 CSS 为准，交付状态与验收入口见[实施基线](handovers/MVP_IMPLEMENTATION_BASELINE.md)。

## 视觉基线

延续现有浅色视觉：公共页面以白色内容面、低对比灰色导航和克制的操作色组织信息；片段阅读保留黑白灰层次，让日文原文成为阅读主体。已有字体、留白、尺寸、布局、信息密度与控件位置保持各自职责，不因支持深色而统一成另一套页面样式。

深色沿用相同的信息层级和交互结构，分别适配背景、正文、辅助文字、边框、焦点、选中和状态反馈。删除、错误、警告、成功等状态保留明确语义，不能只靠背景亮度表达。封面、正文图片、品牌图案与 SVG 插画保留原始配色，不使用整页反色滤镜。

## 颜色作用域

| 作用域 | 颜色来源 | 使用边界 |
|---|---|---|
| 公共应用 | `frontend/src/theme/tokens.css` | 素材库、来源、详情、设置、片段、讨论、公共加载与错误页 |
| 页面与组件 | 公共语义变量及区域别名 | 保留局部阅读层次、悬停、按钮和内容组合；不建立另一套应用主题 |
| EPUB Reader | `frontend/src/materials/reader-r1.css` 的阅读变量 | 独立白／黑纸面、阅读工具、预览与局部对话框 |
| EPUB iframe | `reader-palette.ts` 显式桥接的阅读变量 | 独立文档内的正文、选区和标记；不复制一份配色常量 |

应用根节点的 `data-theme` 确定公共颜色模式。Reader 在自己的作用域设置 `color-scheme`，独立解析白／黑纸面；应用浅色配黑纸面、应用深色配白纸面都属于正常组合。两处的系统模式各自读取系统颜色偏好，不互相改写存储值。应用颜色选择不影响材料版本、内容身份与阅读位置。

## 语义变量使用规则

- 按用途选择变量：内容面、正文、辅助文字、边框、强调、危险状态、遮罩与阴影分别维护。变量名表达用途，避免按十六进制值命名或为每页复制主题表。
- 文字强调使用 `--color-accent`，实心操作按钮使用 `--color-accent-solid`，按钮前景使用 `--color-text-on-accent`。兼容别名 `--accent` 与 `--accent-solid` 同样分开，局部黑色操作风格可各自定义浅色分支。
- 公共变量用 `light-dark()` 配合当前作用域的 `color-scheme` 解析。原生输入和对话框继承所在作用域；Reader 的独立纸面可以显式选择 light／dark。
- 保留已有浅色差异时，可使用 `light-dark(原浅色值, var(--color-相应用途))`。重复值应收拢到组件或区域的语义变量，避免在文件末尾追加成片暗色选择器覆盖。
- 明确区分纯配色与几何变化。背景、文字、阴影等配色更新原地应用；字体、字号、宽度、注音范围和横竖排继续使用阅读布局恢复链路。纯配色不重建 iframe、不重新绑定 ruby 事件、不触发位置写入。
- Markdown、表格、图表、工具提示和浮层使用其所在作用域的颜色。新增状态同时核对正常、悬停、焦点、选中、禁用和错误表现。

## 下拉选择控件

普通单选下拉框使用 `frontend/src/NativeSelect.tsx`，保留原生选项菜单、键盘、表单、标签和焦点行为。收起时共用 14px 的装饰箭头，距行末边缘 14px，文字末端预留 40px；箭头不截获点击，也不进入辅助技术的操作范围。长选项在控件内省略，不挤占箭头区域。

箭头颜色使用所在作用域的辅助文字色：公共应用用 `--color-text-muted`，Reader 用 `--reader-muted`，朗读设置用 `--speech-muted`。禁用控件及箭头保持弱化反馈；强制颜色模式使用浏览器原生箭头。多选或多行列表保留原生列表，分享按钮内透明覆盖的范围选择保留独立呈现。

各页面继续负责宽度、高度、边框和背景，布局类放在包装层，原生属性与事件传给内部 `select`。局部内边距不得覆盖共用的箭头预留；组合输入样式通过 `--native-select-padding-end` 保留该空间，不复制背景箭头或独立维护另一套图标。

## 阅读器的强调色与标记

阅读器按用途复用颜色，默认配色以蓝色组织操作和选中，以红色标记已有学习记录。颜色只承担局部强调，保留紧凑控件、中性纸面和正文层次。

| 用途 | 阅读器 token | 使用约定 |
| --- | --- | --- |
| 柔和操作强调 | `--reader-accent-soft`、`--reader-on-accent-soft`、`--reader-accent-soft-hover` | 背景、配套文字及悬停背景成组使用；选区工具栏的保存和保存后的打开片段共用 |
| 控件选中 | `--reader-selected-bg`、`--reader-selected-fg` | 默认引用柔和强调色；选中语义仍由 pressed／current 等状态表达，强调按钮本身不表示已选中 |
| 正文临时选区 | `--reader-selection-bg` | 同属蓝色系，使用透明覆盖以保留文字；不直接拿按钮底色覆盖原文 |
| 学习与译文记录 | `--reader-study`、`--reader-translation` | 默认红色，分别配合实线、虚线；保持两种用途的独立 token |
| 搜索命中 | `--reader-search-match` | 默认金色，与原生选区及持久记录区分 |
| 原文定位反馈 | `--reader-location-highlight` | 浅金黄色荧光底色，随定位反馈淡出；正文保持清晰深色 |
| 错误 | `--reader-error`、`--reader-error-border` | 独立的状态颜色；即使与学习标记同属红色系，也不共用 token |
| 中性工具反馈 | `--reader-tool-hover-bg`、`--reader-action-solid-hover` | 分别用于普通浮动工具及中性实心按钮的悬停，保留各自原有强度 |
| 普通浮层阴影 | `--reader-shadow` | 复用阴影颜色，各组件保留原有位移、模糊和范围 |

阅读器通用色值集中在 `reader-r1.css`，组件引用语义变量。已有全局应用使用 `theme/tokens.css` 的同类语义变量；阅读器保留自己的纸面作用域，不直接跟随应用深浅模式。正文 iframe 经现有 palette 桥接读取同一组阅读颜色。

具有独立表面职责的组件可在共同祖先维护局部 token：书签卡片和编辑器共用派生底色，图片查看器在遮罩容器集中维护固定深色 palette，继续衬托原图。共享的译文、朗读控件在 Reader 中优先引用阅读器颜色，其他页面保留应用颜色。较弱的工具栏阴影、图片遮罩、搜索淡出覆盖及渐隐 mask 各有用途，不为了减少色值数量强行合并。

同一用途的浅色、深色值成对维护：浅色通常用浅底和较深文字，深色用暗底和较亮文字；覆盖文字的颜色另设透明度。调整某个色系时一起核对背景、文字、悬停、焦点及正文对比，不要求所有用途使用相同色值。

后续配色风格沿用这组语义角色，在声明它们的作用域成组替换 token，并提供各自的浅／深值；阅读器在 `.reader-r1` 上覆盖，避免只覆盖子组件而让继承的别名仍取旧值。配色风格和明暗模式分别描述色彩选择与亮度环境；组件不按风格名称分支，也不新增零散硬编码色值。实际的风格选项、设置入口与保存方式留待功能设计。

## 阅读器紧凑浮窗

词卡、片段、翻译及记录列表共享 `reader-popover.css` 的表面：13px 圆角、细边框、两层柔和阴影与 9px 背景模糊。选区工具栏共用底色透明度与背景模糊，保留自身的圆角、阴影和按钮样式。浮窗内有焦点时略微加深中性边框；标题栏及只读词头不加矩形描边，键盘聚焦时加强顶部拖动条。按钮、链接及表单控件保留蓝色键盘焦点，强制颜色模式保留系统焦点框。背景将 Reader 纸面色按共享偏好与透明混合，文字和图标不设置整体透明度；白纸与黑纸继续使用 Reader 的颜色变量。展开的完整阅读侧栏使用实底并取消模糊，嵌入内容不重复铺底。

词条排版由词卡维护；片段原文采用约 18px 日文阅读字体，当前译文与原文以细引线和轻底色连续呈现，讲解篇名先于真实正文。翻译浮窗的日文引用较小，译文约 21px、正常字重。类型小印记、选中与焦点采用局部蓝色，主要内容保持中性。具体入口、计数与设置范围见[阅读与导航](INFORMATION_ARCHITECTURE.md#原处预览与记录浮窗)。

## 维护与后续范围

修改颜色时检查浅色基线、深色、系统模式变化、公共页面与 Reader 的独立组合，以及文字／图标与表面的对比。涉及阅读布局时继续验证原文位置、选区、注音与图片表现。检查结论记录在对应验收资料，长期规范只维护规则。

当前提供内置浅色、深色与系统模式。用户自定义 CSS 的入口、作用范围和存储契约，以及其他 Reader 重构，留待后续单独设计。
