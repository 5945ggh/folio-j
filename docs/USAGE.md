# 使用指南

启动方式见[项目首页的快速开始](../README.md#快速开始)。本文说明日常阅读、模型设置、讨论与应用配置；已有数据的升级和凭据备份见[升级与备份指南](UPGRADING.md)。

## 阅读与保存片段

打开应用进入素材库，选择已有或新建来源，再选择 EPUB 提交导入。弹窗立即关闭，书籍网格显示文件名占位卡和准备动画；完整处理成功后，点击真实书卡开始阅读，应用不会自动跳转。若新书未出现在当前筛选或分页中，可从网格中的临时书卡打开。失败卡会显示原因，可以重试同一文件或移除提示，已创建来源仍保留。

同一标签页内可以离开再返回查看导入状态；刷新或关闭页面后不保证找回进度。来源用于组织材料与学习片段，可以关联多本书。也可从来源目录添加日文片段，无需先导入 EPUB。

阅读 EPUB 时，可以划选原文并保存为片段，核对预装的前后文语境。点击正文标记或从右上角“本章记录”选中片段，可以回看已有译文、讲解和备注。页边的片段图标或“译”直接打开对应记录，数字打开列表。同一段原文还关联其他记录时，可从单条详情点标题左侧的箭头回到“此处记录”。在“此处记录”中点“展开”可留在书里阅读完整讲解。点标签行右侧的“打开片段 →”进入片段详情页。从“本章记录”浏览片段或翻译时，可以点引文旁的“定位原文”跳到书中相应位置。

同一标签页打开片段后再返回，应用会短期保留阅读会话，并定位该片段原文；刷新或较长时间离开后会重新加载。

打开片段默认展示原文和讲解列表，选定讲解后可对照阅读。顶部的“所属来源：来源名 →”打开来源首页；工具栏的返回按钮回到进入片段前的页面。你可以直接编写或粘贴 Markdown 保存讲解，也可以编辑已有讲解并保留历史修订。这些操作无需配置模型。

来源概览和“片段”列表在原文下展示具体材料出处及添加时间；手填出处作为补充，无材料出处时显示已填说明或“未保存出处”。材料已删除或定位失效时显示相应状态，已保存的片段内容仍可回看。

删除片段可从来源的“片段”列表行末三点菜单进入，也可打开片段后选择“片段更多操作 → 删除片段…”。确认框显示会连同删除的讲解、讨论、消息及中断的任务；来源、原材料和其他片段保留。影响数量变化时需要重新确认，删除后无法从页面恢复。

打开讲解右上角“更多操作 → 重命名”可修改名称，最多 200 个字符。名称同时用于列表与阅读页；重命名保留正文、历史版本和引用。若其他窗口已改名，草稿会保留，可先读取最新名称，核对后再保存。

### 目录、搜索与阅读设置

从底部“目录”打开书内导航，点击章节恢复上次停留位置，也可选择“回到章首”。切到“搜索”输入原文，点击结果跳转；搜索按字面匹配正文，不搜索注音，不跨资源或章节拼接匹配。查看搜索结果或从图库跳转后，可使用阅读器提供的返回位置入口回到此前阅读处。

打开底部“阅读设置”，面板按“排版”“注音”“阅读界面”“带上下文复制”分组。字号、横排／竖排、注音显示与范围和纸面直接可调，其余选项在各组内展开。同次阅读中关闭或切换工具后重新打开，会保留展开状态和面板滚动位置；换书从收起状态开始。

“排版”中的“更多排版”提供行距、字体和正文宽度。首次阅读及重置排版的默认字号为 22、行距为 2.4，已有书籍保留保存的设置。宽度仅在横排生效，竖排时保留原值。字号、行距和方向随本书阅读位置保存；字体、宽度仅保存在当前浏览器的本书版本中。调整后恢复原文位置。

“注音”直接选择“显示”“按需”“隐藏”，在同组的“注音范围”直接选择“原书”或“全量”。原书使用书中已有注音；全量以本地词典补充未标注的汉字，原书注音优先。按需时可悬停、轻点、选中或按 R 显现。全量数据尚未就绪时保留当前画面，准备失败可重试。注音偏好仅保存在当前浏览器的本书版本中。自动注音不调用模型，读法仍需结合语境判断。

“阅读界面”选择白／黑／跟随系统纸面，展开后调整工具栏不透明度，以及“展示阅读记录下划线”“展示阅读记录页边入口”。专注阅读由底部工具栏的独立开关控制。这些偏好用于当前浏览器的所有书籍，纸面独立于应用外观；隐藏记录标记不删除资料。

前三组即时生效，各组标题旁的“重置”可单独恢复默认。恢复排版只改字号、方向、行距、字体与宽度；恢复注音只改范围和显示；恢复阅读界面只改纸面、工具栏不透明度与记录显示，保留工具栏上的专注阅读选择。浏览器保存失败时，本次调整仍可用，按提示处理未持久保存的状态。

### 位置书签

点击底部工具栏的“添加当前位置书签”保存当前阅读位置。成功后以一行原文摘要提示，可点击蓝色“添加备注”写下回访原因，也可继续阅读。附近已有书签时会先提醒，可“查看已有”或选择“仍然添加”；后者保存第一次点击时的位置，之后滚动不改变本次书签。关闭提示即放弃本次添加，不影响已有书签。摘要自动按句子等自然边界截取，不需要设置预算；无文字的图片位置显示图片说明或“图片位置”。

从“目录 → 书签”查看本书书签，卡片按书中顺序展示章节、章内大致进度、最多两行摘要和一行备注。点击卡片任意非操作区域（包括留白）查看完整摘要、备注与添加时间，当前卡片会保持蓝色选中强调。左下垃圾桶可直接发起删除，右下跳转入口可直接前往原文。详情中的原文与备注分组展示，备注标题旁提供添加／编辑入口；长内容可滚动，底部删除和前往原文始终可达。跳转后仍可用临时返回入口回到跳转前；字号、横竖排等阅读设置保持当前值。保存失败或冲突会保留草稿，按提示读取最新记录并核对后再保存。关闭详情、面板或切换页签后可在当前浏览器会话继续编辑，刷新页面前请完成保存。

删除书签会先显示应用内确认框，确认后移除书签及其备注。删除整本书时，书签、摘要和备注保留在数据库中但随书籍隐藏，重新导入不会自动关联；当前没有独立归档查看入口。升级已有库前请按[升级与备份](UPGRADING.md)操作。

### 管理书籍

素材库或来源内的书卡菜单提供“书籍详情”“编辑书籍信息”和“阅读状态”。详情中可查看正文统计与高频词覆盖曲线；编辑入口可修改书名、更换封面或恢复自动封面。阅读状态可手动调整，移动到其他来源尚未开放。

“删除书籍”会清除应用托管的原书与派生阅读数据，无法撤销；已保存的片段、讲解、讨论、所属来源及同来源的其他书籍保留，导入时选择的本地 EPUB 文件不受影响。确认框会列出未关联片段而将隐藏的译文、保留的关联译文及需停止的翻译任务数量。重新导入会创建新的材料身份与阅读位置。

### 即时查词

在 EPUB 底部工具栏点书形的「即时查词」，选择「导入词典」，打开自己的明镜日汉双解词典 Yomitan ZIP。首次导入完成会开启点击查词。工具栏可以随时切换方式或关闭。词典保存在本机，同一服务里的书籍共用。替换成功后使用新词典，失败可重试。

轻点正文里的日文，词卡首先显示覆盖原文最长的候选。同一段原文的不同读音和词条按顺序列在同一页，可以在卡内滚动查看。卡头的箭头切换到其他匹配范围，对应原文也随之高亮。点卡里的日文释义或例句继续查，点返回箭头回到上一张卡，点 × 回到书中。桌面上可以同时对照多层词卡，空间不足时它们会部分重叠。手机上可以直接点露出的父卡片段。在「即时查词」里拖动「词卡背景不透明度」，可以一边看着词卡一边调整透底程度。点划线处也会查词，卡底的「此处记录」可以打开原先保存的内容。鼠标选「Shift 悬浮」后，按住 Shift 指向正文查词，松开后可以在卡里继续点，普通点击划线则直接回看记录。

### 查看统计与材料词汇

从书卡菜单打开“书籍详情”，查看字符、汉字、词次和高频词覆盖曲线。统计在页面可见时定期更新，重新进入或切回窗口时检查最新分析；正常显示时无需手动刷新，读取失败可重试。词次覆盖率表示原书词次的分布，不代表理解率或掌握率。

点击“查看词汇”进入本书词汇页。可按一级词性筛选、按词频升降序排列，并输入词典形、实际词形或读音搜索；平假名、片假名与半角／全角可对应匹配，不支持罗马音。相同词典形的变化合并计数，词性筛选后重新计数；搜索命中其中一种词形时仍显示该组的全部次数。例如搜索「食べた」命中的「食べる」，出现位置也包含同组的其他变化。

选择词汇后查看原文与前后文，点击“查看原文”跳转并临时高亮，再从阅读器顶部返回词汇页。宽屏同时显示词表与出现位置，窄屏从出现位置返回词汇列表；筛选、排序、页码与所选词会保留。部分变体过多时只显示样本，实际频次与搜索仍包含全部变体。出现项标为无法定位时仍可阅读其原文与上下文。

词汇范围与统计相同，包含目录和后记等可提取正文；同一资源重复呈现只计一次。词汇页不接入词典释义，也不保存为学习条目。没有分词代次时会显示尚未准备，可进入阅读准备已有书籍的注音与分词；仅打开详情或词汇页不会触发准备或更新阅读位置。

### 查看正文图片与插图库

点击正文图片，查看器先显示已加载的图片，阅读背景虚化并压暗；图片序号及切图入口在后台定位完成后可用。点击关闭、背景空白处或按 Escape，一次返回原来的阅读位置。从工具栏的“插图库”打开图片时，关闭查看器回到原图库页与滚动位置。

图片默认适合窗口，可以放大、缩小或恢复适合窗口，放大后拖动查看；触屏可以双指缩放。上一张／下一张按书中顺序切换。“复制图片”用于粘贴到其他应用，“下载原图”保留原始图片格式；浏览器不允许复制或写入失败时会显示提示，仍可下载原图。动态图片的剪贴板副本为静态画面，下载保留原文件。

“在图库中查看”会打开当前图片所在的图库页并突出该项；同图在书中出现多次时分别列出。查看、缩放、切图、复制和下载不改变正文位置；点击“前往书中位置”才会跳转原文，并提供阅读器的返回位置入口。

### 复制原文与出处

划选阅读器正文后，用快捷键或右键菜单复制，只复制原文纯文本，保留段落换行，去除原书与自动生成的振假名注音；阅读时的注音显示不变。

阅读选区工具栏的“带上下文复制”可直接组合目标原文、前后文与出处，用于粘贴到外部 AI 对话。默认附书名和章名，前文最多 3 句／200 字符，后文为 0；不用先保存片段。打开“阅读设置 → 带上下文复制”，默认收起的摘要显示已保存配置。展开后调整句数和出处开关，“上下文字符上限”和“格式示例”分别展开；示例随有效草稿更新。点击“保存复制设置”后，实际复制才使用新值。配置保存在数据库，连接同一后端的浏览器和全部书籍共用，不影响翻译或保存片段的语境；旧浏览器配置忽略。

修改后可以收起复制组、关闭设置、切换工具或切章，同次阅读仍保留草稿。未保存、保存中、无效输入、失败和冲突会继续提示；收起后的配置摘要仍以已保存值为准。“放弃修改”恢复已知最新的服务器配置；复制组标题旁的“重置”只改草稿，仍需保存。

离开当前阅读或换书时，有草稿会提示“保存后离开”“放弃并离开”或“继续编辑”；打开片段页也属于离开阅读。保存进行中离开会先等待该次保存结论，失败则保留当前页面和草稿；关闭面板不会撤销已提交请求。刷新或关闭标签页使用浏览器原生提醒，离页后不保证恢复草稿。

保存失败或其他页面已更新时保留草稿。冲突后可“重新读取并保留修改”，核对后再次保存整组配置；也可“重新读取并使用服务器设置”。重新读取失败仍保留草稿。配置读取失败可重试，不影响正文阅读与普通复制。任一侧句数或字符上限为 0 时省略该侧；剪贴板失败时从提示中的完整文本手动选择复制。

在片段页复制原文与出处：

1. 点击原文卡右下角的“复制分享”图标，打开复制浮层。
2. 默认“复制原文与出处”保留已保存前后文，用引用块标出当前片段，末尾附书名、章名及手填出处，无材料名时使用来源名。底部箭头可切换仅原文或仅出处，并更新只读预览。
3. 核对预览后点击主按钮复制。仅原文保持目标文本原样，在出处读取期间也可复制。

出处读取失败时可重试或复制现有内容；剪贴板复制失败时可从预览手动选择复制。译文、讲解、听写和个人备注不带入；“查看完整原文与资料”仍是独立入口。

## 翻译与设备朗读

### 翻译与回看

在设置的“翻译”中选择已登记的模型，保存默认语言和语境偏好；可以明确使用当前讨论模型，之后更改讨论默认值不会改动翻译选择。初始日译简体中文，自动取前文最多 3 句／200 字符，后文为 0；翻译偏好不改写学习片段已存语境。

阅读时选择原文并点击“翻译”：已有结果优先回看，没有结果才发起本次调用。译文卡先展示原文引用和译文，被折叠的原文可展开；“语境与设置”可检查实际输入或修改本次语境，生成信息和历史按需展开。译文下方的“朗读原文”播放日语原句，播放结束后可点“重播原文”。“重新翻译”使用当前语境与设置生成新结果，原译文保留到新结果读取完成。每版译文的实际目标语言可在“生成信息”中查看。有相邻历史时，点“上一版”回看，再点“返回新版”回到刚才的译文。

横排卡片避让选区，竖排优先放在选区侧边；宽屏可拖动标题栏调整位置，聚焦标题栏后也可用方向键移动，Shift 加大步长。窄屏放在底部并为朗读控制留出空间。翻译期间可查看进度或停止任务。关闭图标收起卡片，任务继续。再次选择同一原文可找回任务，成功后也可从正文标记或“本章记录 → 翻译”打开结果。失败或进程重启不会自动重复调用模型；提交响应不确定时，重译位置改为“核实原提交”，只核实原请求。

需要保留为学习资料时，在正文重新划选相应原文，点击“保存为学习片段”。草稿会一次预填同一确切位置的成功译文，语境按学习片段偏好独立摘录；译文和语境均可编辑或清空，迟到结果不会覆盖修改。选用已有片段会保留其译文和语境，并放弃本次未保存的草稿。保存响应不确定时，按提示核实原提交，不重复生成译文。

成功译文可从“本章记录 → 翻译”按原文顺序找回，也会在原文上显示较淡的红色虚线；学习片段仍用红色实线，竖排显示在文字旁侧。相同出处多次翻译只占一项，点击查看最新译文，展开“此处历史翻译”可读旧结果，条目保留时间、语言和译文，原句在顶部详情展示。与学习片段重叠时只画实线，点击后在同一面板切换两类记录。阅读设置可分别隐藏记录下划线和页边入口，本章记录仍可访问。回看不会重新调用模型。

需要清除某处翻译时，点击译文下方操作行末端或“本章记录 → 翻译”列表中的删除图标，核对后确认。该处全部已有阅读译文历史和翻译划线一起移除，进行中的重译停止；已另存的学习片段、当前译文、讲解和关联快照保留，片段实线仍在。删除失败可在确认框重试。提交尚未核实时，先点击“核实原提交”，再删除。以后重新选择该处并明确翻译，可以留下新的记录。

如果正在编辑的片段草稿引用了已删除的阅读译文，应用会保留草稿文字并解除旧译文关联；可继续独立保存。读取失败时，可选择“保留草稿并解除译文关联”。保存响应尚未核实的请求继续使用原请求核实。

### 朗读与声音设置

1. 对选区、译文对应原文或片段原文点击“朗读”，不要求先翻译或保存。片段页的播放条悬浮在阅读区底部，保留原文摘要、语速和关闭入口。
2. 设备支持时，点击播放图标可暂停、继续，结束或停止后可重播。
3. 点击语速／声音区域打开小浮层，选择日语声音，按 0.1 步进调整 0.5–1.5 倍速，或使用预设及恢复默认。点击外部、按 Escape 或再次点击入口关闭设置。

声音与语速偏好只保存在当前浏览器，更改后短暂提示，下次播放或重播生效；暂停后继续使用暂停前的声音与语速。“更多选项”中可重新检测，完整声音设置页提供试听；没有可用声音时按提示检查或配置系统声音。

关闭译文卡仍可继续朗读；关闭播放条或离开阅读／片段页会停止并清理当前目标。浏览器方式不保存音频，也不保证原书特殊 ruby 的读法；语音服务的选型与后续边界见[技术选型](TECH_STACK.md#3-模型接入byok)。

## 外观与阅读纸面

在「设置 → 外观」选择浅色、深色或跟随系统，默认跟随系统。选择立即生效，无需点击保存，刷新后继续使用当前浏览器保存的选择；同一浏览器的其他标签页同步变化。跟随系统会实时响应系统颜色模式。浏览器无法保存时会提示，当前页面仍使用所选外观。

应用外观用于素材库、来源、详情、设置和学习片段等页面。阅读器纸面在阅读设置中独立选择白、黑或跟随系统，与应用外观分别保存；两处的“跟随系统”都读取系统颜色模式。图片保持原始颜色。应用外观页无需配置模型，也不依赖服务端设置读取成功。

## 模型设置

设置入口为 `/settings`，提供模型服务（Provider）、模型、学习背景及讲解预设维护。需要 AI 辅助时，在「模型与服务 → 服务管理」添加服务地址和凭据，再发现或手动登记模型；回到「默认模型」选择并保存“讨论模型”，再到片段中展开讨论。「创建 AI 讲解」新建普通对话，使用当前明确选择的模型，缺省采用讨论／追问默认模型；设置页保留的旧“讲解模型”不影响此入口。没有可选模型时，默认模型页提供服务管理入口。

「验证普通文本」和「验证流式文本」各发起一次短模型调用，可能产生 Provider 费用；结果保存在最近验证中，刷新页面不重复调用。列表获取成功不代表文本、结构化输出或工具能力均已验证。模型请求会发送到配置的服务，应用在本机运行不表示模型也在本机运行。

密钥输入去除首尾空白；编辑留空保持原密钥，清除需显式操作。密钥保存在数据库旁的 `<数据库文件名>.secrets/` 私有目录，目录权限 `0700`、文件权限 `0600`，不进入普通 API 响应、Run 或 Git。这是本机文件权限保护，尚未加密。备份与恢复须同时保管数据库及对应凭据目录，见[升级与备份指南](UPGRADING.md#数据与凭据)。

验证在本地后台执行，页面关闭不取消；服务关闭或重启使未完成验证标为中断，不自动重放。每次操作一次调用、60 秒超时、最多两次并发；重试需明确发起。配置变更后旧的能力验证不冒充新配置结果。

Provider 停用阻止新验证和新问答，不改变已接受任务；存在未完成调用或问答任务时删除会被拒绝。设置页用于接入维护，学习问答在片段中进行。

## 片段讨论与讲解

需要讨论时展开讨论区域，新建对话、选择模型并提问。输入框中按 Enter 发送，Shift+Enter 换行；中日文输入法选词时的 Enter 只确认输入。接受问题时会固定本轮输入和模型配置，并锁定目标原文；失败或停止也不解除原文锁定。成功保存讲解或建立精确材料出处也会锁定原文，附带信息仍可编辑，历史输入保持原样。

普通提问和站内生成讲解共用回复状态：助手消息显示当前可确认的活动和从受理起算的已用时间，包含排队和等待审核。流式模型开始输出讲解正文时可以看到“正在撰写讲解”；一次返回完整内容的模型在返回前显示“等待模型回复”。

讨论在本机后台执行，刷新或离开页面不会重发或取消；返回可查看历史、失败原因、残文及待审核方案。运行或待审核期间可以输入下一轮草稿，但不能发送或切换权限；可停止本轮，停止完成后再发，已保存成果保留。

想用外部 AI 时，选择“＋ 新建讲解 → 复制讲解提示词”，将内容粘贴到你选择的 AI 对话。提示词包含片段原文、已保存的语境和参考资料，以及设置中的学习背景和讲解偏好。拿到 Markdown 回答后，回到同一菜单选择“编写或粘贴讲解”即可保存。复制无需配置模型，也不会固定原文。

普通提问默认在对话中回答。「创建 AI 讲解」每次新建一个普通对话，发送明确请求创建并保存独立讲解的预定问题；Agent提供完整正文并通过工具保存，返回的成果可从主页面打开，聊天中可以只报告保存结果。每次成功创建均形成一份新讲解，已有讲解保留；普通讨论中也可明确提出“整理成独立讲解并保存”。已有讲解可按块修改并产生新修订，审核模式先展示具体方案。Full access 省去已开放工具的逐次审批，仍执行归属与版本检查。当前工具可读取同片段讲解，尚无学习条目（Occurrence）读取、创建或整理工具。

讨论与模型验证共用并发上限 2；讨论采用有预算的多次模型调用与工具执行，上限见[架构中的讨论与成果保存](ARCHITECTURE.md#45-讨论与成果保存analysis已实现occurrence待设计)。模型验证的一次调用、60 秒限制仅适用于接入验证。

服务重启会将执行中的未完成任务标为中断，不自动重放模型请求；待审核方案保留，返回后仍由用户决定。

## 应用配置

可将 [config/app.example.toml](../config/app.example.toml) 复制为 `config/app.toml`，调整服务端口和数据库路径；不复制时使用同样的默认值。默认后端地址为 `127.0.0.1:8000`，相对数据库路径以仓库根目录为基准，默认数据位于 `data/app.db`。

可用 `FOLIO_J_DATABASE_PATH` 覆盖数据库路径，供临时验收或独立数据集使用；迁移和应用读取同一覆盖值。更换路径前应确认目标数据库及对应凭据目录，数据与备份说明见[升级与备份](UPGRADING.md)。真实配置、数据库、缓存和密钥不提交。

`[translation]` 可调整单次原文／语境字符上限、时限、待处理数量和模型未设置输出上限时的候选值。初值是待实测的工程限制，详见配置示例；超限不会静默裁掉原文。它们与设置页面中每次默认摘录多少前后文分别维护。

同一数据库只运行一个后台实例；当前进程锁依赖 macOS／Linux 的 `fcntl`，原生 Windows 暂不支持，Linux 尚未完成验收。开发模式的前端端口及代理说明见[开发指南](DEVELOPMENT.md#环境准备)。
