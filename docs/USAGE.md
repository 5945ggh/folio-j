# 使用指南

安装与启动见[快速开始](../README.md#快速开始)，数据备份、跨设备迁移与版本升级见[升级与备份](UPGRADING.md)。

## 整理来源与导入书籍

「来源」是整理书籍和学习片段的基本单位，可以是一套轻小说系列，也可以是你自定的学习专题。目前支持导入普通可重排 EPUB 书籍。

1. **创建来源与导入书籍**：在「素材库」或「来源目录」中点击「导入书籍」，选择已有来源或新建来源后导入 EPUB。应用会在后台解析书籍，处理完成后点击封面即可开始阅读。
2. **手动添加片段**：手头只有一段日文时，也可以不导入书籍，直接在来源下手动添加片段，开始对话或编写讲解。
3. **管理与删除书籍**：在书卡菜单中可以打开「书籍详情」、编辑书名与封面，或调整阅读状态。自定义封面支持静态 PNG / JPEG（不超过 4 MB、最多 1600 万像素），只影响应用内显示，不会改动本地 EPUB 文件。「删除书籍」会移除应用内的电子书副本、书签和备注（重新导入后不会恢复），默认保留本书关联的学习片段、讲解和对话；如需一并删除，可在确认框勾选「同时删除本书关联的片段、讲解和对话」。本地 EPUB 文件始终不受影响。
4. **删除来源**：在来源右上角菜单中选择删除，会不可撤销地清除该来源下应用托管的全部书籍及关联片段、讲解和对话（你电脑上的本地 EPUB 文件不受影响）。

## 阅读器操作

阅读器左上角可返回「素材库」或进入阅读前的页面；右上角齿轮可打开全局设置（完成后点「继续阅读」即可回到原书）。底部工具栏用于就地调整阅读体验与查找内容。横排用上下方向键、竖排用左右方向键沿正文滚动，步长随字号和行距调整；`PageUp` / `PageDown` 和空格按视口翻动。

### 目录、搜索与书签

- **目录与书签**：点底部「目录与书签」切换章节，或切到「书签」页签查看已保存的位置。跳转查看后，可通过底部临时返回入口回到原来的阅读位置。
- **本书搜索**：点底部「本书搜索」，可查找正文、学习片段、最新译文和书签。支持按内容类型和章节筛选（不输入关键词时可直接按章节浏览已有的片段、译文和书签），点击结果即可定位到书中原处并打开对应记录。
- **位置书签**：点底部工具栏的书签按钮即可记录当前阅读位置，并可顺手添加备注。在「目录与书签 → 书签」中可按章节顺序查看、编辑备注或跳转回原文。
- **查看插图**：点击正文插图或底部「插图库」可放大查看、复制图片或下载原图；从插图库查看时，点「前往书中位置」可跳转到正文对应段落。

### 阅读设置与外观

打开底部「阅读设置」（`Aa`），可按习惯调整阅读体验：

- **排版**：调整字号、行距、字体、横排 / 竖排，以及横排模式下的正文宽度。
- **注音**：显示方式可设为「显示」「按需」或「隐藏」。在「注音范围」中，「仅原书」只显示书中自带的注音；「全部汉字」会根据 `Sudachi` 分词结果为未注音的汉字自动补齐振假名。设为「按需」时，悬停、轻点、选中文字或按 `R` 键可临时显示注音。
- **阅读界面与外观**：可单独设置阅读纸面（浅色 / 深色 / 跟随系统）、工具栏不透明度、浮窗不透明度，以及是否在正文中显示记录下划线与页边入口。底部工具栏另提供独立的「专注阅读」开关。应用整体的浅色 / 深色外观可在「设置 → 外观」中调整。

## 即时查词与词汇统计

### 即时查词

1. **导入离线词典（可选）**：未导入词典时，即时查词会「仅显示读音与词形」（含假名读音、罗马音、原形、词性与活用拆分）。需要词条释义时，可在「设置 → 词典」中导入 Yomitan 第 3 版词条词典（`.zip`，不超过 256 MB）。导入多本词典后，可在列表中点选当前生效的一本。查词词卡与 Anki 制卡参考栏共用词典释义的排版；如果旧版已导入的词典包自带独立 `styles.css`，重新选择原 ZIP 导入一次即可启用支持的样式。
2. **开启与触发查词**：在阅读器底部或片段详情页工具栏打开「即时查词」，选择「点击查词」或「Shift 悬停」模式（开启后查词按钮会高亮提示）。关闭自动触发后，在阅读器和片段页中划选文字，仍可点击选区工具栏的「查词」按钮手动查询。
3. **阅读词卡与连续查词**：
   - 词卡顶部显示原文的假名读音、罗马音、原形、词性和活用接续拆分（例如 `空い〔连用形·イ音便〕＋て＋い〔いる·未然形〕＋ない`）；命中词典时下方展示释义。
   - 拖动卡头可移动词卡位置；点击卡头左右箭头或按键盘 `←` / `→` 可切换不同的匹配长度。
   - 词卡内的日文释义或例句中还有生词时，可直接继续点按或按住 `Shift` 悬停往下连续查词。Shift 悬停预览保留原焦点；需要用键盘操作词卡时，先点击卡头。
   - 按 `Escape` 或点击词卡右上角的 `×` 可逐层关闭词卡；点击阅读背景空白处可一次关闭整组词卡。
4. **查词辅助选项**：在即时查词面板中可按需开关：
   - **自动扩展查词**（默认开启）：点击词语中间时自动向前寻找完整词语；手动划选文字时始终严格按所选范围查询。
   - **辅助排序**（默认开启）：结合原文的词形、读音与词性优化同长度候选词的排列顺序。
   - 已打开词卡时，更改上述选项会在原位置刷新根词卡并收起子卡，无需重新点击原文；设置面板保持打开，便于比较。

> **提示**：片段详情页的原文、前后文和讲解正文同样支持即时查词。开启「点击查词」模式时，点击正文带下划线的句子会优先弹出词卡，可通过词卡底部的「查看记录 ↗」或页边图标查看已保存的译文与讲解。

### 词汇统计与检索

从书卡菜单打开「书籍详情」，可查看全书字数、汉字数与高频词覆盖曲线，点击「查看词汇」即可进入全书词汇表（若提示尚未准备，打开书籍阅读一次即可自动完成分词）。

- 支持按词性筛选、按词频排序，或输入词典形、书中实际词形、假名读音进行搜索。
- 同一词典形的不同活用会合并计数。例如在「昨日は本を読んだ。今日は新聞を読む。」这两句里，搜索「読ん」会找到词典形「読む」，词频计为 2。
- 点击任意词汇即可查看它在全书各处出现的原句与前后文，点「查看原文」可进入阅读器并定位到该句。

## 在阅读器中制作 Anki 卡片

**首次连接**：打开装有 AnkiConnect 插件的 Anki 桌面端，切换到要收卡的 **Anki 用户**。在 Folio-J 的「设置 → Anki」点「测试连接」，核对显示的 Anki 用户。默认 AnkiConnect 地址为 `http://127.0.0.1:8765`；如果修改了地址或填写了插件要求的 API 密钥，再点「保存连接」。

1. 在 EPUB 正文划选目标词，点「制卡」（提示为「制卡（发送到 Anki）」）。也可从查词词卡的根卡发起，自动带入词典形和读音。阅读器里的译文和已保存的学习片段也有「制卡」入口。
2. 展开浮窗顶部的配置摘要，选择导出配置（内置「词义回忆」「例句理解」两套系统预设，也可在「设置 → Anki」中新建导出配置，自定义笔记类型和卡片模板字段映射），并选好目标卡组。「词义回忆」必填**词汇释义**（例如「生徒」填“学生”）；**例句释义**用于填写整句话的译文，可留空。
3. 需要查释义或引用已有译文时，展开参考栏，选好底部的「填入目标」，点条目旁的弯箭头填入，或划选其中一段摘录。从词卡打开时，搜索框已带入当前词头，也可改查其他词。
4. 点击原句即可编辑。如果词条是「聞く」、原句中写的是「聞いて」，可在原句中选中「聞いて」并点「设为重点」。点「预览」核对正反面效果，重点只在卡背着色。
5. 点「发送到 Anki」。首次使用时，如果当前 Anki 用户缺少所选的内置笔记类型，核对类型和卡组后点「创建并发送」。遇到重复提示时，确认确实要保留两条笔记再允许本次重复。

Anki 断开时可以继续填写，保持草稿打开，恢复连接后再发送；关闭草稿或刷新页面会清除本次输入。发送后若显示「结果未确认」，先到 Anki 的「浏览」中查找这条笔记，再决定是否重发。

## 翻译、片段保存与朗读

### 结合前后文翻译

1. **配置翻译**：在「设置 → 翻译」中设置翻译模型、目标语言（默认为简体中文），以及自动附带的前后文句数与字符上限。
2. **划选翻译**：阅读时划选原文并点「翻译」，应用会将摘录原文、前后文以及来源与书名发往模型生成译文，并在正文中标出浅红色虚线。
3. **重译与管理**：点击标有虚线的句子即可回看译文。点浮窗的「展开」可查看「历史译文」，或在「前后文与设置」中调整本次附带的前后文后点击「重新翻译」（新译文会追加保存，不覆盖旧版本，可自由切换查看）。也可从右上角「本章记录 → 译文」按顺序浏览或删除某处译文（已另存为学习片段的译文快照不受删除影响）。

### 保存与回看片段

1. **保存片段**：阅读时划选原文，点「保存」（提示为「保存为学习片段」）。应用会自动带入前后文；如果该句已经翻译过，也会自动填入译文草稿，核对或修改后即可保存。
2. **书中回看**：保存过片段的原文会标出红色实线。点击正文划线、页边图标或右上角「本章记录」，即可在阅读器内查看该片段的译文和讲解（有多篇讲解时可切换标题）。点「展开」可在阅读侧栏完整阅读，点底部「打开片段 →」可进入独立的片段详情页。
3. **删除片段**：可在来源的片段列表菜单或片段详情页工具栏的「片段更多操作」中删除片段（会一并移除该片段下的讲解与对话记录）。

### 朗读

在阅读器或片段详情页中划选文字、查看译文或打开学习片段时，均可点击「朗读」调用设备自带的日语语音。在底部播放条中可以暂停、重播，或打开「朗读设置」调整语速（0.5–1.5 倍）与日语语音；完整语音列表与试听可在「设置 → 朗读设置」中查看。

## 学习片段、对话与讲解

从来源列表或阅读器进入片段详情页后，可以对学习片段补充备注、发起对话或保存讲解。原文一旦建立书籍出处、保存过讲解或发起过对话，即进入「已锁定」状态，不可再修改原文。

### 复制原文与外部 AI 提示词

- **普通复制**：在阅读器中直接用快捷键或右键复制正文，会自动剔除原书与自动生成的振假名注音，只保留干净的正文纯文本。
- **带前后文复制**：划选正文后点工具栏的「带前后文复制」，可将摘录原文、前后文与书籍出处一键打包复制，便于直接粘贴给外部 AI 提问。默认附带的范围和格式可在「阅读设置 → 带前后文复制」中修改。
- **在片段页复制**：打开片段详情页，点原文卡片右下角的「复制分享」图标，可选择复制「原文与出处」「仅原文」或「仅出处」。

### AI 对话与编写讲解

打开任意学习片段，你可以直接用 Markdown 编写讲解，也可以借助 AI 整理思路：

- **使用外部 AI（无需配置模型）**：点击「＋ 新建讲解 → 复制讲解提示词」，应用会把摘录原文、前后文以及你在「设置 → 学习偏好」中填写的学习背景和默认预设打包复制。粘贴到外部 AI 工具中，拿到回答后再选「编写或粘贴讲解」保存即可。
- **在应用内对话与生成讲解**：
  - 展开片段右侧的对话区即可「新建对话」向 AI 提问。对话在本地后台运行，等待回复时离开页面也不会中断。
  - 普通问答保存在对话记录里。想把有价值的解释留存下来，可以在对话中让 AI 整理并保存为讲解，或直接点击「＋ 新建讲解 → 生成 AI 讲解」。
  - 讲解支持多次修改并保留历史版本，也可在讲解右上角「更多操作」菜单中「重命名」或「删除讲解」。

## 模型与服务

阅读、查词、手写或粘贴讲解均无需配置模型。应用内翻译、对话和生成讲解会将原文及本次所需的前后文发送给你配置的模型服务，费用由该服务商决定。如需在应用内使用 AI 功能，请按以下步骤接入：

1. **学习偏好与权限**：在「设置 → 学习偏好」中填写学习背景和讲解方式，并设置保存片段时默认带入的前后文范围。在「设置 → 对话与权限」中可选择 AI 修改讲解时采用「修改前确认」（先展示修改方案供你确认）或「允许直接修改」（直接保存新版本）。
2. **添加服务与模型**：在「设置 → 模型与服务 → 模型服务」中点击「添加服务」，填写 OpenAI 兼容服务的 API 地址与 API 密钥；进入服务详情点击「添加模型」，可点「获取模型列表」勾选，或手动填写模型 ID。随后在「设置 → 模型与服务 → 默认模型」中选定对话与讲解模型，在「设置 → 翻译」中选定翻译模型。
3. **连接验证**：在服务详情的「模型」页签中，点击模型行的「验证」菜单可运行「验证普通文本」或「验证流式文本」（各发起 1 次简短调用）。点击验证状态，或在「验证记录」中展开对应记录，即可查看返回结果或报错原因。
4. **密钥保管**：API 密钥不会写入数据库或 Git，而是保存在数据库文件同级目录的 `<数据库文件名>.secrets/` 文件夹下。制作数据备份时会一并打包（可能含未加密的 API 密钥），请将数据目录与备份妥善存放在个人私有目录，切勿直接分享给他人。详见[升级与备份](UPGRADING.md)。

## 应用配置

首次启动可使用默认目录、指定其他目录创建新库，或打开已有库。Windows 默认使用 `%LOCALAPPDATA%\Folio-J\Data`，macOS 和 Linux 默认使用 `~/Folio-J-Data`，数据库文件名为 `app.db`。可以直接粘贴资源管理器复制的带双引号路径。选定并成功启动后，应用会记住该路径，后续启动和更新程序都会自动沿用。日常可在「设置 → 数据目录」查看或复制当前数据目录与数据库文件路径。

等待期间页面显示当前阶段和用时。请求超时后，页面先查询服务进度。首次建库迁移失败时，排除报错原因后点击「重试当前选择」；如果已经重启，在原目录点「在此创建新数据」。已有库暂时无法访问时，重新连接原位置再重试。已存在且无法识别的数据库文件会原样保留，此时可选择一个新目录。需要报告故障时，记录失败阶段、错误类型和 Windows 错误码，并隐去个人路径。

如需主动重新选择数据目录（例如切换另一份数据，或打开刚恢复的备份目录），请先停止服务，再加 `--choose-data` 参数启动（这只切换读取路径，不会搬迁已有文件）：

```sh
# 源码发行包
uv run --project backend --no-dev python -m app.launcher start --choose-data

# 免安装目录包（Windows PowerShell 使用 .\Folio-J.exe start --choose-data）
./Folio-J start --choose-data
```

### 自定义数据目录与端口

后端默认地址为 `http://127.0.0.1:8010`（开发模式前端端口为 `5187`）。除了在启动页选择数据目录外，如需修改端口或通过配置文件预先指定数据库文件路径，可创建或编辑 `~/Folio-J-Data/app.toml`（更多底层参数见 [config/app.example.toml](../config/app.example.toml)）：

```toml
[database]
path = "/Volumes/Study/Folio-J/app.db"

[server]
port = 8010
dev_port = 5187
```

- `path` 需填写包含文件名的完整绝对路径（支持 `~/`）。
- Windows 推荐写成正斜杠（如 `path = "C:/Users/你的用户名/Folio-J/app.db"`），或使用 TOML 单引号保留反斜杠（如 `path = 'D:\学习资料\app.db'`），避免在双引号中直接使用未转义的反斜杠。
- 修改配置后，可运行 `just data-path` 核对当前生效的数据库文件路径。使用源码发行包且未安装 `just` 时，运行 `uv run --project backend --no-dev python -m app.launcher data-path`。
- **注意**：启动页已记住的数据目录优先于配置文件中的 `path`，且修改配置文件不会自动搬迁已有数据库文件。

### 配置优先级与高级选项

当存在多处配置时，数据库文件路径按以下优先级生效：

1. 环境变量 `FOLIO_J_DATABASE_PATH`（适合临时切换测试数据库，如 `FOLIO_J_DATABASE_PATH=/path/to/test.db just start`）
2. 启动页已记住的数据目录
3. 程序目录下的 `config/app.toml`
4. 用户主目录下的 `~/Folio-J-Data/app.toml`
5. 当前程序目录下已有的旧版 `data/app.db`
6. Windows 旧用户目录中已有的 `~/Folio-J-Data/app.db`
7. 本平台的默认数据库路径（首次创建需在页面确认）

说明：
- 设置了环境变量 `FOLIO_J_DATABASE_PATH` 时，它具有最高优先级，不会改写已记住的数据目录；若要在页面切换其他数据目录，需先移除该环境变量。
- Windows 将位置记录保存到 `%LOCALAPPDATA%\Folio-J\data-location.json`；缺少 `LOCALAPPDATA` 时使用用户主目录下的 `AppData\Local`。新记录缺失时仍读取旧的 `~/.config/folio-j/data-location.json`。macOS 和 Linux 继续使用这个文件。各平台显式设置绝对路径 `XDG_CONFIG_HOME` 时，只使用其下的 `folio-j/data-location.json`。仅在旧注册表记过位置的用户，可在启动页重新打开原库。

<details>
<summary>PowerShell 临时切换数据库示例</summary>

```powershell
$env:FOLIO_J_DATABASE_PATH = "$HOME/Folio-J 测试/app.db"
just data-path
just start
# 停止应用后恢复默认配置
Remove-Item Env:FOLIO_J_DATABASE_PATH
```

</details>

<details>
<summary>常见问题：Windows 中文路径下旧源码包环境报错恢复</summary>

如果旧源码包在中文路径下运行 `just setup` 时报告 `init_import_site` 和 `UnicodeDecodeError`，请将新版源码包解压到新文件夹后再运行 `just setup`。若在原目录就地更新了源码，请先停止应用，在项目根目录用 PowerShell 执行 `Rename-Item -LiteralPath backend/.venv -NewName .venv-old`，再重新运行 `just setup` 重建 Python 虚拟环境。

</details>
