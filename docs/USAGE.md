# 使用指南

安装与启动见[快速开始](../README.md#快速开始)。数据备份、数据迁移与版本升级见[升级与备份](UPGRADING.md)。

## 整理来源与导入书籍

「来源」是整理材料和学习片段的基本单位，可以是一套轻小说系列，也可以是任何你自定的专题。就目前而言，我们仅支持 EPUB 书籍形式的材料，后续会有更多形式的材料如漫画、视频等得到支持，不同类型的材料可以放在同一个「来源」中。

1. **创建来源与导入书籍**：在「来源目录」或「素材库」中选择或创建来源并导入 EPUB 书籍。导入后应用会在后台解析书籍，期间可以离开页面，处理完成后点击封面即可开始阅读。
2. **手动添加片段**：如果手头只有一段日文，也可以不导入书籍，直接在来源下手动添加片段，并开始讨论或写讲解。
3. **管理书籍**：在书卡菜单中可以查看「书籍详情」、修改书名与封面，或调整阅读状态。「删除书籍」会移除应用内的原书与阅读进度，但已保存的学习片段、讲解和讨论都会保留，本地原始 EPUB 文件也不会受影响。


## 阅读器操作

### 目录、搜索与书签

- **目录与搜索**：从底部「目录」切换章节，或切换到「搜索」按字面查找正文（不含注音）。跳转查看后，可随时通过阅读器提示返回原来的阅读位置。
- **位置书签**：点底部工具栏的「添加当前位置书签」记录阅读位置，可顺手添加备注。在「目录 → 书签」中可按章节顺序查看、编辑备注或跳转回原文。
- **查看插图**：点击正文图片或底部「插图库」可放大查看、复制或下载原图。从插图库查看图片时，点「前往书中位置」可跳转到正文对应段落。

### 阅读设置与外观

打开底部「阅读设置」，可按习惯调整阅读体验：

- **排版**：调整字号、行距、字体、横排／竖排，以及横排模式下的正文宽度。
- **注音**：可设为「显示」「按需」或「隐藏」。在「注音范围」中，「原书」仅显示书中自带的注音；「全量」会根据 `Sudachi` 分词结果为未注音的汉字自动补齐振假名注音。选为「按需」时，可通过鼠标悬停、轻点、选中或按 `R` 键临时显现注音。
- **阅读界面与外观**：可在「阅读设置」中单独设置阅读纸面（白／黑／跟随系统）、工具栏不透明度，以及是否在正文中显示记录下划线与页边图标。底部工具栏还提供独立的「专注阅读」开关。应用整体的浅色／深色外观可在「设置 → 外观」中独立调整。


## 即时查词与词汇统计

### 即时查词

1. **导入词典**：在「设置 → 词典」中导入 Yomitan format 3 词条词典 ZIP。导入多本词典时，可在列表中点选当前生效的一本。
2. **开启查词**：在阅读器底部打开「即时查词」，选择「点击查词」或「Shift 悬浮」模式，也可在此调节词卡背景的不透明度。
3. **查词与套娃查词**：弹出词卡后，按住卡头可以拖动词卡，点击卡头箭头或键盘 `←` / `→` 可切换不同的匹配长度。词卡内的日文释义或例句还有生词时，可以直接接着点按或按住 Shift 往下查。我们做了特殊优化，同一段文字能匹配多个词时，系统会自动做重排与消歧。当发现没有按预想的词匹配时，请善用方向键切换～

开启点击查词模式时，原文中的翻译、片段等划线内容在点击时会优先展示词卡，你仍然可以通过页边标记或点击词卡底部的「此处记录」以查看保存的内容。

### 词汇统计与检索

从书卡菜单打开「书籍详情」，可查看全书字数、汉字数与高频词覆盖曲线，点击「查看词汇」可进入词汇表。若提示尚未准备，点开书籍进入一次阅读即可自动完成分词准备工作。

- 支持按词性筛选、按词频排序，或输入词典形、实际词形、假名读音进行搜索。
- 同一词典形的不同活用会合并计数。例如在「昨日は本を読んだ。今日は新聞を読む。」这两句里，搜索「読ん」会找到词典形「読む」，词频为 2。
- 点击任意词汇可查看它在全书各处的原文句子与前后文，点「查看原文」即可跳转到书中具体段落（会覆盖阅读进度，有些危险，预计将会做优化调整）。


## 翻译、片段保存与设备朗读

### 结合语境翻译

1. **配置翻译**：在「设置 → 翻译」中设置目标语言（默认为简体中文）、翻译模型，以及自动附带的前后文句数与字数上限。
2. **划选翻译**：阅读时划选原文并点「翻译」。若该处已有译文会直接展示旧结果，不会重复调用模型；展开「语境与设置」可调整本次附带的前后文并点击「重新翻译」。重新翻译会新增而不会覆盖历史翻译结果，可自由从各次翻译结果中选择展示版本。
3. **回看与清理**：翻译过的句子会在正文中标出浅红色虚线，也可从右上角「本章记录 → 翻译」按顺序找回或删除。

### 保存与回看片段

1. **保存片段**：阅读时划选原文，点「保存为学习片段」。应用会自动带入前后文语境；如果该句已经翻译过，也会自动填入译文草稿。保存前可以核对或修改。
2. **书中回看**：保存过片段的原文会标出红色实线。点击正文划线、页边图标或右上角「本章记录」，都能直接在书里展开查看译文、讲解和备注。点「打开片段 →」则进入独立的片段详情页。
3. **删除片段**：可在来源的片段列表菜单或片段详情页右上角删除片段（会一并移除该片段下的讲解与讨论记录）。

### 设备朗读

划选正文、查看译文或打开学习片段时，点击「朗读」即可调用设备自带的日语语音朗读原句。在底部播放条中可以暂停、重播，或调整语速（0.5–1.5 倍）与发音人。完整语音列表与试听可在设置中查看。


## 学习片段、讨论与讲解

从来源列表或原文中可进入片段详情页，对保存下来的学习片段进行更多操作。

### 复制原文与外部 AI 提示词

- **普通复制**：在阅读器中直接用快捷键或右键复制，会自动去除原书与生成的振假名注音，只保留干净的正文纯文本。
- **带上下文复制**：划选正文后点工具栏的「带上下文复制」，可将目标句子、前后文与书籍出处一键打包复制，方便直接粘贴给外部 AI 提问。默认附带的范围和格式可在「阅读设置 → 带上下文复制」中修改并保存。
- **在片段页复制**：打开片段详情页，点原文卡片右下角的「复制分享」图标，可选择复制完整原文与出处、仅原文或仅出处。

### AI 讨论与编写讲解

打开任意学习片段，你可以直接用 Markdown 手写讲解，也可以借助 AI 整理思路：

- **使用外部 AI（无需配置模型）**：点击「＋ 新建讲解 → 复制讲解提示词」，应用会把原文、前后文语境以及你在「设置 → 学习偏好」中填写的个人背景打包复制。粘贴到你常用的 AI 聊天工具中，拿到回答后再选「编写或粘贴讲解」保存即可。
- **在应用内讨论与生成讲解**：
  - 展开片段右侧的讨论区即可新建对话向 AI 提问。讨论在本地后台运行，等待回复时离开页面也不会中断。
  - 普通问答保存在对话记录里。想把有价值的解释留存下来，可以在对话中让 AI「整理成独立讲解并保存」，或直接点击「创建 AI 讲解」。
  - 讲解支持多次修改并保留历史版本，也可在讲解右上角菜单中重命名。


## 模型设置

阅读、查词、手写或粘贴讲解均无需配置模型，应用内翻译和讨论会把原文及本次所需的上下文发送给你配置的模型服务，费用由该服务决定。如需在应用内使用翻译、讨论和生成讲解，请按以下步骤接入：

1. **学习偏好与权限**：在「设置 → 学习偏好」中填写你的日语水平或讲解要求，并设置保存片段时默认带入的前后文范围。在「对话与权限」中可选择 AI 修改讲解时是「审核模式」（会先展示修改方案供你确认）还是无视风险「完全访问」（直接保存新修订）。这里的设置只影响新对话，已有对话的权限可在该对话中切换。
2. **添加服务与模型**：在「设置 → 模型与服务 → 服务管理」中添加你的 OpenAI 兼容服务地址与 API 密钥，进入服务详情点击「登记模型」。随后在「模型配置」中选定默认讨论模型，在「设置 → 翻译」中选定翻译模型。
3. **连接验证**：在服务详情中可点击「验证普通文本」或「验证流式文本」测试连通性（会发起一次简短调用），并在「验证记录」中查看返回结果或报错原因。
4. **密钥保存**：API 密钥不会写入数据库或 Git，而是保存在数据库同级目录的 `<数据库文件名>.secrets/` 文件夹下。macOS／Linux 使用当前用户权限；Windows 沿用所在目录的访问权限，不额外管理 ACL。请将学习库与备份放在自己的用户目录中。备份命令会把凭据一并保存，可能含未加密的密钥。详见[升级与备份指南](UPGRADING.md)。


## 应用配置

新安装默认将数据保存在 `~/Folio-J-Data/app.db`，后端默认访问地址为 `http://127.0.0.1:8010`（开发模式前端端口为 `5187`）。

### 自定义数据位置与端口

如果想把数据库放到其他位置（例如外接硬盘）或修改端口，可在首次启动前创建或编辑 `~/Folio-J-Data/app.toml`。例如：

```toml
[database]
path = "/Volumes/Study/Folio-J/app.db" # 改了数据库的存放路径

[server]
port = 8010
dev_port = 5187
```

* `path` 需填写包含文件名的完整绝对路径（支持 `~/`）。
* Windows 推荐写成 `path = "C:/Users/你的用户名/Folio-J 测试/app.db"`，或使用 TOML 单引号保留反斜杠，如 `path = 'D:\学习资料\app.db'`。路径中的中文和空格可以直接保留；不要在 TOML 双引号字符串中直接粘贴未转义的反斜杠。
* 修改配置后，可运行 `just data-path`（未安装 `just` 时运行 `uv run --project backend python -m app.config`）确认当前生效的数据库路径。
* **注意**：修改配置文件不会自动搬迁已有的数据库文件。如果已经产生过数据，请先按[升级与备份](UPGRADING.md)备份并恢复到新位置，再修改此路径。

### 配置优先级与高级选项

当存在多处配置时，数据库路径按以下优先级生效：

1. 环境变量 `FOLIO_J_DATABASE_PATH`（适合临时切换测试库，如 `FOLIO_J_DATABASE_PATH=/path/to/test.db just start`）
2. 程序目录下的 `config/app.toml`
3. 用户主目录下的 `~/Folio-J-Data/app.toml`
4. 当前程序目录下已有的旧版 `data/app.db`
5. 默认路径 `~/Folio-J-Data/app.db`

PowerShell 临时切换数据库时，先设置环境变量，再运行命令；结束后删除该变量即可恢复正常配置选择。它不会搬迁已有文件。

```powershell
$env:FOLIO_J_DATABASE_PATH = "$HOME/Folio-J 测试/app.db"
just data-path
just start
# 停止应用后执行
Remove-Item Env:FOLIO_J_DATABASE_PATH
```

如需调整单次翻译的字符上限、超时时间或并发限制等底层工程参数，可参考仓库中的 [config/app.example.toml](../config/app.example.toml) 在 `[translation]` 一节中配置。
