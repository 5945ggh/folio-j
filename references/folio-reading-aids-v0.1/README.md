# Folio-J 阅读辅助交互与本地开发交接

版本：v0.1 · 2026-10-19

本包根据用户本轮讨论及 `folio-j_仓库快照_20261019220331.xml` 编写。它包含可供审阅的实施建议和交互样例，没有修改生产仓库，也不代表用户已经确认了每个推荐细节。

本包保留 2026-10-19 的历史建议与样例。当前操作见[使用指南](../../docs/USAGE.md)，交付状态、限制与后续安排见 [MVP 实施基线](../../docs/handovers/MVP_IMPLEMENTATION_BASELINE.md)。

## 文件

- `DESIGN.md`：完整实施建议。含产品边界、书内/书外交互、数据归属、翻译与语音服务、旧数据兼容、实施顺序和验收。
- `prototype.html`：可直接用浏览器打开的独立交互样例。不需要安装依赖或启动后端。
- `prototype-fragment.html`：交互样例的可编辑源内容。它是供预览宿主使用的片段；单独双击请使用 `prototype.html`。
- `THIRD_PARTY_NOTICES.txt`：独立预览宿主及内置图形的来源说明，以及 Lucide／Feather 图标的许可声明。

## 建议体验顺序

1. 初始阅读器已经打开一句原文的译文。关闭小卡，点击页边的“译”“解”“音”标记，观察原文与内容的对应关系。
2. 划选一整句原文，尝试“翻译”“朗读”或“新建解析”。再划选同一段文字，结果复用同一条记录。
3. 点击右上角“阅读记录”，在书籍页面查看原文、译文、音频状态及关联解析。“回原文”返回相应位置。
4. 编辑译文后切换书内/书外，检查两处看到的是同一份结果。
5. 打开“明知道不会来了，为什么还在等？”这份解析，查看独立阅读页；编辑、粘贴普通段落、预览和保存都不需要强制标题。
6. 切换横排/竖排、调整窗口宽度、隐藏标记。观察页边卡与覆盖卡的变化，以及标记隐藏后记录仍然存在。

## 样例能力与边界

这是用于审阅交互的内存演示。刷新页面恢复初始内容，**不要把真实学习资料只保存在此样例里**。实施版的目标是持久保存；此样例没有数据库。

- 正文、书名、译文和解析均为本次自拟样例。
- 完整例句使用预置译文。任意部分选区会显示译文位置的示意文字，不进行真实翻译。
- 音频生成、播放和时长均为状态模拟，**不会发出真实语音**，也没有调用 TTS 服务。
- 支持同一示例句子内的连续原生选区。范围细线和当前高亮对应所选文字；它没有接入生产 EPUB 的 iframe、注音映射、码点校验或跨 part 选区。
- 阅读器与书籍页共享同一份内存数据；保存纯解析也会建立一条可回看的记录。取消空解析不会创建记录。
- 原型为每条记录演示一份解析；实施方案允许同一 Segment 多份 Analysis。
- 原型修订号用于展示保存效果，没有实现历史正文存储和版本回看。生产实现必须新增不可变 Revision。
- Markdown 演示渲染支持普通段落、部分标题、列表、引用、加粗和行内代码。生产实现应复用现有安全 Markdown 渲染器，不移植本样例的简化解析函数。
- 可以粘贴并编辑正文；`.md` 文件导入、服务配置、重新生成后的结果历史、删除/撤销、真实任务取消与失败恢复均在实施建议中定义，未在原型中实现。
- 同页临时切换会保留编辑草稿；刷新保护、异常恢复和持久草稿仍需实施版补齐。
- 独立样例内置必要脚本和图标，不发起外部网络请求；中日文排版使用浏览器可用字体，外观可能随系统略有变化。

## 已检查的样例行为

在本地 Chromium 中检查了 1024、736、390、320 像素内容宽度，横排、竖排及深色外观；检查了主要控制是否越界、页面切换、共享译文编辑、自由正文保存、空正文取消、纯解析记录、部分选区与重叠标记选择。检查过程中没有 JavaScript 异常或外部网络请求。

这些检查仅针对本包的交互样例。实际 EPUB 锚点正确性、Yomitan 兼容性、真实翻译效果、TTS 音质/时延、数据库迁移、任务幂等和重启后恢复，仍需在本地仓库中分别验收。
